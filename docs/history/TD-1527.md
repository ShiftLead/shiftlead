## §4.5

- 2026-11-07 (TD-1527, the designer; Paul through ao-led-tds-ledger, m-5817cb52379e, amended m-87c0a64dfefc): *A design links its synopsis* — each design keeps a plain-words synopsis, `docs/synopses/TD-<design>.md`, rewritten whole each round; an item about the design draws *· synopsis · GitHub* after *· design #n*, and the design's own Queue line draws it too; *synopsis* is the person's editor file link (`editor_file_link`, never a hand-built `vscode://`) to the design worktree's copy before the merge and the main checkout's after, *GitHub* the forge blob for the phone. The synopsis lives in its own directory rather than beside `docs/history/TD-<n>.md` (Paul's suggestion), since a history file holds only dated lines under `## §` headings.
