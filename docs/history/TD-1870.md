## §4.4a

- 2026-11-21 (TD-1870): *Settings, replicated* gains that the home sends one settings push at a time, its read of the file and its sends together. A dial's push that had read the file before a `set_settings` write could land after that write's own frame and put the old file back on the node until its next dial; a precheck of #4307's branch (9f733ce) caught it as the node's tick reading no reserve in `test_the_homes_settings_reach_a_node_on_each_write_and_on_the_next_dial`.
- 2026-11-26 (TD-1870): *Settings, replicated* gains the node's half: the node saves the pushes one at a time, in the order they came. The link serves each frame in a task of its own and the node saved each in a thread, so the dial's older file could be saved after a write's newer one and leave the replica without the write until the next dial; #4793's precheck (e92af4e1c) caught it at 'the home's write reaching the replica' in `test_the_homes_settings_reach_a_node_on_each_write_and_on_the_next_dial`.
