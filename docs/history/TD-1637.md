It reads only its parameters (`project`, `env`), finds the launcher on `env`'s PATH, and puts the payload on the run's stdin in both modes. The run is a `Popen` in its own session, read by `communicate`, so a lapse kills the group and drains the pipes. A `deadline` bounds the whole run (`START_HOOKS_LAUNCH_TIMEOUT`, 60 s, for the host agent's launch): `cadence.hook_pinned`'s `git` read (now `timeout=`, `lapse=`), the copied mode's and the run each take the lesser bound, and any lapse returns what was printed, then `on_timeout` (`START_HOOKS_TIMED_OUT`). Gemini CLI's hook calls it with no deadline, keeping each call's own bound. `mail.DOORBELL_LINE` is the preface's last sentence (the preface built from it, its bytes unchanged), `mail.START_HOOKS_LINE` the separator, and `adapters.core_runs_start_hooks` the helper; no caller reads the last three yet.
