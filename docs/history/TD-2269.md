## §4.9d

- 2026-11-25 (TD-2269): a node team's *cannot run* mark is read as none once the flow, edited under its name, asks no stage or audit for the marked model; a flow that cannot be read leaves it standing, and a list changed and put back draws the old mark again, since nothing removes it.

## §4.9e

- 2026-11-25 (TD-2269): the mark a node's *no login offers <model>* leaves lasts until the team's list or flow changes or the flow asks no longer for that model (§4.9d).
