**Blocked by:** ledgerboard#TD-151

**Why:** ledgerboard TD-150 (designed, Paul's Go 2026-11-18; built as ledgerboard TD-151, then a minor release) has the gate sweep defer a decision's ask while another blocker of the entry is still in flight, so the person is asked once the work it waits on is done, not before. The sweep can only see a blocker in another repo (`<repo>#TD-NNN`) as in flight when it is given a resolver; shiftlead's home runs the sweep (`sessionorc.gatesweep`) without one, so once the release is vendored a decision waiting on another repo's open work would still be asked at once, and the new `decision-deferred` flag would be drawn nowhere. Asked for by ledgerboard's designer (mail m-bf1b439f4ff4), per the plan's Consumers section (ledgerboard docs/plans/TD-150-decision-waits-on-work.md).

**Fix:** Once ledgerboard's TD-151 release is out, vendor it (`scripts/vendor_ledgerboard.sh <tag>`, with the agent-cadence bump that brings it). In `sessionorc.gatesweep`, where `plan()` calls `lb.sweep(...)`, pass the new keyword-only `resolve` — the same resolver the home passes `pickable()`, `ledger.Registry` over the registered repos (as `agent_tick` builds it). Wherever shiftlead draws `uncovered_decisions()`'s `decision-elsewhere` flag, draw the new `decision-deferred` beside it as a flag, never a refusal; today no shiftlead surface draws `decision-elsewhere` (the vendored v3.4 computes it inside `uncovered_decisions()`, which shiftlead never calls; the merge gate's board row is agent-cadence's), so where none does once vendored, note that in the Log rather than invent a surface. Add a test that a decision gate on an entry also blocked by an open `<repo>#TD-NNN` is deferred by the home's sweep, and say the behaviour in design §4.4's event-runner paragraph.

**Done when:** shiftlead vendors the ledgerboard release with TD-151, the home's gate sweep passes `sweep()` the registry resolver with a test pinning the deferral across repos, design §4.4 says so, and `decision-deferred` is drawn wherever `decision-elsewhere` is (or the Log says no surface draws either).
