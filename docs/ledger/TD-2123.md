**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 62f3e165384745c19c71628b5f9e28f2
**Part of:** TD-2106

**Why:** Part of TD-2106. Nothing ages what runs outside a seat's scratch leave in shared temp space. Read on 2026-11-23: `/tmp/claude-1000` held 85,860 inodes, of which about 36,000 had been quiet for three days and held no git work, and 382 `pdm-build-*` directories sat in `/tmp`.

**Location:** src/sessionorc/tempsweep.py, src/sessionorc/agent_tick.py, src/shiftlead/adapters/claude_code, design 4.3 and 4.6

**Fix:** Build design §4.6 *The disk sweep*, *tool temp*, and §4.3's `temp_roots` and `temp_entry`: a `tempsweep` module, its call in the hourly pass straight after *scratch*, the Claude Code adapter's two members, `TOOL_TEMP_QUIET_S` of three days and `TOOL_TEMP_BUDGET_S` of a minute. Tests take the roots as arguments and never read the real `/tmp`.

Add `changed: bool = False` to `scratch._quiet`, reading the newer of `st_mtime` and `st_ctime` when true; every existing caller stays as it is. Add `limit: float | None = None` to `scratch.git_work` and `_git_dirs`, a monotonic deadline past which the walk raises `TimeoutError`, an `OSError`, so `git_work` reads it as held; `git_work` also reads it between stores and returns True past it. Every existing caller passes none. Add `started: float | None = None`, as its last field, to `ExternalSession`, in epoch seconds from the registry's `startedAt` (milliseconds), None where absent.

Name the two optional members in the adapter Protocol comment block in `src/sessionorc/adapters.py`, beside the other optional members.

**Done when:** With fixture roots: an unused project directory, loose file and clean clone past three days and a `pdm-build-*` past a day are removed, each counted in `removed` and adding nothing to `held`. Kept: an entry written within the age; one with an old modification time and a fresh change time; one written since the oldest live outside session started; every entry while an outside session has no start time; one a live or outside session works in; a project directory named for a live session's working directory; a clone holding git work; a symlink; another uid's entry; anything overlapping a transcript store; an entry when a session goes live between the first read and the re-read. An absent root removes nothing and leaves the reading whole. A clone whose git walk is cut short is kept. Nothing is removed where the root is a symlink or another uid's (the kind reads *partial*), where an adapter cannot name its transcript stores, or where its sessions cannot be read. A dry run removes nothing and reads *partial* past its deadline; a real pass past its budget stops and the next pass takes the rest; a scratch home's agent runs neither part.
