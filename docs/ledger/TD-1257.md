## TD-1257: The test that an item's Open session copies its id reads `app.js` as text, so disabling the branch passes it

**Priority:** Low
**Type:** debt
**Added:** 2026-10-30 (test-audit-ao-1, auditing the last ten merged PRs)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `src/shiftlead/ui/static/app.js` (the `ledger_start` press: `if (r.focus && b.dataset.item) { … navigator.clipboard.writeText … }`); `tests/test_queue_start.py` (`test_an_items_open_session_copies_its_id_and_the_toast_shows_it_where_refused`)

**Why:** #2714 (TD-1246 (3)) made an item's **Open session** put the item's id on the clipboard, the toast showing it where the browser refuses. The test's name says it copies and shows; its body slices `app.js` and asserts that substrings are present (`navigator.clipboard.writeText(b.dataset.item)`, `AO.unPend(row)`, `return;`). Probe at `origin/main` 8893b5bf5: replacing `if (r.focus && b.dataset.item) {` with `if (false) {` and running `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_queue_start.py tests/test_ui_queue.py tests/test_ui_queue_cards.py tests/test_queue_board_item.py tests/test_queue_wants.py` gives `98 passed`, the same as unmutated: the strings are all still in the file, and the clipboard never written. The same holds for a reordered `writeText` after the redirect, which would navigate away before the copy.

**Fix:** run the press in a browser (the repo's Playwright harness, if the suite has one; else a `node` script over a stub `navigator.clipboard` and `location`) and assert the clipboard got the id on an Open session and the toast on a refusal; or say in the test's docstring that it only pins the source text.

**Done when:** `if (false) {` in place of that condition fails a test.

**Related:** TD-1246, #2714
