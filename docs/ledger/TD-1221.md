## TD-1221: The pre-pin shim test skips on every agent-cadence checkout, so what it pins has run in no suite since #2651

**Priority:** Medium
**Type:** debt
**Added:** 2026-10-29 (test-audit-ao-1, auditing #2642–#2651)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `tests/test_pinned_cures.py` (`_shim_at`, `test_agent_cadences_pre_pin_shim_warns_in_a_pinned_repo_and_its_td129_shim_does_not`)

**Why:** The test checks out the shim at two dev-cadence commits, `2cc2b88` (warns) and `ddd2f99` (does not), with `git archive <ref>` in `AGENT_CADENCE` (`~/agent-cadence`), and `_shim_at` answers a missing ref with `pytest.skip(f"no {ref} in the agent-cadence checkout")`. #2651 pointed `AGENT_CADENCE` at agent-cadence, whose history is a rebuilt one (its first commit is `35b4b4a`) and holds neither ref: `git -C ~/agent-cadence cat-file -t 2cc2b88` prints `fatal: Not a valid object name`, as does `ddd2f99`; `git -C ~/dev-cadence cat-file -t 2cc2b88` prints `commit`. `pdm run pytest -q -rs tests/test_pinned_cures.py` at `origin/main` 92df926 prints `SKIPPED [1] tests/test_pinned_cures.py:153: no 2cc2b88 in the agent-cadence checkout`. The guard on the test (`skipif` on `launcher/INTERFACE`) passes, so the skip is quiet, and the `seams.SHIM_MARKER` and the *per-clone setup not run* warning for a pre-pin shim (`seams.reading`) are asserted by no running test.

**Fix:** keep the two shims' text in the repo as fixtures (a pre-pin and a TD-129 `pre-push`, the two files `install_git_hooks.sh` wrote at those refs) and write them into the scratch clone, so the test needs no checkout and cannot skip; or fail, not skip, when the ref is missing and the checkout is present.

**Done when:** the test runs, not skips, on a machine whose only checkout is agent-cadence's, and a mutation that drops the warning for the old shim fails it.
