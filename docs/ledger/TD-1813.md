## TD-1813: read_build's failed merge-base --is-ancestor refusal has no test

**Priority:** low
**Type:** debt
**Added:** 2026-11-14
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 96f36e67b178439bac73c6cc99bf904a

**Why:** Found by the test-audit of #3772 (TD-1794). `read_build` refuses where `git merge-base --is-ancestor HEAD <ref>` exits other than 0 or 1 (a broken or shallow history), so that is never read as 'local'. tests/test_feedback_report.py has no case where that call exits 128. Probe: `if anc.returncode not in (0, 1):` replaced by `if False:` left `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_feedback_report.py` passing; a 128 would then read as local and send the merge-base of a broken history.

**Location:** tests/test_feedback_report.py

**Fix:** Add a case to test_build_refuses_no_upstream_no_main_and_no_checkout with a git stub that exits 128 for `merge-base --is-ancestor`; it must raise Refused. Re-run the probe: it must fail.

**Done when:** Done when removing the exit-code check on merge-base --is-ancestor fails a test.
