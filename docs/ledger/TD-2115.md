## TD-2115: The disk sweep removes old status-line and launch files that no session owns

**Priority:** Low
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 1f4d2c8169cf44a397222b463865024c
**Part of:** TD-2105

**Why:** Part of TD-2105's design (§4.6 *The disk sweep*, *home files*). Status-line files and launch files in the home have no expiry: on 2026-11-23, in a read later than TD-2105's own, 2,975 of 3,016 status-line files and 67 of 84 start-context files named no record, and 16 launch scripts named none.

**Location:** src/sessionorc/homesweep.py, src/sessionorc/agent_tick.py, src/sessionorc/diskbook.py, design §4.6 The disk sweep

**Fix:** Build §4.6 *The disk sweep*, **home files**, for `statusline/`, `statusline/context/`, `launch/*.context.md` and `launch/*.sh`, in a new `sessionorc/homesweep.py` called from `_prune_rules` under `late("home")`, after *worktrees* and before *branches*. Add `home` to `diskbook.KINDS` and draw it in `ao disk` (§4.7), including a dry run, listing exactly the names the rule reads, and naming each kept path with its why. A `*.tmp` beside the status-line files past the age goes with no record test. Add the persisted record field `context_id` beside `adapter_id`, in `NODE_OWNED`, set in the create's `Session(...)` call from `LaunchSpec.adapter_id` on a `start_context` adapter, and filled from `adapter_id` at each load in `__init__` after `store.load_all()` for `self.sessions` (idempotent, unsaved, skipping None and any adapter this host does not know). `rpc_get` reads a moved brief by `context_id`, else `adapter_id`. `_drop_context` drops the file for `adapter_id` and for `context_id`, each only when no other record holds that conversation as either. Both callers (`_forget` and the replace in place, with its guard) pass and compare `context_id` too. A Resume that keeps a context file sets its modification time first, then tests it is a file. Each path is read again, with the records, just before its own removal. Never read or remove `launch/*.json`. Update `paths.context_file`'s docstring to name the sweep.

**Done when:** Each of the four kinds past `runs_keep_days` with no record is removed, and one with a record in any state is kept, with `0` removing nothing. A context file a cleared live session's `context_id` names is kept by the sweep and by a Forget of another record. A record from before the field gets its `context_id` at load. A dead writer's `*.tmp` past the age is removed. A launch record is never removed. `ao disk` and `ao disk --dry-run` count the kind.
