**Fix:** Add to `tests/test_switchover.py` a team whose `logins` hold a bare name with no colon (expect the `its logins are not a list of <tool>:<name>` blocker), and an answers file whose `director` is a list (expect `director must each be a mapping`). Check both fail with the clause removed.
