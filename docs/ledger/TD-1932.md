**Why:** Part of TD-1899's design: the home reads who worked each closed entry from its closing commit's trailers, so the Queue can draw it (TD-1933).

**Location:** src/sessionorc/ledger.py (history, recent, completed); src/sessionorc/queue.py (completed members); design §4.4 What closed

**Fix:** Build design §4.4 *What closed, and by which PR*, its **Who closed it** (TD-1899), and *Completed cards*' members carrying it.

- `sessionorc.ledger.history`'s log format (both of its `git log` calls, the old file's `-p` and the directory's `--name-status`) becomes `%x00C %H %cI %s%x1d%(trailers:only,unfold,separator=%x1f)`. `_commit_line` splits the line at its first `\x1d` before it reads the sha, instant and subject, so `SQUASH` still reads the subject's end; the rest is the trailers, split at `\x1f`, each at its first `: ` into a key and a value. `Event` gains the trailers as its sixth member, which `_log_events` and `_dir_events` both carry from `_commit_line`; `Change` gains `by`, which `_replay` sets beside `closed`, `pr` and `sha` when it closes an entry, from that commit's trailers alone, and clears with them when the entry is re-opened. Trailer keys are compared ignoring case. The history runs no second `git log`; its one other git call is the precheck's, below.
- Each `recent` and `completed` entry carries `by`: None where the entry is open or its closing commit has no `Merged-by:` trailer, else `{pr, built, reviews, precheck, merged, override}`, parsed exactly as §4.4 says. `pr` is the closing commit's own `(#n)`, None where it has none. `built` is the session co-authors (an address's local part equal to the name), in order, each once. `reviews` is `{model, verdict}` per `Review:` trailer, in order: `verdict` the parenthesised `SHIP`, `FIXED` or `BLOCK` ending the value, matched ignoring case and kept upper-case; `model` a name kept as written, only for the cadence's own shapes §4.4 lists, else None, and None for `unknown` in any case. `precheck` is True or False by the `Precheck:` trailer, set so by `_replay`; `history`, which holds the root and the revision its log walks, then calls `cadence.precheck_command(root, <that revision>)` once and sets every `by`'s `precheck` to None where it gives no command, `(None, None)` or `(None, why)`. `override` is a boolean. `merged` is the `Merged-by:` value with a trailing parenthesised group cut.
- The Queue reading's completed-card members and archived rows carry `by` beside `sha` (`src/sessionorc/queue.py`, *Completed cards*).
- Tests: a commit with every trailer (two session co-authors, one with a lower-case `Co-authored-by:` key, the model's and the person's left out, reviews in the `sonnet (SHIP)`, `claude-sonnet (sonnet?) (FIXED)`, `(sonnet, independent) at … (SHIP)` and `(fact-check, doc-only) at … (SHIP)` forms, and model None from `unknown (SHIP)`, `0 findings (SHIP)`, `3 findings (1 fixed) (SHIP)` and `independent review by claude-sonnet (subagent) at … (SHIP)`); `precheck` None in a repo with no precheck set; an entry closed, re-opened and closed again carrying the last close's `by`; an entry archived by a later PR than its `Resolved:` names, its `by.pr` the later one; one with `Merged-by:` and no `Review:` or `Precheck:`; one with `Merge-override:`; one with no trailers (`by` None); a squash subject ending `(#n)` still read as its PR with the trailers after it; both the old file's history and the directory's; and an entry with no sha; an open `recent` entry's `by` None; a repo whose `docs/cadence.toml` does not parse giving `precheck` None; a review value `sonnet (ship)` read as `SHIP`; a commit with `Merged-by:` and no `(#n)` giving `by.pr` None.
