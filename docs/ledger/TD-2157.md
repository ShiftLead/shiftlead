## TD-2157: Nothing tests that the home's tick starts the stage pass

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-25
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 47643c4e36d64ee0b1a4a014b6a9aa09

**Why:** The stage pass reaches the home only through one line in `Agent.tick` (`src/sessionorc/agent_tick.py`): `self._stage_due()`, added by #4499 (TD-2051 slice 36). No test runs a tick and sees the pass start. Evidence: with that line replaced by `pass`, `tests/test_stage_pass_agent.py`, `tests/test_agent.py`, `tests/test_attention.py` and `tests/test_seat_budget.py` all pass (108 passed), and `grep -rn "_stage_due\|_stage_task" tests/` finds them only in `tests/test_stage_pass_agent.py`, which calls `_stage_due()` itself on a stub `_Agent` that is not the real tick. So a change that stops the home ever starting the pass after the cut-over would not be caught.

**Location:** src/sessionorc/agent_tick.py; tests/test_stage_pass_agent.py

**Fix:** Add a test that runs the real `tick` on a home-mode agent past the cut-over (as `tests/test_agent.py` builds one) with `_stage_pass` replaced by a recorder, and asserts it was started once; check it fails with the `_stage_due()` line removed.

**Done when:** A test fails when `Agent.tick` no longer calls `_stage_due()`, and passes with it.
