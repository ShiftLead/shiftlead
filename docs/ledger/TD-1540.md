**Fix:** Build §4.7 `ao board edit … --carried-to` and the briefs' step:
- `src/shiftlead/cli.py` (`cmd_board_edit` ~3486, its parser ~5641): `--carried-to TD-n[,TD-m…]`, accepted with `done` only (refused with `snooze`), composes the `Closed:` reason *carried to TD-n* (several joined *TD-n and TD-m*, *TD-a, TD-b and TD-c* for three; a `<repo>#TD-n` written as given), followed by `: <why>` where `--why` is given too, and passes it as the `--why` the edit already writes. Each bare id must be an entry of the branch's own ledger, open or under `archive/` (read from the working tree the edit commits on); an unknown bare id is refused before anything is written, naming it; an id of another repo is not checked.
- Briefs: `docs/briefs/designer-ao-1.md` (held path; its *The answered item* line's `ao board edit done --why "carried to TD-n"` becomes `ao board edit done --carried-to TD-n`) and the packaged grinder brief, `src/shiftlead/briefs/grinder.md` (~12: *close the line pointing at it (`ao board edit done --line <n> --expect "…" --why "see TD-n"`)*, the template every free-pick lane runs and the source of the *see TD-n* closes), say `--carried-to TD-n`. `grep -rn 'carried to\|see TD-n' docs/briefs src/shiftlead/briefs` finds every place; each that closes a line for another's work names the option.
- **Tests** (`tests/test_board_edit.py`): `done --carried-to TD-5` closes the line `— carried to TD-5`; `--carried-to TD-5,TD-6 --why "the bought round"` writes `— carried to TD-5 and TD-6: the bought round`; an id the ledger lacks is refused with nothing written; `snooze --carried-to` is refused; the reason it writes is one `workorders.carried_to` reads back as the ids given.

**Done when:** `ao board edit done --carried-to TD-n` writes a `Closed:` reason beginning *carried to TD-n* that the Queue's reader parses, refusing an id its ledger lacks; the designer briefs name it for an answer that is another's work; the tests pass.
