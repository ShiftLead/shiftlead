## TD-1483: A doc-only or ledger-only PR runs the whole suite, which flakes under load and costs minutes per rebase

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-06 (Paul, through ao-led-tds-ledger and the techlead seat; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 555b17c25f5240e38687f6ae9aed41a6
**Location:** docs/cadence.toml (`precheck`, a new `[precheck-paths]` table, agent-cadence TD-155); tests/ (the doc-bound tests)

**Why:** A PR that changes only `docs/` or `docs/ledger/` runs the full suite (~5,000 tests, 3–4 min) at its precheck, and flakes under load: #3043 needed three runs at a load average near 21. On 2026-11-06 the techlead seat's ledger-only PRs #3011 and #3067 each failed once on an unrelated flake (TD-1442, TD-1254) and passed on the re-run.

Found by Paul's trial review of three seats' transcripts (designer-ao-1, grinder-ao-2, techlead-ao-1), 2026-11-03 to 2026-11-06, deduped against the ledger, and sent through the person's session `ao-led-tds-ledger` (m-01263e0bba7e); its tooling and rule parts went to agent-cadence.

**Fix:** Use what the pinned precheck already supports (agent-cadence TD-155). `precheck.py` reads a `[precheck-paths]` table from `docs/cadence.toml`, and when every file in a PR's three-dot diff matches an entry's globs it runs that entry's command instead of `precheck`. A diff no entry covers, or one it cannot read, takes the full command, and the forge's `cadence/precheck` status is the same either way. Shiftlead's `docs/cadence.toml` has no such table today. Add one entry for `docs/**` (ledger, board, design, briefs, memories, mockups) whose command runs the doc-bound tests:
- `tests/test_design_doc*.py`, `tests/test_help*.py`, `tests/test_ledger*.py`;
- every test file that names `4.5a`;
- `agent-cadence run ledger.py --check`;
- lint.

Check that a PR touching `src/` still runs the full suite.

**Done when:** A ledger-only PR's precheck runs the light command and records `cadence/precheck`, and a PR touching `src/` runs the full suite: both seen on a real PR and recorded here.
