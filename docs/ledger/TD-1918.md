## TD-1918: The Focus terminal still draws a ZWJ emoji sequence or an emoji presentation selector in other cells than tmux

**Priority:** Low
**Type:** debt
**Added:** 2026-11-17
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 33f389129f604602aba34e331e96e521

**Why:** TD-1912 (#4055) loads xterm.js's unicode11 addon in the Focus terminal, which matches tmux 3.5a for single-codepoint emoji and wide symbols, but not for grapheme clusters. Read 2026-11-17 on an 80-column grid, the cursor column after each string, against `#{cursor_x}` in a private tmux 3.5a: `👨‍👩‍👧x` (a ZWJ family) is 3 in tmux and 7 in xterm with unicode11; `⚠️x` (⚠ with the emoji variation selector U+FE0F) is 3 in tmux and 2 in xterm. Each such sequence still shifts the rest of its line in the browser. xterm.js measures clusters only through `@xterm/addon-unicode-graphemes`, whose one stable release (0.4.0, 2025-12-22) is built for xterm 6; nothing was published for the vendored 5.5.0 line.

**Location:** src/shiftlead/ui/static/vendor/ (the xterm.js family); src/shiftlead/ui/static/app.js (AO.termUnicode, AO.focus)

**Fix:** Move the vendored xterm.js family to the 6 line (`@xterm/xterm` 6.x with the fit, WebGL, web-links and unicode11 addons of the same release, each file matched by SHA-256 to what its package publishes, rows in `src/shiftlead/ui/static/vendor/README.md`), read xterm 6's breaking changes against `AO.focus` and every test that runs the vendored files under node, then vendor `@xterm/addon-unicode-graphemes` at the release paired with it and load it in `AO.termUnicode` in place of unicode11, its version made active. Goal 12's sentence (design §2) drops its exception for ZWJ sequences and variation selectors.

**Done when:** In a headless browser on the vendored files, `👨‍👩‍👧x` and `⚠️x` leave the cursor at the column tmux's `#{cursor_x}` reads for them (3 and 3 on tmux 3.5a), as `a😀b`, `✅x` and `中文x` already do; a test holds that the graphemes addon is vendored, loaded and active; `pdm run test` and `pdm run lint` pass.
