## TD-2275: The design says a change clears a cannot-run mark that returns when the change is undone

**Priority:** Low
**Type:** debt
**Added:** 2026-11-26
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 4ef238fdbf174967acae34f25d3e8a99

**Why:** Audit of #4760 (TD-2068 slice 12) and #4763 (TD-2269). Design §4.9d *Where a seat's session launches* says a set's node mark is "read only while the set's list and the seat's model are the ones it names, so a change of either clears it with nothing written". §5 says the same, "which a changed list or seat model clears", and of a team's mark "which a changed list or flow clears".

Nothing removes either mark, so a change only hides it. Probe at 22675a930, one mark `{"node1": {"model": "haiku", "logins": ["claude-code:a"]}}` read by `set_node_cannot_run`: as marked, the words; list changed, `{}`; list put back, the words again; model changed, `{}`; model put back, the words again. With the mark read as standing, `on_set_node` (`src/shiftlead/stage_start.py`) and the tick's `_node_seat_list` send that node no launch, so it is not asked again until the list or the model next changes. `rpc_builtins_node_cannot` is the one writer of a set's mark, and `rpc_builtins_delete` edits the settings file alone.

For a team's mark #4763 wrote this into §4.9d *A team on a node* ("a list changed and then put back, with no refusal between, draws the same mark again"). It left the set's paragraph saying *clears*, and §5's line on the team's mark, which now also lacks the case #4763 added (the flow edited to ask no longer for the model).

**Location:** docs/design/4.9d-teams.md Where a seat's session launches; docs/design/5-configuration.md

**Fix:** Say in §4.9d *Where a seat's session launches* that a list or model changed and put back draws the old mark again, as *A team on a node* says of a team's; bring both of §5's clauses into line; add the history lines. A session that would rather drop the mark at the write changes §4.9d first.

**Done when:** Neither §4.9d nor §5 says a change clears a node mark that returns when the change is undone.
