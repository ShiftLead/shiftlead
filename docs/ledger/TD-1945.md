## TD-1945: The host agent's hourly sweep also removes ended sessions' scratch, landed worktrees, old caches and run logs past a size, never transcripts

**Type:** debt
**Added:** 2026-11-18
**Owner:** grinder

**Status:** Open

**Why:** What sessions leave on a host has no owner and no schedule: the tool's scratch, worktrees a close kept or a session made itself, run logs of 30 days whatever their size, and old precheck and agent-cadence caches (TD-1921: about 24 GB on kmaster, growing about 10 GB a month). Design §4.6 *The disk sweep* adds them to the host agent's hourly sweep and keeps transcripts out of its reach.

**Location:** design §4.6 *The disk sweep*, §4.3, §4.1, §5; src/sessionorc/agent_tick.py (`_prune_runs`), src/sessionorc/agent_common.py (`PRUNE_EVERY`), src/sessionorc/hosts.py, src/shiftlead/ui/settings_page.py, src/shiftlead/adapters/

**Fix:** Build design §4.6 *The disk sweep*, with §4.3 (`transcript_roots`), §4.1's pointer, §9 invariant 16 and §5 (`scratch_keep_hours`, `worktree_keep_days`, `runs_keep_mb`, `cache_keep_days`, each parsed in `sessionorc.hosts` as `runs_keep_days` is and shown on the Settings page's Hosts card), in the host agent's hourly sweep (`_prune_runs` in `sessionorc.agent_tick`, every `PRUNE_EVERY`):
- scratch: a directory under `shiftlead-<uid>/` whose `owner.json` names this home and that is no live record's `scratch`, once the record naming it has been ended `scratch_keep_hours`, or, named by no record, an hour after its newest write; never a live record's, one naming another home, one with no readable `owner.json` (kept and reported), or one holding git work not all on a remote branch or with modified or untracked files (kept, *git work*); `git worktree prune` in the owning repo after removing one that held a worktree;
- worktrees under each registered repo's worktree root (`docs/cadence.toml` `worktree-root`, else `.claude/worktrees`) on the host passing the five tests `reap_worktrees.sh` states (*landed*, *clean*, *idle*, *unlocked*, *nested*), held in `sessionorc` (the script is not run: it weighs no single worktree, writes no report a program reads, and its `--reap` deletes branches), with a fixture test that runs the pinned script without `--reap` over the same worktrees and finds the same verdicts; *idle* also read from the live records; older than `worktree_keep_days` by their newest write; the records read again just before each `git worktree remove`; never the main checkout, a detached worktree, one with a commit on no remote branch or a modified or untracked file; no branch deleted; a pass weighs worktrees oldest first for at most `SWEEP_WORKTREE_S` (60 s), the next carrying on;
- run logs and attachment folders of ended sessions past `runs_keep_mb` (`0` no bound), oldest ended session first, beside `runs_keep_days`; rounds logs, promote logs and draft folders neither count nor go by it;
- agent-cadence trees under `~/.cache/agent-cadence/trees/` that are no registered repo's `origin` default branch's pin and older than `cache_keep_days`, only by the home at `~/.shiftlead`, under agent-cadence's cache lock, renamed aside and made writable before removal; no repo's own precheck cache;
- `transcript_roots()` on each adapter (Claude Code `~/.claude/projects` and each profile's `config_dir`'s `projects`; Gemini CLI its `<home>/.gemini/tmp`; Grok Build each profile's `<config_dir>/sessions`, none without one); the sweep removes only under its named roots, never follows a symlink, and refuses any path inside a transcript root;
- each pass returns, per kind, the bytes held and removed and each kept item with its why (*not landed*, *untracked files*, *live record*, *pinned*, *git work*, *another home*, *no owner*), which TD-1946 writes and reads.

**Done when:** In a scratch home with scratch repos and a fake tool home, one sweep removes an ended record's scratch past its keep, a fresh start's old directory an hour after its last write, and leaves a live one's, one naming another home, one with no `owner.json`, and one holding a clone with an unpushed commit (*git work*); a second home's sweep over the same `scratch_root` removes none of the first's; removes a landed, clean, idle, unlocked worktree past its keep and keeps one with an unpushed commit, one with an untracked file, a live record's, a detached one and the main checkout, each with its why; the fixture test finds the same verdicts as the pinned script; drops the oldest ended session's run log past `runs_keep_mb` and never a live one's; removes an unpinned agent-cadence tree past its keep and keeps the pinned one, and a scratch home's sweep removes no tree; and a test plants a transcript (and a symlink to one) under every adapter's `transcript_roots()` and inside a swept root, runs the sweep, and finds every transcript intact.
