## TD-1259: A file path that wraps onto a second row of the Focus pane is never a link, though the file exists

**Priority:** Medium
**Type:** debt
**Added:** 2026-10-30 (Paul, through Add entry; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `src/shiftlead/ui/static/app.js` (`AO.pathProvider`, which reads one row; `AO.cutRows`, TD-494's join, which only the web-links addon reads; `AO.pathRuns`); design §4.6 *A path in the pane is a link* (*A path that wraps across rows is cut as a URL is until TD-494's join, which serves both*); `tests/test_ui_focus_paths.py`

**Why:** Paul, 2026-10-30: *In our focus terminal, some files are still not linked … Lets fix the links so that if a file exists on the machine it gets a link* (screenshot `~/.shiftlead/attachments/draft-1d5a6230/paste-20261030-113522.png`). The session printed `/tmp/claude-1000/-home-kmaster-agent-cadence--claude-worktrees-sl-tds/5634736a-ec3f-495f-82d9-e32ebecf5b18/scratchpad/td203-rounds-plan.md`. The file exists, is a regular file, and nothing in `PATHS_PRIVATE` matches it, so the host's `paths` RPC would answer it (TD-688). But the path is longer than the pane is wide and wraps onto a second row. `AO.pathProvider` reads `term.buffer.active.getLine(y - 1)` alone, so each row holds only part of the path: the first part does not exist and the second part does not start with `/`, so neither is a link. TD-494 joined wrapped and cut rows (`AO.cutRows`) only for the web-links addon, though §4.6 says that join *serves both*. So a long path is never a link, and that is the case where a link saves the most typing: scratchpad, worktree and `/tmp` paths, which agents print often.

**Fix:** make the path provider read the logical line, as the URL addon does. From the hovered row, walk back while a row is wrapped (`isWrapped`, or cut by `AO.cutRows`'s rule) and forward while the next one is. Join their text, run `AO.pathRuns` over the joined text, and map each run's start and end back to (row, cell) pairs, through each row's wide-character cell map. Return a link whose range spans the rows, as the addon's ranges do. Keep the row cache, keyed by the joined text, and the cap of eight runs. Bound the join (the addon's own limit, or about 2048 characters) so a wall of joined text costs one ask. The cut-row rule is TD-494's: share it with `AO.cutRows`, don't copy it, so the two never drift apart. Then change §4.6's sentence from *until TD-494's join, which serves both* to say that the join serves both. While building it, check whether any other shape a session prints leaves an existing file unlinked (for example a path in backticks or quotes, which `pathRuns`'s character class already stops at), and file anything found as its own entry.

**Done when:** in a Focus pane, a path to an existing file that wraps across two or more rows, whether soft-wrapped or cut by the program at the width, underlines on every row it spans, and Ctrl+click opens that file. A test in `tests/test_ui_focus_paths.py` drives `AO.pathProvider` over a fake buffer where one path is split across a wrapped row and a cut row. §4.6 no longer says *until*.

**Related:** TD-494 (the row join, URLs only), TD-501 / TD-493 (a path is a link), TD-688 (any readable file on the host)
