## TD-1419: The home's sync merge runs cadence step 5's line, so a pin bump's squash ends in Merged-by: shiftlead-sync

**Priority:** medium
**Type:** feature
**Added:** 2026-11-06
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 2cb31d2dcee943d4a740be55fe9a3407
**Blocked by:** TD-1418
**Part of:** TD-1412
**Location:** src/sessionorc/sync.py (merge); src/sessionorc/agent_sync.py (_sync_merge); design §6 Sync step 5

**Why:** TD-1412's design (§6 *Sync* step 5). The home merges a mechanical sync PR with `gh pr merge <n> --squash --match-head-commit <head>` and no body (`sessionorc/sync.py` `merge`, called from `agent_sync._sync_merge`). So the squash carries no `Merged-by:`, and from the first step-5 merge on, agent-cadence TD-234's weekly read lists every pin bump the home merged as merged outside step 5.

**Fix:** As §6 *Sync* step 5 says:
- `sync.merge(root, n, head)` runs cadence step 5's line in the registry checkout, each script found as `cadence.check` finds the gate (through `cadence.command` in a pinned repo, `python3 scripts/…` else). The steps are: `check_cadence.py --pr <n> --trailers <dir>/gate` (with `--json`, read as `cadence.check` reads it), then `forge.py squash-message <n> --gate <dir>/gate --out <dir>`, then `gh pr merge <n> --squash --match-head-commit <the file's sha> --subject <subject> --body-file <dir>/body`. `<dir>` is a `tempfile.mkdtemp()` removed in a `finally`.
- The two scripts get `AGENT_NAME=shiftlead-sync`, with `AGENT_MODEL` and `AGENT_MODEL_FILE` removed from their environment.
- A gate exit other than 0, or a `squash-message` refusal, returns its words, so `_sync_merge` writes *no reading* as today. A sha in `<dir>/sha` other than `head` returns the moved head, so nothing is written and `_sync_merge` returns None.
- Where `cadence.composes(root)` (TD-1418) is false, the merge is today's bare one.
- The system note to the person is unchanged.
- Tests, with `gh` and the launcher shimmed: the three commands in order with their flags, the environment, the fallback, a failing gate making no merge, a moved sha, and the directory removed on every road.

**Done when:** The home's next merge of a sync PR has a squash commit that `git log -1 --format='%(trailers:key=Merged-by,valueonly)'` reads as `shiftlead-sync`. The tests above pass.
