## TD-1419: The home's sync merge runs cadence step 5's line, so a pin bump's squash ends in Merged-by: shiftlead-sync

**Priority:** medium
**Type:** feature
**Added:** 2026-11-05
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 2cb31d2dcee943d4a740be55fe9a3407
**Blocked by:** TD-1418
**Part of:** TD-1412
**Location:** src/sessionorc/sync.py (merge); src/sessionorc/agent_sync.py (_sync_merge); design §6 Sync step 5

**Why:** TD-1412's design (§6 *Sync* step 5). The home merges a mechanical sync PR with `gh pr merge <n> --squash --match-head-commit <head>` and no body (`sessionorc/sync.py` `merge`, called from `agent_sync._sync_merge`). So the squash carries no `Merged-by:`, and from the first step-5 merge on, agent-cadence TD-234's weekly read lists every pin bump the home merged as merged outside step 5.

**Fix:** As §6 *Sync* steps 4 and 5 say. The gate runs once.
- **Step 4.** Where `cadence.composes(root)` (TD-1418) is true, `judge`'s gate run takes `--trailers <dir>/gate`, beside `--json`. `<dir>` is a `tempfile.mkdtemp()` the pass makes for that PR. `judge` returns it on the in-memory entry as `gate_dir`, which is popped before the entry is written to the reading.
- **Step 5.** `_sync_merge` / `sync.merge` runs `forge.py squash-message <n> --gate <dir>/gate --out <dir>` under `GATE_TIMEOUT`. Each script is found as `cadence.check` finds the gate (`cadence.command` in a pinned repo, `python3 scripts/…` in a copy; agent-cadence's source never reaches here). Then it re-reads the head and the holders, as it does today, now just before the merge. Then it runs `gh pr merge <n> --squash --match-head-commit <sha from <dir>/sha> --subject <dir>/subject's text --body-file <dir>/body`.
  - A `squash-message` refusal is *no reading* with its words.
  - A sha in `<dir>/sha` other than the re-read head is the moved head: nothing is written, and it returns None.
  - `<dir>` is removed in a `finally` on every road.
- **The environment.** Both scripts get `AGENT_NAME=shiftlead-sync`, with `AGENT_MODEL` and `AGENT_MODEL_FILE` removed.
- **The fallback.** Where `composes` is false, the gate runs without `--trailers` and the merge is today's bare one.
- The system note to the person is unchanged.
- **Tests**, with `gh` and the launcher shimmed:
  - `--trailers` on step 4's gate only where `composes` is true;
  - `gate_dir` never written to the reading;
  - the compose and the merge with their flags, in order, the holders re-read after the compose;
  - the environment;
  - the fallback;
  - a refusal, and a moved sha, each making no merge;
  - the directory removed on every road.

**Done when:** The home's next merge of a sync PR has a squash commit that `git log -1 --format='%(trailers:key=Merged-by,valueonly)'` reads as `shiftlead-sync`. The tests above pass.
