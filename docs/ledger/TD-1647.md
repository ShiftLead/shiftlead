**Location:** design §4.3 *The conformance suite* *A seat's life end to end*; tests/conformance/ (stub_cli.py, test_seat_life.py, fixtures/*/manifest.json)

**Why:** TD-1577's design (§4.3 *A seat's life end to end, in CI, with no model*): the offline suite reads each adapter method alone and the live walk needs a person, so no test runs a seat's life — a launch, an ask delivered and read, an `ao` command run, the reply landing, the seat closing. A stub CLI replaying the adapter's own captured fixtures runs it in CI with no model, for every registered agent adapter, a new one included from its first fixture.

**Fix:** Build §4.3 *A seat's life end to end, in CI, with no model* as written:
- `tests/conformance/stub_cli.py`: one tool-neutral stub, run as the adapter's `binary`; it writes its argv and its `SHIFTLEAD_*`/`CADENCE_*` environment to a file, replays the manifest's `life` payloads from `captured/hooks.jsonl` through `shiftlead-hook --adapter <name>` (stdin, the pane's environment, the captured session id replaced by the launch's), prints the `life` composer pane after the start and each turn, and reads typed lines: the first prompt plays a turn; a line the adapter's `_DOORBELL` matches plays a turn that runs `ao inbox --unread --json` and, per open ask, `ao reply <id> '<the ask's last word>'` (§4.7; where TD-1582 has not landed, the reply road the briefs name then).
- A `life` key in each adapter's `tests/conformance/fixtures/<adapter>/manifest.json`: the indices of the start, turn and end payloads and the composer pane, taken from captured fixtures only (capture more with the walk's `--capture` where the present ones lack a turn or an end).
- `tests/conformance/test_seat_life.py`, parametrized over `agent_adapters()`: the adapter registered built with `binary` set to the stub, on the suite's private tmux socket and scratch home; launch assertions (unattended under `skip`: the unattended arguments; under `all`: `asking_args`; the id or resume; the hook layer exists); an unattended seat with a stub brief asked from a second record with a nonce; states by hook (`idle`, then `working`/`idle` per turn, never `needs-you`); the nonce on the asker's thread; the end payload reported and the record closed once the case closes the seat. An adapter with no `life` fails, never skips.

**Done when:** `test_seat_life.py` passes in CI (`pdm run test`) for Claude Code and Gemini CLI on their captured fixtures, with no model and no network, and a registered agent adapter whose manifest names no `life` fails it.
