**Why:** TD-1984's design (§4.5 screen 12 *Three verbs: Start session*, *Beside another holder*): Paul, 2026-11-18, saw the card around TD-1977 draw no Start session while grinder-ao-2 held the entry, and expects every card of open work to offer one. **Ask:** Should the grinders build Start session on a card whose entry a worker holds, or run one more review round first?

**Location:** design §4.5 screen 12 Three verbs: Start session (Beside another holder); §4.5a Queue card: Start session / Open session; src/shiftlead/ui/queue.py (card_session, item_start, the answered count), src/shiftlead/ui/app.py (/api/ledger/start), src/shiftlead/repoconfig.py (WORK_HELD, work_text), src/shiftlead/ui/templates/queue_card.html, queue_row.html, inbox_row.html; tests/test_queue_start.py, test_queue_kept_start.py, test_queue_start_all.py
