## TD-2151: A test for the memory reading's periodic process walk is missing

**Priority:** Low
**Type:** debt
**Added:** 2026-11-24
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** ff83805c46f2435cbe732b6fa6e4bbb1

**Why:** PR #4484 (TD-2136) makes `_memory_pass` start a walk of `/proc` "also every `LEFT_EVERY`" (src/sessionorc/agent_tick.py, `due = time.monotonic() - self._walk_at >= scratch_mod.LEFT_EVERY`), which is how the holders of a half already low are refreshed with no half turning. No test would catch it going back. Evidence: on origin/main, replacing that `due` expression with `False` leaves all 28 tests in tests/test_memory_low.py passing. The only line that sets `agent._walk_at` back (in `test_a_hung_walk_is_cut_and_no_second_walk_overlaps_it`) asserts that no walk starts while one is running, so it never sees a periodic walk start on an idle agent. `test_a_walk_refreshes_the_holders_of_a_half_already_low` calls `Watch.walked` directly and never the tick's schedule.

**Location:** src/sessionorc/agent_tick.py,tests/test_memory_low.py

**Fix:** Add a test in tests/test_memory_low.py that leaves a half low, the walk idle and `agent._walk_at` older than `LEFT_EVERY`, runs `_memory_pass` with ram above the low line, and asserts one walk started and the half's holders were refreshed; and that with `_walk_at` recent no walk starts.

**Done when:** Replacing the `due` expression in `_memory_pass` with `False` fails a test.
