## TD-2253: Nothing tests that a built-in seat starts from the set of logins its repo picked

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-26
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** c663f9799fd142318e38c20acfb055d5

**Why:** Audit of #4717 (TD-2068 slice 4). Design §4.9d *The login a seat starts on* has a built-in seat start on a login of the set its repo uses. `_builtin_login` (`src/sessionorc/agent_tick.py`) names that repo, `repo = str((self._repos.get(root) or {}).get("name") or Path(root).name)`, and hands it to `builtinstore.seat(doc, repo, key, rows)`.

Every fill test in `tests/test_builtin_fill_login.py` writes a `default` set alone and no repo's pick, so the repo's name is never read to any effect. `tests/test_builtinstore.py` holds `repo_set` itself; nothing holds that the fill asks it about the seat's repo.

With the call changed to `builtinstore.seat(doc, "", key, rows)`, the 47 test modules that mention `cut_over`, `_first_shape_off`, `builtin` or `unfillable` passed at b6f5c8850 (1239 passed), and tests/test_builtin_fill_login.py, test_builtinstore.py, test_teamstore.py and test_team_show.py passed at 28715c324 (122 passed).

Probe (a temporary test: settings with a second set `night` whose list is `[hookstub:second]`, `repos: {repo: {builtins: night}}`, the held record's `repo` set to the checkout, both logins usable): the unchanged code fills the tech lead on `hookstub:second`; with the change it fills it on `hookstub:first`, the `default` set's.

A break would start every repo's built-in seats on the default set's logins and models, whatever the person picked for it.

With that change made together with the other changes that TD-2251 to TD-2255 name, the whole suite at b6f5c8850 (`pytest -n 4`) passed (10259 passed, 24 skipped).

**Location:** tests/test_builtin_fill_login.py; src/sessionorc/agent_tick.py _builtin_login

**Fix:** In tests/test_builtin_fill_login.py, fill a built-in seat of a repo that names a second set, whose list and model differ from `default`'s, and assert the record holds that set's login, model and list.

**Done when:** Passing `builtinstore.seat` no repo name in `_builtin_login` fails a test.
