**Why:** #3041's precheck on 3db8094 (2026-11-06; a change to the decide lift's re-read, nowhere near the witness log) failed `tests/test_witness.py::test_a_press_is_recorded_with_its_repo_and_refused_for_an_unknown_word` at its third press — *no team: the home names the repo*, `recorded` None — with 5129 others passing; the file passes alone. The test registers its repo by writing `agent._repos[root]` straight into the agent's reading (`_registered`), and a press with no team is recorded only when the home finds the directory's repo there; a tick's repo refresh that replaces `_repos` under load drops that entry, so the press reads as in no registered repo. A precheck red for it costs a whole rerun and reads as the PR's fault.

**Fix:** Park the agent's ticks before registering (the `park_ticks` helper tests/test_board.py uses), or register the repo on the home's roster the way a tick reads it, so nothing replaces `_repos` mid-test; then confirm by running the file beside a second full suite.
