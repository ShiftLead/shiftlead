**Location:** design §4.9b *The director works for the person* *Acting by delegation*, *How the person sees the acts*, §4.7, §5, §4.5a; src/shiftlead/, src/shiftlead/briefs/director.md

**Fix:** Build design §4.9b *Acting by delegation* (`merge`) and *How the person sees the acts*, with §4.7 (`ao pr merge`), §5 (`director.delegate`, `director.review`, `director.digest_at`) and §4.5a (the Director card's **delegate** and **review**; the digest row's **Dismiss all**):
- `director.delegate` (a list of `merge`, `direct`; empty by default) and the Director card's two ticks.
- `ao pr merge <repo>#<n> --for person --why "<line>"`: the director seat's alone, under `merge`; the host agent itself runs cadence step 5's line in a detached worktree under `~/.local/share/shiftlead/merges/<repo>/` (the host agent's own, never entered by the director's session) (made at the first merge, moved to the PR's base each time), the squash message ending `Merged-by: director for <person> (merge)`; refused naming why: *not the director*, *merge not delegated*, *gate: FAIL <row>*, *held at its reader*, *held by <session>* (a live session's lease, as on a filing PR a lane took), *the director's own PR*. On success it writes the **act record**: a `note --shows fyi` from the director seat to the person, `--about` the PR (unchecked), its text the act and the `--why`. Only a PR waiting on the person's merge (an interactive session's PR, or a filing PR nobody holds) is in scope; the director judges the merge line's class in its `--why`, the host agent checks the rest.
- `director.review`: `none` (default: the act record alone, under Read), `digest` (also one `note` a day from the director seat, written by the host agent at `director.digest_at` when any act was made since the last, with no `--about` so it draws in the Inbox, *The director acted for you n times*, each act linked; **Dismiss all** dismisses it and each listed act record by `inbox_dismiss`), `each` (the act record drawn under *Needs you* on its card with **Seen**, which dismisses it).
- The director's brief gains the merge line's test and the `--why` it writes.

**Done when:** In a scratch home with a scratch forge repo, the director merges a docs PR at SHIP and green under `merge`, the squash message carrying the `Merged-by:` trailer; each refusal named in the design is raised by a test; each `director.review` value draws as designed, the digest closing on Dismiss all.
