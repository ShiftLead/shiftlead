**Why:** **Why:** `tests/test_stuck.py` fails by itself about one run in ten to one in three, a different test of the TD-1496 section each time. Seen with `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_stuck.py` on origin/main d4a5877b2, the machine under other sessions' test load: 8 runs gave 3 failures, a later 8 gave 3 more, 2 of 30 at lower load; the failed tests were `test_a_line_the_person_is_asked_about_is_muted_and_clocked_from_the_answer`, `test_a_withdrawn_ask_or_a_lapsed_steer_clocks_the_line_from_its_close[withdrawn|expired]`, `test_a_team_held_at_day_reads_that_reason_and_a_line_no_lane_takes_reads_no_lane`, `test_an_answer_while_unread_is_clocked_from_the_first_good_read_and_a_drop_with_it_moves_at_once`, `test_waiting_until_is_served_beside_the_stuck_row_and_never_stored`, `test_the_tick_mutes_on_a_steer_and_a_paused_steer[a-steer-from-anyone]`. Each fails with `KeyError: 'stuck'` or `'stuck_open'` on `home._host_rec`: `_stuck_pass` raised nothing (a traceback print added to its `except` stayed silent) and read no repo `fx`. A single test run alone passed 25 of 25 and 8 of 8 times.

The cause looks like the `home` fixture (`tests/test_stuck.py`, `def home`): it sets `agent._repos = {ROOT: board()}` and pops `stuck`/`stuck_open` in a fixture, before the test body calls `park_ticks(home)`. A tick still running when the fixture sets it can write `_repos` after it (`park_ticks` drains the detached passes, but only after the assignment), so the line's repo is gone. The same module with `_repos` set again right after `park_ticks` failed 0 of 30 runs, against 2 of 30 for the unmodified module in the same period. PRs #3433, #3435 and #3438 added most of the tests that use `home`.

**Fix:** **Fix:** Set `_repos` and clear `stuck`/`stuck_open` after `park_ticks`, not in the sync fixture (an async fixture that parks first, or a helper each test calls after its `park_ticks`). Run the module 30 times under load.

**Done when:** **Done when:** `tests/test_stuck.py` passes 30 runs in a row with the machine loaded.
