## TD-1356: Bump the agent-cadence pin past its TD-206 builds, and AGENTS.md names the board helper and the ledger's edit commands

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-04 (the designer, from TD-1286's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Part of:** TD-1286
**Location:** `docs/cadence.toml` (the `[agent-cadence]` pin); `AGENTS.md` (*Session Hygiene*, *Stack and conventions*)

**Why:** The agent-cadence this repo pins (`docs/cadence.toml`, 9c61e5a) predates agent-cadence#TD-206's builds (#75–#77): its `board_edit.py` has no `add`, `archive`, `fmt` or `list`, and its cadence check has no board row, so a session here cannot add a board line through a helper and nothing holds a PR to it. `AGENTS.md` tells a session to write ledger entries and board items without naming a helper (TD-1286).

**Fix:** As design §4.4 *A session writes the ledger and the board only through the helpers*:
1. `agent-cadence bump` to agent-cadence's main at or after 6894299 (#77), a reviewed PR; read the bump's `cadence-changes.md` and carry what it asks of this repo.
2. In the same PR, `AGENTS.md`'s lines that tell a session to write a board item or change a ledger entry name the commands: `agent-cadence run board_edit.py add --no-commit` for a board line and its `done`, `snooze` or `due` (or `ao board edit done|snooze`; a `decide` or `reply` is the person's) for a change to one; `agent-cadence run ledger.py set|note|edit|archive|reopen|renumber` for a change to an entry. A new entry's command is TD-1360's, which waits on agent-cadence#TD-188.
3. Precheck green on the bumped pin: the board row reads this repo's board.

**Done when:** `docs/cadence.toml` pins agent-cadence at or after 6894299, `agent-cadence run board_edit.py add --help` answers here, and `AGENTS.md` names the helpers wherever it tells a session to write a board line or change an entry.
