## TD-1319: #2797's tests do not pin the branch fetch's three safeguards

**Priority:** medium
**Type:** debt
**Added:** 2026-11-03 (test-audit-ao-1, auditing #2797)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `src/sessionorc/shots.py` (`_fetch_branch`); `tests/test_shots_commit.py`

**Why:** each change was made in a scratch worktree (restored after) and the same four modules still read *99 passed*: removing `"--no-prune",` from the fetch argv; removing `env=env,` (so `GIT_TERMINAL_PROMPT=0` is never set and a fetch may ask for a login on the home's terminal); changing the refspec `+refs/heads/…` to `refs/heads/…` (a force-pushed branch no longer updates the kept ref). The module docstring and `_fetch_branch` state all three. The tests run a fetch against a local bare origin, which succeeds without any of them.

**Fix:** record the argv and env the fetch is run with (monkeypatch `subprocess.run` in `shots`) and assert `--no-prune`, the `+` refspec and `GIT_TERMINAL_PROMPT=0`; or force-push a branch and assert the kept ref follows.
