## TD-1552: A board line whose Context names only a PR draws on that PR's entry's card

**Priority:** Low
**Type:** debt
**Added:** 2026-11-07
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** cfbe5813a94b498f856ea269b7217f24
**Part of:** TD-1538
**Location:** src/shiftlead/ui/queue.py (item_home); src/sessionorc/queue.py (only_pr, pr_card); design §4.5 screen 6 Every item that needs the person draws on a card

**Why:** Design §4.5 screen 6 *Every item that needs the person draws on a card* now says that a board line whose `Context:` names no entry but names a PR (`PR #n` or a bare `#n`, as the board's own Format line writes it) ties by that PR as a mail item's PR does (TD-1538). Today `item_home` reads a board line's `Context:` for entries alone, so such a line that needs the person stays in the Inbox, and TD-1468's Done when asked for a board line tied by its PR that nothing could read.

**Fix:** In `src/shiftlead/ui/queue.py` `item_home`, the board branch: where the line needs the person (`needs`), its `Context:` names no entry (`named` empty) and the `Context:` names a PR, draw it by `pr_card(<the PR>, <the line's repo_name>, index)`, `tied.by: pr`, as the mail branch does with `only_pr`. The PR is the `Context:`'s first match of `(?<![\w./-])#(\d+)\b` (`PR #3142`, `#3142` and `(#3142)` read 3142; `agent-cadence#164`, `owner/name#12`, `a.b#3` and `TD-12` read nothing), its repo the line's `repo_name`; a line with no `repo_name` stays in the Inbox. A helper beside `only_pr` in `src/sessionorc/queue.py` (say `context_pr(text)`) reads the number, so the board's reader and any later caller read it alike. A `Context:` that names an entry keeps today's road (its PRs are words, never a second anchor). The design link (§4.5 screen 6 *An item about a design links the design's PR*) draws nothing for a PR-only line, as for an `about: #n`. A board line never closes `merged`: it leaves the card by its own Done or decide, as today.

**Done when:** Tests in `tests/test_queue_kept_loose.py` (or beside TD-1468's PR-only tests): an undecided `decide` line on a repo's board whose `Context:` is `PR #164` draws on the open card of the entry #164's title names (`tied.by: pr`); with #164 found only in `recent`, the same by its title; with #164 naming no entry, on `loose:<repo>#164`, counted on the Queue tab; the same line with `Context: #164` alike; a line with no `repo_name` stays in the Inbox; a line whose `Context:` is `TD-9 / PR #164` ties by TD-9 as today; `Context: agent-cadence#164` names no PR and stays in the Inbox; a closed (decided) PR-only line stays where it is drawn today; a PR-only `watch` or `fyi` line stays in the Inbox; a PR-only line draws no *· design #n*. The Queue tab and the Inbox tab still add up to what waits on the person.
