## TD-1824: a no-channel tool's subagent-event end could end another child's permission and no test would say so (TD-1817)

**Priority:** Low
**Type:** debt
**Added:** 2026-11-14
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 88f40c02ef934b8483e4ff25c70f436f

**Why:** Found by the test-audit of #3805 (TD-1817, a subagent's event ends a no-channel tool's main-thread permissions). Design §4.2 *A subagent's event, for a tool with no channel* (and the entry's own Fix, item 1) says the new end removes every main-thread permission entry "and nothing else: no question, no subagent's own entry". In `agent_tick._apply_event` the branch is `self._end_entries(s, lambda p: p.subagent is None and p.kind == "permission", sure=False)`. Probe: `p.subagent is None and ` deleted from that lambda; `PYTHONPATH=$PWD/src pdm run pytest -q tests -k "subagent or child or permission or grok"` gives the same result as unmutated (182 passed; the 3 `test_grok_adapter.py` failures are the scratch worktree's unregistered grok entry point, present before the probe). The question half is held (`test_a_childs_event_ends_the_main_thread_permissions_and_restores_kept` fails when `p.kind == "permission"` is dropped), but no test opens a permission of one child (`Pending.subagent` = "c2") and then sends another child's event (`subagent` = "c1"): as written, a child's event could end every other child's open prompt and no test would say so. The same probe class, a smaller one: `PERMISSION_STOPS` gaining a reason (`"end_turn"`) passes, so "any other child `StopCancelled` dropped" is asserted for the one reason the test uses and no more.

**Location:** tests/test_permission_channel.py

**Fix:** Add to `tests/test_permission_channel.py` (beside the TD-1817 cases): a no-channel session with a permission pushed from child "c2" (`{"state": "needs-you", "pending": {...}, "subagent": "c2"}`), then `CHILD_POST` from "c1": c2's entry still stands, the state `needs-you`. And in `tests/test_grok_hook.py`, parametrise the child `StopCancelled` drop over a reason that is not a permission's (`end_turn`, `cancelled`) as well as the one it has. Re-run the probes: each must fail.

**Done when:** Removing `p.subagent is None and ` from the lambda in `agent_tick._apply_event`'s no-channel end, and adding `"end_turn"` to `PERMISSION_STOPS`, each fails a test.
