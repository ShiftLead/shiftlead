**Why:** Audit of #3701 (TD-1761 slice 1). Mutations in `AO.qDiff` in `src/shiftlead/ui/static/app.js`, each run with `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_ui_holds_still.py` (16 passed every time): (1) `(r.group === "completed" && d.group !== "completed")` → `(r.group === "completed")` — a card already in Recently completed in both copies would count *done* on every re-read; (2) `if (!hidden(d) && !askCards.has(id)) out.done++;` with `!askCards.has(id)` dropped — a card that left and also carries a new ask counts twice, against the doc comment *each card counted once, in the first part it fits*; (3) the same line with `!hidden(d)` dropped — a card the picks hide counts *done* when it leaves; (4) `&& r.group !== "completed"` dropped from the `out.new++` line — a card arriving straight in Recently completed counts *new*; (5) `|| hidden(d) !== hidden(r) ||` dropped from the `out.moved++` line and (6) `d.group !== r.group ||` dropped — a card the picks reveal, or one that changed group, is not counted moved; (7) the `ks.some((k) => !mine.includes(k))` line and (8) the `common.join(" ") !== was.join(" ")` line dropped — a row arriving in, or reordered inside, a card is not a place change; (9) `if (hidden(r) && (!d || hidden(d))) return;` dropped from the asks pass — asks on a card the picks hide count; (10) `!own(k) &&` dropped from the asks count — the person's own answer counts as a new ask. `tests/test_ui_holds_still.py` names each rule in a test (`test_a_card_gone_to_recently_completed_is_done`, `test_a_place_change_inside_a_card_is_moved`, `test_a_card_the_picks_hide_or_a_folded_group_holds_counts_nothing`) but its cases `completed`, `inside`, `picks`, `folded` are each one direction of the rule: `inside` has *both* a row reordered and one arriving in the same card, `picks` moves a card that is hidden in both copies, and no case has a card hidden in one copy only, a card that leaves carrying a new ask, or a card arriving in `completed`. The bar's counts are what the person reads to decide whether to Refresh, so a wrong count is wrong silently.

**Fix:** Add one case per mutation to the `CASES` of `tests/test_ui_holds_still.py` (each a one-line `diff(...)` over `base()`) and a test beside the existing ones: a card in `completed` in both copies counts nothing; a card that leaves with a new ask in the reading counts in *asks* only; a card the picks hide that leaves counts nothing; a card arriving in `completed` is not *new*; a card hidden in one copy only, and one that changed group with no other change, are *moved*; a row arriving, and a row reordered, each alone in its card, are *moved*; new asks on a hidden card and on the person's own press count nothing. Run the ten mutations above against the new cases.

**Done when:** Each of the ten mutations above fails a test in `tests/test_ui_holds_still.py`.
