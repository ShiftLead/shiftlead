  - `agent-cadence run ledger.py edit TD-n --section "Event (<name>)" --from <file>`.   - **The name is never reused**, since a lift leaves its section in the file:
    - `live` for the first gate;
    - `live-2`, `live-3`, … for a later PR of the build merged after a gate was written (a review fix), which adds its own;
    - `live-td<m>` for a fix entry TD-m that a failed live check is `Blocked by:` (written as below).
- **The brief's rules for a live check**:
  - **The builder of a fix**: the PR that archives the fix entry TD-m (its last build's) adds `event (live-td<m>)` (section and gate, as above) to each open live check `Blocked by:` TD-m, and appends its own PR to that check's `Kind:` line (`ledger.py set --kind "live-check #<old> #<this>"`) in a commit after the PR is opened, since the number is the forge's (cadence §2.8).
  - It is picked when pickable, with its gate lifted, not by `live: yes`.
  - A grinder that claims one and finds its build not live (a rollback after the lift) adds a fresh gate by the naming rule and ends its claim.
  - A `pr:<n>` order for a home's `lift/TD-n/live…` PR: run its precheck, re-run the check against `promote/live` as it stands (never the evidence's sha), and merge on the cadence.
    - A re-run that reads *not yet* (a rollback since the sweep, or a moved tag): never merge it. In a PR of its own, write a fresh gate by the naming rule in place of the lift's (its section added, the lift's gate dropped from `**Blocked by:**`), merge that on the cadence, then close the lift PR unmerged with a comment naming it (design §4.9b). The event runner then asks nothing about the closed lift.
  - The names `live`, `live-<digits>` and `live-td<digits>` are these gates' alone; no other event gate takes them.
  - No session pushes `promote/live`.
- **The open live checks** (one ledger PR, through the helpers): write the gate as above on every open live check that has none, whatever its *not live* reading says. A gate on a build already live lifts at the first sweep after this migration PR is itself live, and none can become pickable early when TD-1452 drops the reading. List the moved entries in the PR body.
