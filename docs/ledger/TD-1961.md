## TD-1961: Nothing in ShiftLead's cadence settings names the files whose designs the person decides

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-19
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 3df7631a412e4f3cb11e3e8143ac9051
**Blocked by:** decision (paul)

**Why:** The cadence lets a repo name its far-reaching files in a `[far-reaching]` table of `docs/cadence.toml`: a design whose builds change a matching file is far-reaching whatever its author's mark, and the cadence check's `reach` row holds such a build until a person's Go is recorded (design §4.9c *What ends a design's rounds, and what is far-reaching*). That passage says this repo's file has no such table yet, so today only a design's own mark makes it far-reaching. First filed as a part of TD-1911 (the techlead as judge of a design's verdict), which the Flows design rejects and which was dropped on 2026-11-25; the table stands without it, since under a flow the `reach` row is one only a person can cure.

**Ask:** Should the grinders add the table that names the files whose designs always come to you?

**Location:** docs/cadence.toml; design §4.9c *What ends a design's rounds, and what is far-reaching*

**Fix:** Add `[far-reaching]` to `docs/cadence.toml` with `paths` for what every session reads and what says who acts: `docs/briefs/**`, `src/shiftlead/briefs/**`, `src/shiftlead/flows/**`, `src/shiftlead/flows3/**`, `docs/glossary.md`, `src/shiftlead/org.py`, `src/shiftlead/orgcheck.py`, `src/shiftlead/flowdefs.py`, and a `note` pointing at §4.9c *What ends a design's rounds, and what is far-reaching*. Check each path exists at the build's head; where one has moved or gone (the first shape's files go with TD-2056), use its new place or leave it out and say so in the PR. Update that passage's sentence that the repo has no table.

**Done when:** `agent-cadence run cadence_config.py --check` passes and `cadence_config.far_reaching([("docs/cadence.toml", <the parsed file>)])["paths"]` is the table's paths; a test reads the table and asserts each of its globs matches at least one file of `git ls-files` under `fnmatch.fnmatch`, as the cadence's `reach` row matches, so a renamed path fails it; design §4.9c no longer says the repo has no table.
