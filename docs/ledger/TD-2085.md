## TD-2085: A stage session on a node cannot end its stage, because the home cannot read its worktree

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** d0bfc3cdcad84b23a7e9067d1f50c873
**Part of:** TD-1954

**Why:** A stage session running on a node cannot end its stage: the home checks each outcome by reading the session's worktree, which is on the node, so the call is refused there. Format-3 flows run nowhere yet, so nothing is stopped today, but a team on a node could not use one.

**Fix:** Have the home read the branch, head and fetched head of a node session's worktree over the link (as the host_files reads do), or have the node answer those three facts, and remove the refusal in the stage_end call.

**Done when:** A stage session on a node ends its stage with each outcome checked against its own worktree, and a test covers it.
