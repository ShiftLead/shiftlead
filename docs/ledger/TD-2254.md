## TD-2254: Nothing tests which seats are given a login at a fill, or which refusal an ended one shows

**Owner:** grinder
**Kind:** build
**Status:** Open

**Why:** Audit of #4717 (TD-2068 slice 4). `_on_set_login` (`src/sessionorc/agent_tick.py`) says which fills pick a login: `bool(self._first_shape_off and BUILTIN_SEAT_KEYS.get(str(s.builtin or "")) and here)`, so only after the cut-over, only a built-in seat's record, and only on the home's own host; a seat on a node is launched as before until the node half. `_seat_pass` reads an ended seat's login, due or not, only where `_unfillable_word` found no refusal: `if ended and not self._unfillable_word(s, now) and self._on_set_login(s) and not s.seat_due:`.

`tests/test_builtin_fill_login.py` holds the cut-over condition. Each change below, made alone, left the 47 test modules that mention `cut_over`, `builtin` or `unfillable` green at b6f5c8850 (1239 passed), and tests/test_builtin_fill_login.py, test_builtinstore.py, test_teamstore.py and test_team_show.py green at 28715c324 (122 passed):

- `and here` removed from `_on_set_login`;
- the built-in condition removed from it (`return bool(self._first_shape_off and here)`);
- `_seat_pass` calling `_unfillable_word` and then reading the login whatever it returned (`self._unfillable_word(s, now) if ended else None`, then `if ended and self._on_set_login(s) and not s.seat_due:`).

Probes (temporary tests over the module's fixtures), each passing on the unchanged code:

- a built-in record with `host` set to a node: `_builtin_login` answers `{}`; without `and here` it answers a login of the home's;
- a record with no `builtin`: `_builtin_login` answers `{}`; without the built-in condition it raises `KeyError: 'None'`, which would break rule 3's pass for every ordinary seat after the cut-over;
- an ended, not due tech lead at its fill ceiling, whose set cannot run it: `unfillable` reads *fill ceiling*; with the third change it reads *cannot run*.

With the three made together (the two to `_on_set_login` as `return bool(self._first_shape_off)`) with the other changes that TD-2251 to TD-2255 name, the whole suite at b6f5c8850 (`pytest -n 4`) passed (10259 passed, 24 skipped).

**Location:** tests/test_builtin_fill_login.py; src/sessionorc/agent_tick.py _on_set_login, _seat_pass

**Fix:** In tests/test_builtin_fill_login.py: after the cut-over, fill an ordinary seat (no `builtin`) and assert it is launched as before; read a built-in seat's record on a node and assert no login is picked; run the seat pass on an ended built-in seat at its fill or restart ceiling whose set cannot run it, and assert `unfillable` keeps the ceiling's word.

**Done when:** Each of the three changes fails a test.
