## TD-1279: No test holds the Focus pane's release wiring for Copy's edge note: which row the edge must touch, the copy-on-select-off toast, or the Shift press

**Priority:** Medium
**Type:** debt
**Added:** 2026-10-30 (test-audit-ao-1, auditing the last ten merged PRs)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `src/shiftlead/ui/static/app.js` (the Focus terminal's `mousedown` and `mouseup` listeners that call `AO.edgeMark`, `copySel(edge)`); `tests/test_ui_focus_copy.py`, `tests/test_ui.py::test_a_copy_on_release_says_so_with_copys_own_toast`

**Why:** #2734 (TD-1267) put three decisions in listener code that no test runs. `tests/test_ui_focus_copy.py` drives only the pure functions (`AO.pastEdge`, `AO.edgeMark`, `AO.copyNote`, `AO.copyWith`), and `test_a_copy_on_release_says_so_with_copys_own_toast` only checks the release's source text for `"copySel(edge)"` and `AO.copyWith(`. Probes at `origin/main` 345260f67, each edit made alone, restored after, then `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_ui_focus_copy.py tests/test_ui.py -k "copy or release or toast"` gives `7 passed` every time:
- the edge only counts when the selection touches that row, `(up.fire === "top" ? pos.start.y === 0 : up.fire === "bottom" && pos.end.y === term.rows - 1)` replaced by `(up.fire)`: a drag that crossed an edge but left the selection short of it then draws *the selection stops at the screen's edge* wrongly (design §4.6 *A selection is one screen*);
- the `else if (edge) AO.toast(AO.copyNote(…))` branch, the edge's note when copy on select is off or disabled, deleted;
- `shift: e.shiftKey || e.button !== 0` in the `mousedown` listener replaced by `shift: false`: a Shift press or a non-primary button then starts a drag and can draw the edge note.

**Fix:** extract the release's decision (`up.fire`, the selection position, `rows`, whether copy on select is on) to a pure function on `AO`, as `AO.copyWith` is, and probe it under node in `tests/test_ui_focus_copy.py`; or run the three listeners against a stub terminal there. Cover the three cases above.

**Done when:** each of the three edits above fails a test.
