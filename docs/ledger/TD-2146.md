**Why:** Part of TD-2129 (design §4.6 *Where a session's working files go*). Earlier sessions left files in `~/.cache`, `/var/tmp` and `~/ao-shots`. ShiftLead did not make those paths its own, so nothing removes them by rule: the person sees one list and answers.

**Location:** docs/leftovers, design §4.6

**Fix:** On kmaster, read-only, list the direct children of `~/.cache`, `/var/tmp` and `~/ao-shots` owned by this uid. For each: its size; its newest write, the newest modification time under it by a walk bounded at 60 seconds an entry; whether it is a symlink (never followed); and, for a directory that is a git worktree or clone, its origin (or *none*), its branch, its uncommitted count (`git status --porcelain` lines) and its unpushed count (`git rev-list --count HEAD --not --remotes`). Sort each into the first group it fits, a name shape being a prefix of the name:
- **Kept, by name:** a tool's own cache in `~/.cache`: `agent-cadence`, `claude`, `claude-cli-nodejs`, `copilot`, `dconf`, `evolution`, `event-sound-cache*`, `fontconfig`, `google-chrome-for-testing-headless`, `gstreamer-1.0`, `helm`, `huggingface`, `ibus`, `ibus-table`, `mesa_shader_cache`, `mesa_shader_cache_db`, `Microsoft`, `motd.legal-displayed`, `mozilla`, `ms-playwright`, `node-compile-cache`, `node-gyp`, `pdm`, `pip`, `pnpm`, `pyright-python`, `qdtools`, `samscrape-precheck`, `tracker3`, `ubuntu-report`, `update-manager-core`, `virtualenv`; `~/ao-shots/pwlib`; `/var/tmp/pc.*`.
- **Kept, by state:** anything written in the last 3 days or whose walk was cut short, held by a process (`/proc/<pid>/` cwd, root, exe, maps or fds), named by a current brief or memory (a literal `grep -rF` of its name over `src/shiftlead/briefs/`, `docs/briefs/` and `docs/claude-memory/`), a registered git worktree with an uncommitted count above zero, or a symlink whose target lies in a live record's scratch.
- **Needs your word:** a git clone that is not a registered worktree, with an uncommitted or unpushed count above zero or a count that cannot be read (shown *unreadable*: an unborn `HEAD`, no remotes). Its commits live nowhere else, so it goes only where the person's note names it.
- **Proposed for removal:** in `~/.cache`, every loose file or symlink not kept, and a directory whose name starts `ao`, `aw`, `rv`, `rev`, `td`, `tl`, `inb`, `sent`, `tmp.`, `pct`, `dpr`, `pr`, `log`, or a letter and a digit (`g1`, `r10s`); in `/var/tmp` and `~/ao-shots`, every entry not kept, `~/ao-shots/scripts/` included, since the scripts there are one-off.
- **Unsure:** any other directory in `~/.cache`. It is kept unless the person's note names it.

A registered worktree with no uncommitted changes is proposed whatever its unpushed count, since its commits stay on its branch in its repo once the worktree goes; the list says so beside it. The repository is public, so `docs/leftovers/TD-2146.md` holds the proposed and needs-your-word groups by name, each with its size, its newest write, *link* for a symlink (never its target), and for a git tree its branch and counts where its origin is a public repository, else *a git tree of another repo*; the kept groups and the unsure are counts alone. The full list, unsure names included, goes in this run's scratch at a path the board item names, readable on kmaster. A PR of `docs/leftovers/` alone runs the full precheck, which is accepted.

In the same PR, gate TD-2147 on the person: `ledger.py set TD-2147 --blocked-by "decision (paul)" --ask <file> --answers '…' --lifts '…'`, which replaces its `TD-2146` block, the Ask file one plain sentence of at most 25 words ending in `?`. Add its `decide` item on the board with Context `TD-2147 decision (paul)`, `--default 0` (the board's answers carry no `(default)` mark, which only the ledger's `--answers` takes), a `--detail` carrying `context`, `question` and `recommended` (the first answer) and naming the committed list, the full list's path, each group's count and size, and every needs-your-word entry by name, and the answers *Remove the proposed (default) — a session removes the proposed group and keeps the rest*, *Remove with changes: <note> — a session removes the proposed group, less what your note keeps and plus any unsure or needs-your-word entry it names*, *Keep all — a session removes nothing and closes the entry*, all three in `--lift`, since each ends the wait.
