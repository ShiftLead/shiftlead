## TD-1795: ao feedback intake: parse the open feedback report issues into their fixed fields, refusing malformed ones

**Priority:** low
**Type:** feature
**Added:** 2026-11-13
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** f028a54f85574a7bbbfbfa5fa2159e3a
**Blocked by:** TD-1794
**Part of:** TD-1718

**Why:** TD-1718's design: a file-mode run of `/shiftlead-feedback` at shiftlead's home reads the open feedback reports beside its seats. The reports are strangers' text on a public repo, so they are parsed by code into the fixed fields, never read loose by the session.

**Location:** design §4.7 Feedback (Reports from other installs); src/shiftlead/feedback*.py, cli.py

**Fix:** Build `ao feedback intake --issues <file> [--json]` on TD-1794's `shiftlead.feedback_report` rules, as design §4.7 *Feedback*, *Reports from other installs*, bullet *The intake, in file mode*, says: read the saved `gh issue list --json number,title,body,author,createdAt` list (oldest first); keep titles that open `feedback report: `; from each body take the first fenced `json` block after the `<!-- shiftlead-feedback-report v1 -->` marker; apply the shared rules, cutting a report to its first 50 findings, a count over 999 to 999 and `what`/`fix` to 300 characters, `commit` 7 to 40 hex digits or `null`; run the scrub's pattern pass over `what`/`fix`, line breaks made spaces and control characters dropped; refuse, naming the issue and why, no marker, a block that does not parse, an unknown `v`, or a field that breaks a rule; derive each report's build day from `commit` in shiftlead's clone (`git log -1 --format=%cs`, only where `git merge-base --is-ancestor <commit> origin/main` holds; else *build unknown*), never from the report's `build_day`. Prints `{reports: [{number, login, created_at, commit, build_day, days, seats, noise, new, known, cut}], refused: [{number, login, created_at, why}], limit_reached}`, `login` the author's login alone, `limit_reached` when the list held 100. Tests: a report TD-1794's `ao feedback report` wrote parses back to its findings; an issue form's body (`### <label>`, a blank line, the pasted text) parses; each refusal; a 60-finding report is cut to 50, a count of 5000 to 999, both named in `cut`; a foreign URL in a hand-written report's `what` becomes `<url>`; a commit on `origin/main` gives its day, one off it and `null` give *build unknown*; a field the report does not define is dropped; the author's `name` is never printed.

**Done when:** Done when `ao feedback intake` parses reports as the design gives it, round-trips a report `ao feedback report` wrote, and refuses each malformed kind by issue number, with tests for each.
