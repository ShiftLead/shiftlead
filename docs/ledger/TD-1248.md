**Why:** design §4.9 *The Sessions page* (*The repo's line*: *the compact facet*), §4.5a rows *team card: Repo facet*, *Repo page, team card: Repo facet → Add entry…* and *Sessions: repo line* (TD-1240; Paul, 2026-10-30: *Yes, as drawn: two rows, no-team repos too, no selector*). Today a Sessions repo line whose team cards are all folded, or a repo with no team, draws the whole Repo facet (two bars, legend, selector, PR blocks), so folding a team makes the page longer.

**Fix:**
1. On the Sessions page the repo line draws the compact facet, a block of its own beside the `.rsum` (which keeps `repo_facet.html` whole, Fix 4): row **Technical debt** — *n open*, then *n high · n medium · n low* each after a small square in the facet's priority hue (a priority at 0 not drawn), the lanes *i* (the repo's, one line per servicing team) where a team services the repo, and **Add entry…** (the facet's own form, the repo filled); row **Pull requests** — *n open*, *· n red* in red where any open PR reads red or conflicting and *· n CI never ran* where any never ran (`p.not_run`), each with the facet's hover, *· oldest <age>* where any is open, *· n waiting on review* where any waits, *· read <age> ago* — the whole facet's order (`repo_facet.html` ~:32, ~:42). Every figure is already in `g.facet` (`org.py` `repo_facet` ~:234; `_bars` already drops a priority at 0).
2. Each figure is a link to the Repo page's list filtered to it, as the facet's segments are; a failed reading reads *could not look*, dimmed, the error on hover.
3. No bars, legend, *open · day · week · month* selector or window picker on the compact line; the compact form carries no `data-team`; the whole form keeps its own (`repo:<name>`) for the Repo page.
4. The line carries both forms, since `repo_line.html` is rendered from the `org_layout` item alone, the same for both pages, at load and on every delta (`app.py` ~:857), with no page flag: the whole facet (`.rsum`, as today) and the compact one, in its own class, matched by neither `.rsum` nor `facet frepo`. CSS hides the whole outside `.repopage` (`repo.html` ~:10) and the compact inside it. `syncLineFacets` (`app.js` ~:2391) sets `hidden` on the compact element in place of `.rsum`, by `AO.lineFacetShown` as today (no team, or every team card folded, hidden by the filter or drawing no summary), and the compact class has a `[hidden] { display: none }` rule beside `#groups > .rline .tsum.rsum[hidden]` (`app.css` ~:695), since its own `display` would override the attribute.
5. Narrow (the 400 px shot): a row wraps its figures under its label.
