## TD-1248: A Sessions repo line under folded team cards draws the compact facet, two rows with Add entry…, in place of the whole Repo facet

**Priority:** Medium
**Type:** debt
**Added:** 2026-10-30 (the designer, from TD-1240's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Part of:** TD-1240
**Location:** `src/shiftlead/ui/templates/repo_line.html` (includes `repo_facet.html` whole, in `.rsum`); `src/shiftlead/ui/templates/repo_facet.html` (the figures, the lanes *i*, **Add entry…**, the PR hover); `src/shiftlead/ui/static/app.js` (`AO.lineFacetShown` ~:2388, the `.rsum` show/hide ~:2395); `src/shiftlead/ui/static/app.css`; mockup `docs/mockups/reviews/2026-10-30-td1240-td1240-{1600,400}.png` (source `docs/mockups/reviews/td1240-src/td1240_shots.py`)

**Why:** design §4.9 *The Sessions page* (*The repo's line*: *the compact facet*), §4.5a rows *team card: Repo facet*, *Repo page, team card: Repo facet → Add entry…* and *Sessions: repo line* (TD-1240; Paul, 2026-10-30: *Yes, as drawn: two rows, no-team repos too, no selector*). Today a Sessions repo line whose team cards are all folded, or a repo with no team, draws the whole Repo facet (two bars, legend, selector, PR blocks), so folding a team makes the page longer.

**Fix:**
1. On the Sessions page the repo line's `.rsum` draws the compact facet in place of `repo_facet.html`: row **Technical debt** — *n open*, then *n high · n medium · n low* each after a small square in the facet's priority hue (a priority at 0 not drawn), the lanes *i* (the repo's, one line per servicing team) where a team services the repo, and **Add entry…** (the facet's own form, the repo filled); row **Pull requests** — *n open*, *· n red* in red where any open PR reads red or conflicting and *· n CI never ran* where any never ran (`p.not_run`), each with the facet's hover, *· oldest <age>* where any is open, *· n waiting on review* where any waits, *· read <age> ago* — the whole facet's order (`repo_facet.html` ~:32, ~:42). Every figure is already in `g.facet` (`org.py` `repo_facet` ~:234; `_bars` already drops a priority at 0).
2. Each figure is a link to the Repo page's list filtered to it, as the facet's segments are; a failed reading reads *could not look*, dimmed, the error on hover.
3. No bars, legend, *open · day · week · month* selector or window picker on the compact line; the `data-team="repo:<name>"` selector memory goes with them.
4. The line carries both forms, since `repo_line.html` is rendered from the `org_layout` item alone, the same for both pages, at load and on every delta (`app.py` ~:857), with no page flag: the whole facet (`.rsum`, as today) and the compact one, in its own class (not `facet frepo`). CSS under `.repopage` shows the whole and hides the compact; on the Sessions page the whole is never shown, and the compact is shown by `AO.lineFacetShown` as the `.rsum` is today (no team, or every team card folded, hidden by the filter or drawing no summary).
5. Narrow (the 400 px shot): a row wraps its figures under its label.

**Done when:** the tests the change breaks are updated to it — `tests/test_ui_org_layout.py` ~:102–121 and ~:174–182 (the line's facet counted, `count('class="facet frepo"')`), `tests/test_ui_card_repo_facet.py` ~:63–68 (`data-team="repo:main"`), and the `repo_line.html` header comment; a render test of a repo line finds the compact form's two rows, the priority figures, **Add entry…** and the PR figures, and no bars and no selector in the compact form; the node probe in `tests/test_ui_card_repo_facet.py` ~:38–49 shows the compact form by the fold rule (the fold is the client's: the server renders the same line folded or not) and never the whole on the Sessions page; the Repo page's line still draws the whole facet; the team card's facet is unchanged; a headless shot at 1600 and 400 px matches the mockup's shape; `pdm run test` and `pdm run lint` pass.
