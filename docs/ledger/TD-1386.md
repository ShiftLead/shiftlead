## TD-1386: The home's witness log: `witnessed/<month>.jsonl`, its kinds, and the three writers (precheck-fail, press, msg)

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-04 (the designer, from TD-1295's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Part of:** TD-1295
**Location:** new `src/sessionorc/witness.py` (`KINDS`, the press words, `append`, `prune`, `WITNESS_KEEP_MONTHS`); `src/sessionorc/paths.py` (`witnessed/`); `src/sessionorc/promote.py` (`precheck_on_main`'s status pass) and `src/sessionorc/reports.py` (the open-PR read, `OPEN_PR_FIELDS`); `src/sessionorc/agent.py` (`rpc_witness_press`), `src/sessionorc/modes.py` (`HOME_EDITS`), `src/sessionorc/mail.py` (`PERSON_ONLY`), `tests/test_person_only.py`; the press sites: `src/shiftlead/teamrun.py` (`apply`, `start`), `src/shiftlead/cli.py` (`ao host rebuild`), Send to reviewer and push on's callers in `src/shiftlead/ui/app.py`; `src/sessionorc/agent_mail.py` (`_msg`, `_system_note`); the tick (`agent_tick.py`, the monthly prune); `agent_common.BACKUP_MEMBERS`; design §4.4 *The home keeps a log of what it witnesses*

**Why:** TD-1295's design: a wait on an event the home sees is answered by a count of what the home witnessed, and the home keeps no such record today — mail is pruned 12 h after it is read, a press leaves only a `log.info` line, and a precheck's failure only a forge status.

**Fix:** as design §4.4 *The home keeps a log of what it witnesses* says: the log (one line a record, `{id, at, kind, repo, text}`, `id` `w-<YYYYMMDDTHHMMSSZ>-<4 hex>`, filed in the UTC month of `at`, append-only, read sorted by `at`; `witnessed/start` written once by the first append, nothing dated before it written), one entry point `witness.append` on the agent's loop (a detached writer hands its record over), `KINDS` with each kind's text shape and declared class (all three `public`), and the three writers:
- `precheck-fail`: where the home reads a head's `cadence/precheck` (main's in `precheck_on_main`'s pass; an open PR's in the open-PR read) and finds it changed (a new head; the rollup context's state or `startedAt`/`createdAt` moved), read `commits/<sha>/statuses` and record each `failure` or `error` not yet recorded and created at or after `start`, `at` the status's `created_at`, `status <id>` in the text; the seen set rebuilt at the agent's start from this month's file and the last; `FAILED <id>` node ids only on the status the home's own main run set (matched by `precheck.json`'s sha and the status's `target_url` or time), none otherwise;
- `press` through the new person-only home edit `witness_press {word, target, repo}` (`HOME_EDITS`, `mail.PERSON_ONLY` and the person-only test's list; refused from a node by `PERSON_NODE_BOUND`), sent after success by `teamrun.apply` (when it applied anything) and `teamrun.start` — so the team card's routes and `ao team flow --apply`/`ao team start` alike, a Start that applies first recording `apply` then `start` — by `ao host rebuild`, Send to reviewer and push on; the UI process as the person, the CLI with its own identity, swallowing a refusal; a word not in the table refused;
- `msg` in `_msg` and in `_system_note`: the header alone, never the body, `repo` from the sending session's record (empty for a system note), `team` in the text where the entry carries one.
The prune on the first tick of each UTC month, `WITNESS_KEEP_MONTHS` 13; `witnessed/` in `BACKUP_MEMBERS`. A writer's failure is a log line and never fails the act it records.

**Done when:** tests that each writer appends its record with the text shape the design gives (`FAILED` ids on the home's own main run's status only, none on a PR's; a body never carried; a system note recorded through `_system_note`); that a head whose status list holds fail, pass, fail writes two records dated by the statuses' `created_at`, a red re-run green between two readings still one, a re-read of an unchanged status none, a status from before `start` none, and an agent restart none twice; that an `error` status counts as red; that `ao team start` applying a changed definition writes `apply` then `start`, as the card's Start does; that `witness_press` is refused to a session (the CLI going on) and for an unknown word, and that a failed Apply sends none; that a record from a detached writer lands whole beside one from the loop; that a late record goes in its own month's file and reads in `at` order; that the prune keeps thirteen months; and that a writer's failure leaves its act standing.

**Related:** TD-1295 (the design); TD-1387 (the query); TD-1388 (the check); the ask that agent-cadence's `precheck.py` put the `FAILED` node ids in its red status's description, carried by the techlead (m-8e4a849462ee), until which a PR's `precheck-fail` names no test.
