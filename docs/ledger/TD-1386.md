## TD-1386: The home's witness log: `witnessed/<month>.jsonl`, its kinds, and the three writers (precheck-fail, press, msg)

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-04 (the designer, from TD-1295's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Part of:** TD-1295
**Location:** new `src/sessionorc/witness.py` (`KINDS`, the press words, `append`, `prune`, `WITNESS_KEEP_MONTHS`); `src/sessionorc/paths.py` (the `witnessed/` dir); `src/sessionorc/promote.py` (`precheck_on_main`'s pass that sets `precheck_failed`) and `src/sessionorc/reports.py` (the open-PR read, `OPEN_PR_FIELDS`, each row's `failing`); `src/sessionorc/agent.py` (`rpc_witness_press`), `src/sessionorc/modes.py` (`HOME_EDITS`); the press sites: `src/shiftlead/ui/app.py` (the team Apply and Start routes, `api_team_flow_apply`; Send to reviewer), `src/shiftlead/cli.py` (`ao host rebuild`), push on (`push_subscribe`'s caller); `src/sessionorc/agent_mail.py` (`_msg` and `_system_note`); the tick (`agent_tick.py`, the monthly prune); `agent_common.BACKUP_MEMBERS`; design §4.4 *The home keeps a log of what it witnesses*

**Why:** TD-1295's design: a wait on an event the home sees is answered by a count of what the home witnessed, and the home keeps no such record today — mail is pruned 12 h after it is read, a press leaves only a `log.info` line, and a precheck's failure only a forge status.

**Fix:** as design §4.4 *The home keeps a log of what it witnesses* says: the log (one line a record, `{at, kind, repo, text}`, one append-only file per UTC month, written by the agent process alone; an unreadable line skipped), `KINDS` with each kind's text shape, and the three writers:
- `precheck-fail` where the home reads a `cadence/precheck` status as `failure` — main's head in `precheck_on_main`'s `precheck_failed` pass, with the `FAILED <id>` pytest node ids its log names; an open PR's head in the open-PR read, its description in their place — once per repo, PR or `main`, sha, the dedupe read from this month's file and the last;
- `press` through the new person-only home edit `witness_press {word, target, repo}` (`HOME_EDITS`, refused to a session caller), sent after the act succeeds by each place that composes a press: the team card's Apply and Start routes, `ao host rebuild` run by the person, Send to reviewer, push on; a word not in the table refused;
- `msg` in `_msg` and in `_system_note`: the header alone, never the body, `repo` from the sending session's record (empty for a system note), `team` in the text where the entry carries one.
The prune on the first tick of each UTC month, `WITNESS_KEEP_MONTHS` 13; `witnessed/` in `BACKUP_MEMBERS`. A writer's failure is a log line and never fails the act it records.

**Done when:** tests that each writer appends its record with the text shape the design gives (a `FAILED` id carried for main's run, a PR's status description for a PR, a body never carried, a system note recorded through `_system_note`), that `precheck-fail` is written once per sha however often the reading sees it, that `witness_press` is refused to a session and refused for an unknown word and that a failed Apply sends none, that the prune keeps thirteen months, and that a writer's failure leaves its act standing.

**Related:** TD-1295 (the design); TD-1387 (the query); TD-1388 (the check).
