**Why:** TD-1527's design (§4.9c *The designer writes the synopsis*): every design PR writes the design's synopsis, `docs/synopses/TD-<design>.md`, in a fixed shape and a plain-words writing rule; the designer briefs must say so, the directory needs its README, and a test must hold every synopsis to the shape and the rule.

**Fix:** Build §4.9c *The designer writes the synopsis*:
- **The briefs.** The designer briefs — `docs/briefs/designer-ao-1.md` (this repo's part, a held path) and the packaged `src/shiftlead/briefs/designer.md` (the template) — gain the step: every design PR writes `docs/synopses/TD-<design>.md` (the first round's PR makes it; each later round's, a bought round's or a `Hold` revision's among them, rewrites it whole, present tense), last, after the round's fixes, so the closing fact-check reads it with the diff and checks that it says nothing the design does not and leaves out none of the choices the person would weigh. The briefs name the shape and the rule by pointing at `docs/synopses/README.md`, never by copying it.
- **`docs/synopses/README.md`**: the shape (a `# TD-<n>: <title>` heading; `## What it does`, `## The key choices, and why`, `## What it rules out`, `## What you will see`, in that order; about 40 lines at most) and the writing rule (§4.10 *How a message to a person is written*: plain words; no finding id `F<n>`, no function, file, path or line reference, no backticks; a ledger id only for other work the person knows by it), with Paul's TD-1476 example of the level, as §4.9c gives it.
- **The test** (`tests/test_synopses.py`): every `docs/synopses/TD-<n>.md` other than the README has the heading and the four sections in order, at most 40 non-blank lines, no `F<digits>` word, no backtick, no `.py`, and no `:<digits>` after a path-like word; a file named for an id the ledger does not hold (open or archived) fails. `docs/synopses/TD-1527.md`, written by the design PR, passes it.

**Done when:** Both designer briefs carry the synopsis step; `docs/synopses/README.md` states the shape and the writing rule; `tests/test_synopses.py` holds every synopsis to them and passes.
