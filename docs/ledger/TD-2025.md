**Owner:** designer
**Kind:** design-first
**Status:** Open

**Why:** Found auditing #4268 against design §5 and §4.9b. §5's `org.yml` example reads `director: {profile: grind, brief: docs/briefs/director.md}`, a path that reads as relative to a repo checkout. `src/shiftlead/teams.py` (#4268) reads a relative `director.brief` beside the org file (`Path(d.brief).expanduser()`, resolved against the org file; its test `test_a_brief_the_org_names_is_read_beside_the_org_file`), so that example would be looked for under `~/.shiftlead/docs/briefs/` and not found. Neither §5 nor §4.9b (*The director seat*, which says only "the package's `director.md`") names the base, or says that `director.brief` may override the package brief at all. The techlead's note on #4268 (TD-642's log, 2026-11-20) names the same mismatch, but no entry holds it.

**Location:** design §5 org.yml director:, §4.9b The director seat; src/shiftlead/teams.py

**Fix:** Decide which is true and write it: either §5's example and §4.9b say a relative `director.brief` is read beside `org.yml` (and the example names a path that is), or the code reads it from a repo checkout. Then say in §4.9b that `director.brief` replaces the package's `director.md`, with its `{org}` slot. A design change first, its dated line to `docs/history/TD-2025.md`.

**Done when:** §5's `director:` example and §4.9b name the base a relative `director.brief` resolves against, and the code and its test agree with them.
