**Why:** Part of TD-2080: its Fix item 4 asks what happens to temporary files with no owner. Read on 2026-11-23: `/tmp/claude-1000` held about 86,000 inodes across 814 project directories, with nothing ageing them out, and 382 bare `/tmp/pdm-build-*` directories were left by interrupted builds, likely because `pdm sync` runs before the precheck sets `TMPDIR`. §4.6's rule 3 and `scratch.BUILD_LEFTOVERS` cover such directories only directly under a seat's `<token>/`.

**Design PR:** #4439

**Location:** src/sessionorc/scratch.py, docs/cadence.toml, design §4.6 *The disk sweep*

**Fix:** Design which leftovers ShiftLead may remove. `/tmp/claude-<uid>` is Claude Code's, and a person's live or resumable session may depend on it, so settle how a project directory is proven unused, by age and no live session. Run the precheck's `pdm sync` under the run's `TMPDIR`, after TD-2100 has landed since both edit that command, and say whether the bare `/tmp/pdm-build-*` then needs a sweep rule or only a one-time removal.

**Done when:** An unused project directory past the agreed age and an old `pdm-build-*` are removed. A directory of a live or recent session is kept. A killed precheck's sync leaves nothing in `/tmp`.
