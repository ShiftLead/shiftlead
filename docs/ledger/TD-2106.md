**Design PR:** #4439

**Fix:** Design which leftovers ShiftLead may remove. `/tmp/claude-<uid>` is Claude Code's, and a person's live or resumable session may depend on it, so settle how a project directory is proven unused, by age and no live session. **Done when:** An unused project directory past the agreed age and an old `pdm-build-*` are removed. A directory of a live or recent session is kept. A killed precheck's sync leaves nothing in `/tmp`.
