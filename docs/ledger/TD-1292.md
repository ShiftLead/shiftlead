## TD-1292: A fork's PR row on the Repo page draws a fork tag and, once its CI is green, the person's `--fork-ok` precheck line with Copy

**Priority:** Medium
**Type:** debt
**Added:** 2026-10-31 (the designer, from TD-1285)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Part of:** TD-1285
**Location:** `src/shiftlead/ui/repo.py` (`pr_rows`); `src/shiftlead/teamrun.py` (`red_prs`, its `whose`); `src/shiftlead/ui/templates/repo_part.html` (`pr_row`, and the `info-prs` hover text); `src/sessionorc/cadence.py` (`precheck_typed`, read, not changed); `src/shiftlead/ui/static/app.css` (the line's style); tests beside `pr_rows`' and `red_prs`' own

**Why:** TD-1285: since slice 1 (#2762) a fork's PR is no work order and no session is ever given its precheck line, which runs a stranger's code on the machine. Paul decided on 2026-10-30 that the person is shown that line once the fork's forge CI is green. The design (§4.5 screen 11 *Review*, §4.5a *Repo page, Review*) puts it on the PR's row in the Repo page's Review column, and counts it nowhere.

**Fix:**
1. `pr_rows` gives each row `fork` (the reading's `fork`) and, for a fork's PR whose `checks` is `green` and whose `prechecked` is false, `fork_line`: `cadence.precheck_typed(root, n) + " --fork-ok"`. `root` is the repo reading's `root`. Where the page's home does not hold that root on its own disk (a node's repo), the line is the pinned form, `agent-cadence run precheck.py --pr <n> --fork-ok`, rather than a guess at a layout. `fork_line` also carries the PR's files URL (`<url>/files`).
2. `red_prs`: past `ORPHAN_AFTER`, a fork's PR (not a sync PR) that is not held reads `whose` *its author's*, where today it reads `''`.
3. `pr_row` draws a `tag` **fork** whose `title` is screen 11's words. With `checks` `none` the title adds the *no CI on this head yet — the forge may be waiting for you to approve a first-time contributor's run* clause. When `fork_line` is set, a second line under the row reads *yours, after reading the diff:*, then the line in `mono`, then a `btn sm ghost` **Copy** with `data-copy` set to the line (the page's one `data-copy` handler in `app.js` puts it on the clipboard and toasts *copied*) and a **diff ↗** link to the files URL (`target="_blank" rel="noopener"`). Nothing posts, and no road runs the line.
4. The `info-prs` hover text gains one clause: *a fork's PR is its author's; once its CI is green its precheck line is yours to run, after reading the diff*.
5. Tests: a fork's PR row with `checks` green and no `prechecked` has `fork_line` ending `--fork-ok`; with `prechecked`, red, pending or none it has none; a PR that is not a fork's never has one; `red_prs` gives a fork's PR *its author's* past `ORPHAN_AFTER`; the rendered row has the **fork** tag and, with the line, a `data-copy` whose value is the line. No count changes: the Inbox, the Queue and the facet's counts are the same with and without a fork's PR (slice 1's tests hold that already; keep them green).

**Done when:** the Repo page's Review row for a fork's PR draws the **fork** tag, the line with **Copy** and **diff ↗** appears only once its CI is green and its head is not prechecked, nothing runs the line, and the tests above pass.
