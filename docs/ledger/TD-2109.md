## TD-2109: The smoke test for a page over budget fails when the machine is busy

**Priority:** Low
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 3c445e06903a4d8aa64ee78c9f3b8585

**Why:** The smoke test for a page over its budget failed once under the full suite on a change that touches no source (TD-2100's follow-up, 2026-11-23): it expected the first byte to read 0.2 s and the loaded machine measured 0.44 s. It passed five times alone, so a precheck can go red for a reason unrelated to the pull request.

**Fix:** Make the assertion independent of the measured time, for example by giving the test a fixed timing, rather than matching a figure the machine's load can change.

**Done when:** The test holds under the full suite at its usual load.
