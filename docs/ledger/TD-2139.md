## TD-2139: The read of pull requests a session holds is not tested on node paths and loops

**Priority:** Low
**Type:** debt
**Added:** 2026-11-24
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 77546a5892594498a5f983233d2513df

**Why:** PR #4456 added `held_read` and `_in_checkout` (src/shiftlead/stage_fetch.py). Two of their guards survive removal with tests/test_stage_fetch.py green (103 passed). (a) The node branch compares `os.path.normpath` of both sides, and no test gives a node path that differs only in form (`/r/./x`, a trailing slash). Replacing it by `s.repo in paths` passes. (b) `test_a_symlink_loop_is_no_session_of_the_repo_and_stops_nothing` guards the `RuntimeError` the code's comment says Python 3.12 raises. On kmaster's 3.13 `Path.resolve()` of a self-loop raises nothing, so the test passes with `RuntimeError` removed from the except. It asserts the guard only on 3.12.

**Fix:** Add a node-path case that differs only by normalisation. Make the loop test patch `Path.resolve` to raise `RuntimeError`, so it holds on any Python.

**Done when:** Each of the two replacements above fails a test on 3.13.
