## TD-1387: The witness log's query: the `host_log` home read and `ao host-log`

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-04 (the designer, from TD-1295's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** TD-1386
**Part of:** TD-1295
**Location:** `src/sessionorc/witness.py` (`count`); `src/sessionorc/agent.py` (`rpc_host_log`); `src/sessionorc/modes.py` (`HOME_READS`) and `src/sessionorc/identity.py` (`READS`); `src/shiftlead/cli.py` (`ao host-log`, `--kinds`); the `ao` skill text; design §4.4 *The home keeps a log of what it witnesses*, §4.4a (the readings' row), §4.7

**Why:** TD-1295's design: the event check and a session both ask the log one question — at least N records of this kind, containing this text, since this date — and nothing reads the log until this lands.

**Fix:** as design §4.4 *The query* and §4.7 say: `host_log {kind, text, since, times, repos}` answers `{count, kept_since, records}` (literal, case-sensitive containment; `since` a required UTC date, inclusive; `records` the first `times`, oldest first; `repos` omitted means any); refused for a kind not in `KINDS` and for a `since` before `kept_since` (*the log keeps from <month>: since <date> is older*). It is a home read (`HOME_READS`, `identity.READS`): forwarded by a node while the link is up, refused offline. `ao host-log` prints the count and records and exits 0, 1 or 2 as §4.7 says; `--kinds` prints the table; `--json` the answer.

**Done when:** tests for the count over month files (a `since` mid-month, a text matched literally — a `.` or `*` matching only itself — and case-sensitively, an empty text matching all, `repos` filtering), both refusals, the CLI's three exit codes, and the node path as the `td_next` tests do it: `host_log` listed in `HOME_READS`, forwarded to the home while a node's link is up, refused on the node while it is down.

**Related:** TD-1295 (the design); TD-1386 (the log); TD-1388 (the check).
