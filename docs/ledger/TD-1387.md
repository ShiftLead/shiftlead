## TD-1387: The witness log's query: the `host_log` home read and `ao host-log`

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-04 (the designer, from TD-1295's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** TD-1386
**Part of:** TD-1295
**Location:** `src/sessionorc/witness.py` (`count`); `src/sessionorc/agent.py` (`rpc_host_log`); `src/sessionorc/modes.py` (`HOME_READS`) and `src/sessionorc/identity.py` (`READS`); `src/shiftlead/cli.py` (`ao host-log`, `--kinds`); the `ao` skill text; design §4.4 *The home keeps a log of what it witnesses*, §4.4a (the readings' row), §4.7

**Why:** TD-1295's design: the event check and a session both ask the log one question — at least N records of this kind, containing this text, since this date — and nothing reads the log until this lands.

**Fix:** as design §4.4 *The query* and §4.7 say: `host_log {kind, text, after, repo}` answers `{count, covers_from, records}` — literal, case-sensitive containment; `after` a required instant, inclusive, compared with `at`; `repo` omitted means any; `records` every match, oldest first by `at`; `covers_from` the later of `witnessed/start` and the first instant of the oldest month kept. Refused only for a kind not in `KINDS`; nothing refused for age. A home read (`HOME_READS`, `identity.READS`): forwarded by a node while the link is up, refused offline. `ao host-log` asks from 00:00 UTC of `--since`, prints the count, `covers_from` and the first N records, and exits 0, 1 or 2 as §4.7 says; `--kinds` prints the table with each kind's class; `--json` the answer.

**Done when:** tests for the count over month files (an `after` mid-month, a late record read in `at` order, a text matched literally — a `.` or `*` matching only itself — and case-sensitively, an empty text matching all, `repo` filtering), `covers_from` before and after a prune, the unknown-kind refusal, the CLI's three exit codes, and the node path as the `td_next` tests do it: `host_log` listed in `HOME_READS`, forwarded to the home while a node's link is up, refused on the node while it is down.

**Related:** TD-1295 (the design); TD-1386 (the log); TD-1388 (the check).
