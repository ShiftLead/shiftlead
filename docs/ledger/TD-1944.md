## TD-1944: Each session has one scratch directory of its own, named in its environment and its brief

**Priority:** High
**Type:** debt
**Added:** 2026-11-18
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 688eb9fd6473411eb789bbb5c6f8e253
**Part of:** TD-1921

**Why:** Sessions put temporary files in /tmp, in the tool's own per-user temp directory and under ~/.cache/ao<topic>, where nothing can say whose they are or reap them (TD-1921: 4.4 GB under /tmp/claude-1000 on 2026-11-17). Design §4.6 *A session's scratch* gives each record one directory the sweep can find by its record id.

**Location:** design §4.6 *A session's scratch*, §4.3, §5; src/sessionorc/, src/shiftlead/adapters/, src/shiftlead/briefs/, docs/briefs/

**Fix:** Build design §4.6 *A session's scratch*, with §4.3 (`scratch_env`) and §5 (`scratch_root`):
- the host agent makes `<scratch_root>/shiftlead-<uid>/<token>/` (`0700`, `<token>` eight random hex digits) at every run's start, a restart's and a refill's among them, writes `owner.json` in it (the record's id and the run log's name), stores the path as the record's `scratch` field, and puts it in the launch env as `SHIFTLEAD_SCRATCH` and `TMPDIR`;
- `scratch_root` on the host's `local` entry (default `/tmp`), parsed in `sessionorc.hosts` as `runs_keep_days` is and shown on the Settings page's Hosts card (`settings_page.host_card`); the host agent refuses at start a `scratch_root` longer than 48 bytes;
- the adapter attribute `scratch_env` (Claude Code `CLAUDE_CODE_TMPDIR`, Gemini CLI and Grok Build `None` unless their tools name one), set to the directory by `launch`;
- the packaged briefs (`src/shiftlead/briefs/`) and this repo's briefs (`docs/briefs/`, a held path) name `$SHIFTLEAD_SCRATCH` as the one place for temporary files and a scratch `SHIFTLEAD_HOME` (`$SHIFTLEAD_SCRATCH/home`), in place of `~/.cache/ao<topic>` and bare `/tmp` paths.

**Done when:** A session started in a scratch home has `SHIFTLEAD_SCRATCH` and `TMPDIR` set to its own existing `0700` directory under `scratch_root`, named in its record's `scratch` and holding `owner.json`; a Claude Code session has `CLAUDE_CODE_TMPDIR` set to it; a restart of the same record gets a new directory and the record's `scratch` moves to it; a 48-byte `scratch_root` with a ten-digit uid gives a scratch home whose `agent.sock` binds, and a 49-byte one is refused at start; the briefs name it and no brief names `~/.cache/ao`.
