## TD-1944: Each session has one scratch directory of its own, named in its environment and its brief

**Priority:** High
**Type:** debt
**Added:** 2026-11-18
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 688eb9fd6473411eb789bbb5c6f8e253
**Part of:** TD-1921

**Why:** Sessions put temporary files in /tmp, in the tool's own per-user temp directory and under ~/.cache/ao<topic>, where nothing can say whose they are or reap them (TD-1921: 4.4 GB under /tmp/claude-1000 on 2026-11-17). Design §4.6 *A session's scratch* gives each record one directory the sweep can find by its record id.

**Location:** design §4.6 *A session's scratch*, §4.2 (`TMPDIR`), §4.3, §5; src/sessionorc/, src/shiftlead/adapters/, src/shiftlead/briefs/, docs/briefs/

**Fix:** Build design §4.6 *A session's scratch*, with §4.2 (`TMPDIR`), §4.3 (`scratch_env`) and §5 (`scratch_root`):
- the host agent makes `<scratch_root>/shiftlead-<uid>/` (`0700`; it refuses to start when that is a symlink or not its uid's) and, at a run's start, `<token>/` under it (`0700`, `<token>` eight random hex digits), writes `owner.json` in it (the record's id, the run log's name and the home), stores the path as the record's `scratch` field, and the core puts it in the launch env as `SHIFTLEAD_SCRATCH`, `TMPDIR` and the adapter's `scratch_env` where it names one, after the env `launch` returns so ours win (§4.2, replacing TD-1487's host-agent `TMPDIR`; `launch` unchanged); the directory is made once per create, before its attempts at a free id; the host agent refuses at start a `scratch_root` inside or holding any adapter's `transcript_roots()`;
- a restart (a close followed at once by a create of the same record, §4.1 *Which closes reap*) and a Resume keep the scratch: the create takes the old run's `scratch` as a parameter from the launch record, over the link for a node, and makes none; a fresh start and a refill get a new one;
- the hourly sweep (`PRUNE_EVERY`) re-makes a live record's missing scratch directory and `owner.json` and touches every file under it not touched for a day;
- `scratch_root` on the host's `local` entry (default `/tmp`), parsed in `sessionorc.hosts` as `runs_keep_days` is and shown on the Settings page's Hosts card (`settings_page.host_card`); the host agent refuses at start a `scratch_root` longer than 48 bytes;
- the adapter attribute `scratch_env` (Claude Code `CLAUDE_CODE_TMPDIR`, Gemini CLI and Grok Build `None` unless their tools name one), read by the core as above;
- the packaged briefs (`src/shiftlead/briefs/`) and this repo's briefs (`docs/briefs/`, a held path) name `$SHIFTLEAD_SCRATCH` as the one place for temporary files and a scratch `SHIFTLEAD_HOME` (`$SHIFTLEAD_SCRATCH/home`), in place of `~/.cache/ao<topic>` and bare `/tmp` paths, and say a worktree is never made under it.

**Done when:** A session started in a scratch home has `SHIFTLEAD_SCRATCH` and `TMPDIR` set to its own existing `0700` directory under `scratch_root`, even where the adapter's launch env sets `TMPDIR`, named in its record's `scratch` and holding `owner.json` with the home; a Claude Code session has `CLAUDE_CODE_TMPDIR` set to it; a restart and a Resume of the same record keep the directory, on the home and on a node, and a refill gets a new one; a live record's directory removed by hand is back, with `owner.json`, after the next sweep, and a file under it dated eleven days back is touched; a `scratch_root` holding a transcript root is refused at start; a `shiftlead-<uid>` that is a symlink stops the host agent's start; a 48-byte `scratch_root` with a ten-digit uid gives a scratch home whose `agent.sock` binds, and a 49-byte one is refused at start; the briefs name it and no brief names `~/.cache/ao`.
