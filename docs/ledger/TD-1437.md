Neither road written so far fits as it stands (the techlead's answer to TD-1385's steer, 2026-11-06):
- **`ref-includes <repo>@<deploy-ref> <commit>`** (the target design's example): the gate sweep's `event_checks.py` asks the forge, and no deploy ref exists there — the live commit is only `promotes.<repo>.live` on the home; and the build PR that makes the entry a live check cannot name the squash commit, which exists only after its merge.
- **`host-log witnessed kind promote "(#<n>)"`**: `witness.KINDS` has no promote kind, and the reader counts from 00:00 UTC of the day after the gate's `gate added` line (design §4.4 *The check*), so a promote on the build's merge day — the usual case with `auto` on — is never counted.
