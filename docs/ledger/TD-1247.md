## TD-1247: The briefs say a board line found done closes in a PR of its own, never folded into a feature PR

**Priority:** Low
**Type:** debt
**Added:** 2026-10-30 (the designer, from TD-1066's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Part of:** TD-1066
**Location:** `src/shiftlead/briefs/grinder.md` (the decided-line paragraph, ~:12); the other shipped briefs under `src/shiftlead/briefs/` that tell a session to close a board line; `docs/briefs/` where a repo brief says the same

**Why:** design §4.9a *A line found done* (TD-1066). On 2026-10-26 the close of an `act` line sat in a ledger PR (#2408) that conflicted, so `main`'s board kept asking Paul to do what was done.

**Fix:** one sentence beside the decided-line paragraph: a session that finds an open `act` or `decide` line's task done — by anyone, itself included, in another repo or a merged PR — and no open PR of its own doing that task closes it in a PR of its own off `origin/<default>`, carrying `ao board edit done --key board:<key> --why "<what was done, where>"` and nothing else, merged on the cadence; never folded into a PR that does other work. grinder.md's *do it in the same PR* stands only where that PR does the task. The briefs' doc-bound tests updated where they quote the paragraph.

**Done when:** the shipped briefs carry the sentence, `grep -rn "PR of its own" src/shiftlead/briefs` finds it, and `pdm run test` passes.

**Related:** TD-1066 (the design), TD-584 (`ao board edit`).
