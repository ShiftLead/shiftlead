**Fix:** Build design §4.6 *The pressure pass*: `PRESSURE_EVERY`, `PRESSURE_LOW`, `PRESSURE_CLEAR`, `PRESSURE_BACKOFF`, inodes alone where `scratch_root` shares the home's file system, the reclaim under the sweep's lock, its three rules in order (`PRESSURE_KEEP_HOURS` in the second), and consecutive empty passes folded into one `disk.json` line.

**Done when:** In a test with the free-space reading stubbed (this machine allows no unprivileged mount), a reading under `PRESSURE_LOW` starts a reclaim without the hourly sweep. It removes a finished and a dead test run from a live seat's directory, keeps a run written in the last ten minutes, `pytest-current`'s target and a directory holding git work outside a test run, takes an ended run's directory past `PRESSURE_KEEP_HOURS` unless a hold keeps it, stops over `PRESSURE_CLEAR`, and backs off after a pass that freed under 1%.
