## TD-1377: The merge gate checks that each new decision has a board item

**Priority:** High
**Type:** feature
**Added:** 2026-11-04 (ao-led-tds-ledger, a person-session in ledgerboard, through `ao td add --repo shiftlead`; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** TD-1376
**Part of:** TD-1369
**Location:** where ShiftLead gates a merge on the ledger (the pinned `check_cadence.py` run, `src/sessionorc/workorders.py`'s PR orders, `scripts/` or `tests/test_ledger.py`); design §4.4

**Why:** ledgerboard's target design (ShiftLead/ledgerboard `docs/plans/target-design.md`) §7.2 steps 3 and 4 (*the same merge-gate check*), §1.2 (`uncovered_decisions`): a `decision (Paul)` gate with no board item asks nobody, so the person never hears of it.

**Fix:** on every PR, refuse a new `decision (<person>)` gate that no board item names, using the module's `uncovered_decisions`. The PR changes ShiftLead's design (docs/design/) in the same diff wherever the behaviour it changes is written there.

**Done when:** a PR adding a `decision (paul)` gate without a board item fails the check, and one with it passes.

**Related:** TD-1369; ledgerboard's target design (ShiftLead/ledgerboard `docs/plans/target-design.md`) §7.2 step 4.
