**Location:** docs/design/4.5a-controls.md (lines 154 and 159)

**Why:** `docs/design/4.5a-controls.md` has two rows keyed `Inbox row: restart` for the same control, and they disagree on its buttons. Line 154: `| Inbox row: restart | **Open**, **Resume**, **Dismiss**, **Snooze** | §6 *Keeping a team running*: a supervised member the tick could not restart …` and line 159: `| Inbox row: restart | **Open**, **Restart**, **Resume**, **Dismiss**, **Snooze** | a supervised member the tick could not restart (§6 *Keeping a team running*) …`. Both describe the same row ("It is its own row, beside any state row the record also has"), and §4.5a's rule is that the table is the one place a control is stated. Line 154 is the older text (no **Restart**, no §6 rule 2 *A person's restart*); `git log -S` finds it unchanged since the split (325d50021, 2026-10-06 / TD-464 f3afd84cb) while the **Restart** row was added beside it. #2995 (TD-1422) had to edit the *The row leaves when the mark does* sentence in both rows in lockstep, and the next change that edits one will drift the other. A reader taking the first row gets a Restart-less row, which the code contradicts (`ui/inbox.py` draws Restart on a restart row).

**Fix:** Merge the two rows into one, keeping the **Restart** row (line 159) and carrying into it what only line 154 says: that an early row says what decided it, then the session's own `why` (*restart wanted · early: nothing reported done this run — …*, the words the mark carries as `decided`, a mark older than the field reading *early*). Then check `tests/test_ui_inbox.py` and the 4.5a doc-bound tests (`grep -ln 4.5a tests`) still pass, since a row's first cells are test keys. The Restart drawing is in `static/app.js` (`v.restartable`, set by `ui/inbox.py`).

**Done when:** §4.5a holds one `Inbox row: restart` row. The doc-bound tests and `pdm run lint` pass.
