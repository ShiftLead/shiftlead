## TD-1256: No test reaches the Start road's `card_mail` / `waits_on_me` branch: the world fake makes it raise, and `suppress(Exception)` hides it

**Priority:** Medium
**Type:** debt
**Added:** 2026-10-30 (test-audit-ao-1, auditing the last ten merged PRs)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `src/shiftlead/ui/app.py` (`api_ledger_start`: `with contextlib.suppress(Exception): … card_mail(…) … mine = waits_on_me(mine, wants)`); `tests/test_ui_inbox_ledger.py` (`_start_world`, imported by `tests/test_queue_start.py`)

**Why:** #2713 (TD-1246 (2)) made the prompt's *waits on me* group name every Decide and Do item of the card (mail ids, board keys, PRs) by reading `card_mail` inside `contextlib.suppress(Exception)`. In `tests/test_queue_start.py` that read always raises, so the branch never runs. Two probes at `origin/main` b24246275: (1) replacing `mine = waits_on_me(mine, wants)` with `pass` and running `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_queue_start.py tests/test_own_sessions_edge.py tests/test_ui_queue.py` gives `77 passed`, the same as unmutated; (2) replacing `with contextlib.suppress(Exception):` with `if True:` fails six tests, the first `test_a_card_press_starts_on_its_start_with_the_queue_prompt_and_the_cards_ids`, with `KeyError: 'entries'` at `app.py:1297` (`for e in got["entries"]` in the person-inbox reader), because the `_start_world` host fake serves no person-inbox record shape. So the one test of the prompt's *waits on me* list (`… waits on me — samscrape#TD-012, samscrape#TD-009, board:91aa0c3e`) sees only the ledger-entry fallback, and a card's mail and board items missing from the prompt — or `card_mail` broken outright — would fail nothing. `test_an_items_id_is_its_board_key_mail_id_entry_or_pr_and_waits_on_me_names_every_item` tests `waits_on_me` alone, not the road's call of it.

**Fix:** give `_start_world`'s host the person-inbox shape `h.person_inbox` / `person_states` / `board_view` / `ledger_view` read (an `entries` list among them), put a mail item on the card, and assert the prompt's *waits on me* group names its id; keep the suppress, as an older home may fail the read.

**Done when:** replacing `mine = waits_on_me(mine, wants)` with `pass` fails a test.
