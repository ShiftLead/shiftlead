## TD-1205: `test_ui_card_completed` asserts none of a completed row's age, the reference width, or the week and month empty words: set each to a constant and the suite stays green

**Priority:** Low
**Type:** debt
**Added:** 2026-10-28 (test-audit-ao-1, from #2611)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `tests/test_ui_card_completed.py`; `src/shiftlead/ui/org.py` (`completed_faces`, `team_summary`'s `done_ref_w`)

**Why:** #2611's tests pin the rows' ids, urls, the `no PR` width and the day window's *nothing completed today*, and nothing else of what `completed_faces` returns. Probes on `origin/main` (2026-10-28), each followed by `pytest -q tests/test_ui_card_completed.py` (5 passed every time):
- `"age": _short_age(c.get("closed"), now)` → `"age": ""` — the visible age in every row's phase column is never read (the test reads `x.closed` as `data-doing-at`, not the text `x.age`).
- `"word": COMPLETED_WORD[w]` → `"word": "today"` — *nothing completed this week* / *this month* (the design's words, §4.5a *team card: TDs in motion*) are asserted nowhere; only `day` is.
- `"done_ref_w": min(max(...), REF_WIDTH)` → `"done_ref_w": 1` — the completed grid's reference track (`--ref-n`) is never read, so a one-character column passes.

**Fix:** assert the row's age text, the three windows' empty words, and `done_ref_w` (its max id length, capped at `REF_WIDTH`) in `test_ui_card_completed.py`.

**Done when** each of the three probes above fails `tests/test_ui_card_completed.py`.
