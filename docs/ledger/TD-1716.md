**Location:** design §4.7 *Feedback*, §4.3 `conversations`, `read_transcript`; src/sessionorc/adapters.py (TranscriptEntry, Conversation); src/shiftlead/adapters/claude_code, gemini; src/sessionorc/agent_common.py (NODE_READS); the RPC handlers; src/shiftlead/cli.py

**Why:** TD-1491's design (§4.7 *Feedback*) gives the `/shiftlead-feedback` procedure a deterministic extractor that condenses a seat's transcripts over a window into text an agent reads. It reads through each tool's adapter, never a tool's files from core. The 2026-11-06 review the procedure replaces read Claude Code's and Gemini's files by hand.

**Fix:** Build §4.7 *Feedback*'s extractor and §4.3's two additions:

- **§4.3**: `TranscriptEntry.error` on a `tool` entry (True when the tool marked the result failed; `to_dict` carries it only when True), set by the Claude Code and Gemini CLI adapters in `read_transcript`. Also the optional `conversations(cwd, profile) -> list[Conversation] | None` with `Conversation(id, first_at, last_at, size)`, oldest first and read from each file's head and tail only: Claude Code from the profile's `projects/<munged cwd>/*.jsonl`; Gemini CLI from the top-level chats of the projects whose `.project_root` names `cwd`. The conformance suite (TD-112) names it among the reads an adapter declares.
- **RPCs**: `conversations {id, since, until}` (every profile the adapter's `profiles()` lists, a conversation two profiles list kept once, the record's own profile first; a shell refused with *a shell has no transcript*) and `transcript_digest {id, conversation, profile, since, until}` (paging `read_transcript` back by `before` until it passes `since`; the digest's line forms as §4.7 lists them; `cut` at 4 MiB, at the last prompt before it, with the *cut: n later lines not read* line). Both are reads gated by nobody, added to `NODE_READS`.
- **CLI**: `ao feedback digest <seat>… --since <when> [--until <when>] --out <dir> [--part-bytes N]` (default 250000). `<when>` is a local day or an instant. It writes `<dir>/<seat name>.txt`, or `<seat name>.1.txt` and on, split at a conversation header or a prompt, each conversation under its `## <id> · <profile> · <first_at> → <last_at>` header; it prints the `--json` index §4.7 gives; a record with none in the window is listed with none and gets no file; it writes nothing outside `<dir>`.

**Done when:** `ao feedback digest` over a scratch home's record writes the parts and index §4.7 gives. Tests cover each digest line form (prompt cut at three lines, whole doorbell, text, `✗` failed call, collapsed calls, subagent, compaction, no thought), the window's edges, the part split, `cut`, the profile dedupe, and a shell's refusal. Both adapters' `conversations` and `error` are tested on fixture files. §4.3 and §4.7 say what the code does.
