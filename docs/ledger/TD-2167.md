**Why:** In `src/shiftlead/stage_job_make.py`, `_offer` passes a job sent back by a review its reason: `came = _came(record, str(stage))[0] if stage else None`, handed to `reach.start(record, came)` (#4519, TD-2053; `stage_job_start.told` writes it into the session as "It came back to you by a move whose reason was: …"). No test gives a record a stage and a history. Evidence: with that line replaced by `came = None`, `tests/test_stage_job_make.py`, `tests/test_stagerecord.py` and `tests/test_stage_job.py` all pass (90 passed); the test double records `came` (`self.started.append((dict(record), came))`) but no test asserts a non-None value. Also in the same file, `"holder": None` in the `stage-gone` case (`moved = {**stage_job.moved(record, ...), "holder": None}`, comment "its holder ended first") can be dropped with all 90 passing, because `stage_job.moved` does not clear the holder and the stage-gone test record has none.

**Location:** src/shiftlead/stage_job_make.py; tests/test_stage_job_make.py

**Fix:** Add two tests in `tests/test_stage_job_make.py`: an offer-again for a record at a stage whose last history move has a reason, asserting the `came` the start double received is that reason; and a stage-gone record that has a holder, asserting the written record has none. Check each fails with its line reverted.
