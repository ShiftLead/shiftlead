## TD-1487: Seat shells: TMPDIR unset, pdm run fmt rewrites unrelated files on a ruff version skew, and no one tested waiter

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-06 (Paul, through ao-led-tds-ledger and the techlead seat; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 555b17c25f5240e38687f6ae9aed41a6
**Location:** the seat launcher's environment (src/sessionorc/tmux.py, the session's env); pyproject.toml (`ruff>=0.6`, the dev group); `ao pr wait`, the precheck runner

**Why:** - `TMPDIR` is unset in seat shells, about 12 times. Scripts that write `$TMPDIR/pc.log` or `$TMPDIR/inbox.json` hit `/pc.log: Permission denied`.
- `pdm run fmt` rewrites unrelated files because of ruff version skew, 6 or more times, and called *a known trap*. One stray hunk reached a review. `pyproject.toml` pins `ruff>=0.6`, and the main venv had 0.16.3 while the live install had 0.16.6.
- Background waits are unreliable: `pgrep` matched itself, and a Monitor event reported a gate passed that had not.

Found by Paul's trial review of three seats' transcripts (designer-ao-1, grinder-ao-2, techlead-ao-1), 2026-11-03 to 2026-11-06, deduped against the ledger, and sent through the person's session `ao-led-tds-ledger` (m-01263e0bba7e); its tooling and rule parts went to agent-cadence.

**Fix:** - Export `TMPDIR` (the session's own temp directory, or `/tmp`) in the environment the launcher gives every session.
- Pin ruff to one exact version in the dev group so every checkout formats alike, and bump it by PR.
- Name one tested waiter in the briefs: `ao pr wait <n>` for a PR's checks, and the precheck's own exit for a precheck (agent-cadence, if a `--wait` is wanted there). Replace ad-hoc `pgrep` loops in the briefs with it.

**Done when:** A new seat shell has `TMPDIR` set; `pdm run fmt` on a clean main changes nothing; the briefs name `ao pr wait` and no pgrep loop.
