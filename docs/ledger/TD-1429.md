**Why:** TD-1422's design (§6 rule 2 *A person's restart*, rule 3 *The ceiling is a rate, not a stop*; §4.7 `ao restart`; §4.5a *Inbox row: restart*). `ao restart` refuses every seat (*a seat: rule 3 fills it when it is due, and Resume is the way to it*, `src/sessionorc/agent.py` `_restart_check`), and the *fills exhausted* row draws no Restart (`restartable` is false on a seat, `src/shiftlead/ui/cards.py`), so a person at a terminal had no command to bring back a seat held at the ceiling, and the Inbox's way was Resume, which brings it back attended.

**Fix:** 1. **The RPC.** In `rpc_restart` / `_restart_check` (`src/sessionorc/agent.py`), a seat whose `restart_ceiling` is `{why: fill}` (lapsed or `held`) is not refused: the press, still a person's own, clears `restart_ceiling`, writes `restarts = [{at, why: person}]`, saves and pushes, creates and closes nothing, and returns the record's view. Every other seat keeps the refusal's words. The other refusals (suspended, superseded, scheduled, working) are checked first as today.
2. **The fill past the count.** In `_fill` (`src/sessionorc/agent_tick.py`), a seat whose newest `restarts` entry is `{why: person}` with no `fill` after it is filled whatever its fellows' count, once, when its cause is due; that fill is written `{why: fill}` as any other and counts from then.
3. **`ao restart`'s reply** on such a seat prints *<seat> · fills exhausted cleared — rule 3 fills it when it is due* (§4.7), not the new-record line.
4. **The row, not the card.** `restartable` (`src/shiftlead/ui/cards.py`) is one flag that both the card's more ▾ (`card.html`) and the Inbox row (`inbox.py`, `inbox_row.html`) read; leave it false on every seat, so more ▾ keeps no Restart for a seat (§6 rule 2, §4.5a), and give the *fills exhausted* row its own test — a seat whose `restart_ceiling` says `why: fill` — so the row alone draws **Restart** beside Resume, calling the same `restart` RPC. Leave §4.5a's help list and `src/shiftlead/ui/help.py` as they are unless the Restart help no longer reads true of a seat; if it does not, change both in this PR (the test compares them word for word).
5. Tests: `restart` on a seat at the fill ceiling clears the mark, writes `[{why: person}]` and creates no record; the next tick fills the due seat though its fellows hold six fills in the hour; `restart` on a seat with no ceiling is refused as before; the row carries Restart for a fills-exhausted seat and not for a seat with no mark. Run `grep -ln "4\.5a" tests/*.py` and the help tests.

**Done when:** A person's `ao restart <seat>`, or Restart on the *fills exhausted* row, clears the seat's fill ceiling and the seat is filled on the tick its cause is next due, past the count; `restart` on any other seat is refused as before; the tests in the Fix pass.
