## TD-1884: The td-max test fails every precheck from midnight to 14:02 local

**Priority:** High
**Type:** debt
**Added:** 2026-11-15
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 738750f916164b7a99f67d729c6085e4

**Why:** `tests/test_td_max_seen.py` fails every full precheck run between local midnight and 14:02. Its `TODAY` (line 16) is today at 14:02 local. Before 14:02 that time is in the future, so the reader formats it with its weekday (*+1 at Sat 14:02*), and four asserts that expect *+1 at 14:02* fail: `test_the_card_badge_rows_and_header_draw_it`, `test_the_members_dialog_reads_the_range_beside_up_to`, `test_ao_team_list_says_each_scaling_line_on_a_live_team` and one more. This was seen on PR #3960's precheck at 5067bb11f, run 2026-11-15 shortly after midnight MST. The same suite passed on that PR at 23:4x the evening before. Every PR whose precheck runs the whole suite is red for those fourteen hours.

**Location:** tests/test_td_max_seen.py

**Fix:** Build `TODAY` as a time already past whenever the test runs. One way is to freeze the clock the reader formats against. Another is to take the time from a fixed past day, then assert the words the reader gives for that day. Keep each assert's expected text. Check the other tests that build a time from `datetime.now()` at a fixed hour (`git grep -n "now().*replace(hour" tests`) for the same fault.

**Done when:** `tests/test_td_max_seen.py` passes whatever the local hour, shown by running it under a clock set before 14:02 and one set after.
