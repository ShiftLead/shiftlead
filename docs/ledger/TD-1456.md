On 2026-11-06 the techlead ended a turn listing asks it had read but not worked (TD-1428, agent-cadence TD-233, four of the person's), and nothing woke it: the doorbell rings only undecided mail (`mail.undecided_mail`, past `mail_decided`), and rule 4 names open asks only for a record with a `seat` whose `seat_due` is set (`_nudge_line`, `src/sessionorc/agent_tick.py` ~2882). **Fix:** - **Open work.** In `_idle_nudge` (`src/sessionorc/agent_tick.py` ~1298), an open `ask` in a supervised member's inbox from another session, read or not (`s.asks_waiting(home=self.host)`), counts as open work for every member, seat or not; a seat's own test (`seat_due` set) stands as it is.
- **The line.** In `_nudge_line`, the non-seat branch adds *you have N questions waiting — run `ao inbox`* (N from `asks_waiting`, less entries the person handed it, which keep their own clause as the seat's branch writes them) after the open reference where there is one and alone where there is none, then the owed part, joined with `; ` as now. Once per idle stretch (`nudged_at`), as every rule-4 line.
- **The techlead brief** (`src/shiftlead/briefs/techlead.md`, the end-of-turn rules): never end a turn on a list of open asks — work each to an answer, a hand-off (a `reply` saying who now holds it) or a filed entry first.
- Tests: an idle, unattended, supervised record with no seat holding one read open `ask` from another session gets the *questions waiting* line once per stretch; with an open claim the line names the claim then the questions; an ask that is closed (replied, lapsed) does not count; a seat's line is unchanged.

**Done when:** An idle supervised member with a read open ask from another session is nudged *you have N questions waiting — run `ao inbox`*, seat or not, and the techlead brief says to end no turn on open asks. Tests cover each case above.
