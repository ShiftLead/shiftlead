## TD-1940: The pushed-commit reading's test misses origin and local-remote cases

**Priority:** Low
**Type:** debt
**Added:** 2026-11-18
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** a0a40833027f4847ba0878afbcb3ac19

**Why:** Test audit of #4070 (TD-1923): reverting two lines of `gitinfo.pushed_since` leaves `tests/test_restart_pushed.py` and `tests/test_gitinfo.py` green (25 passed each time). (1) `"log", ref, "--not", "origin/HEAD"` → `"log", ref`: the fixture's branch never holds a commit that is on main, yet design §4.9a says a commit reachable from `origin/HEAD` is not new work. (2) `if not remote or remote == ".":` → `if not remote:`: a branch tracking a local branch (remote `.`) is untested, so it would read `refs/remotes/./<branch>` and return None.

**Location:** src/sessionorc/gitinfo.py (pushed_since); tests/test_restart_pushed.py

**Fix:** Add to `tests/test_restart_pushed.py`: (a) a branch whose pushed history includes a commit made after the start that is also on `origin/main` (merged there by a fast-forward) — `pushed_since` must return None for it, and the sha of a later commit of its own; (b) a branch with `branch.<name>.remote` set to `.` and an `origin/<name>` ref — the sha is read from origin. Run each revert and see the test fail.

**Done when:** Reverting `--not origin/HEAD` and the `remote == "."` case in `gitinfo.pushed_since` each fails a test of `tests/test_restart_pushed.py`.
