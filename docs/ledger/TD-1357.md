## TD-1357: The briefs ShiftLead ships name the board helper and the ledger's edit commands

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-04 (the designer, from TD-1286's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** TD-1356
**Part of:** TD-1286
**Location:** `src/shiftlead/briefs/` (every role template); the tests that quote them

**Why:** The briefs and start texts ShiftLead ships (`src/shiftlead/briefs/`) tell sessions to write board lines and change ledger entries by hand: *write a `**Waits:**` line*, *a board line*, *archive it*, with no command (TD-1286).

**Fix:** As design §4.4 *A session writes the ledger and the board only through the helpers*: every template under `src/shiftlead/briefs/` (`grinder.md`, `grinder.stage.md`, `designer.md`, `techlead.md`, `techlead.stage.md`, `manager.md`, `manager_on_call.md`, `sweeper.md`, `hunter.md`, `auditor.md`, `work.md`, `fact-checker.md`, and `entry.md`'s steps that change an existing entry): each step that changes an entry names its `agent-cadence run ledger.py` command (`set`, `note`, `edit`, `archive`, `reopen`, `renumber`), and each that writes or changes a board line names `board_edit.py add --no-commit` or the edit's command; none gives a line's shape to type. Filing a new entry stays as it is until TD-1360. The doc-bound tests over the briefs (`grep -ln briefs tests`) pass, updated where they quote a changed line.

**Done when:** No template under `src/shiftlead/briefs/` tells a session to type a board line or a change to an existing entry: each names the helper command.

**Related:** TD-1286; agent-cadence#TD-206; TD-1330.
