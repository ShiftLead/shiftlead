## TD-1286: Sessions here still type ledger entries and board items by hand: every write goes through the helpers, as Paul's rule asks of every ledgerboard repo

**Priority:** medium
**Type:** feature
**Added:** 2026-10-30 (Paul, ledgerboard session `led-tds`: "Every repo that uses ledgerboard should only use the helpers (ledger.py, board.py) and never edit the ledger or board by hand")
**Owner:** designer
**Kind:** design-first
**Status:** Designed 2026-11-04 (the designer) — design §4.4 *A session writes the ledger and the board only through the helpers*, §4.9 *Two ways out*; builds TD-1356 (the pin bump and AGENTS.md), TD-1357 (the shipped briefs), TD-1358 (docs/briefs), TD-1360 (new entries through ledger.py new, after agent-cadence#TD-188). The code's ledger half has nothing to convert: ShiftLead's code writes no ledger entry (its `src/sessionorc/ledger.py` only reads); §4.4 says code that comes to write one uses ledgerboard's writer. Class in-repo (this repo's briefs, templates and pin; agent-cadence's rule and helpers are built, agent-cadence#TD-206), cap 4. Rounds: in progress. Was: Open 2026-10-30, filed held on agent-cadence#TD-206 (resolved 2026-11-04, #75–#77); Paul's Ask answered 2026-10-30 and his go 2026-10-31; rescoped 2026-11-03 by ledgerboard's target design §1.1, the board half TD-1330.
**Location:** `src/sessionorc/board.py` (`add`, `add_decided`, `edit_line`, `_insert`: the board half, TD-1330); `src/shiftlead/briefs/entry.md` (the drafting brief the Add entry flow and `ao td add` hand an ask to), `AGENTS.md` and `docs/briefs/` (each step that tells an agent to write a ledger entry or board item); `docs/cadence.toml` (the agent-cadence pin, whose wrappers name the helper commands); `scripts/vendor_ledgerboard.sh` (v2.3)

**Why:** Paul set the rule on 2026-10-30: every repo that uses ledgerboard writes its ledger and its board only through the helpers, `ledger.py` and `board.py`, never by hand. agent-cadence carries it (agent-cadence#TD-173 and its builds agent-cadence#TD-197 to agent-cadence#TD-202 for the ledger, agent-cadence#TD-206 for the board and for every consuming repo), and ledgerboard#TD-008 adds the board writers it needs. ShiftLead is one of those repos, and its sessions still type ledger entries and board items by hand wherever a brief or a seat tells them to write one. Its own code already goes through ledgerboard for most board writes (`board.py` adds plain and decided items through `item_line()` and `decided_line()`, and edits through `edit_line()`), but has no writer for a new `decide` item with `Answers:` and a detail block, or for an archive.

**Fix:** designed (design §4.4 *A session writes the ledger and the board only through the helpers*, §4.9 *Two ways out*, *How it lands*); the builds, in order:
- **TD-1356**: the agent-cadence pin bumped past agent-cadence#TD-206's builds (#75–#77), and `AGENTS.md` names the board helper and the ledger's edit commands.
- **TD-1357** and **TD-1358** (after TD-1356): the briefs ShiftLead ships, and this repo's `docs/briefs/`, name the same commands; the memory rules that teach hand edits are retired or reworded (TD-1358).
- **TD-1363** (after agent-cadence's ledgerboard v2.4 vendor, agent-cadence#TD-188 step 2): `ao td reserve` prints the take's `Id take` line, TD-188's step 3, which its step 4 waits for.
- **TD-1360** (after TD-1357, TD-1358, TD-1363, and agent-cadence#TD-188's step 4 merged, a `Waits:` event, since TD-188 itself closes only after TD-1360): a new entry is filed with `ledger.py new --id`, once the pin is past TD-188 (`ledger.py new` refuses in this ledger until then).
- **The code** (Paul, 2026-10-30: *Any place in shiftlead that makes ledger or board edits should do so*): nothing to convert. ShiftLead's code writes the board through ledgerboard's board writer in-process (TD-1330, v2.3) and writes no ledger entry; §4.4 says code that comes to write one calls ledgerboard's ledger writer, the in-process route that ADR 2026-11-03 sets beside cadence §2.12's *code calls `ledger.py`*.

**Done when:** TD-1356, TD-1357, TD-1358, TD-1363 and TD-1360 merged: `ledger.py new --id` files an entry here, and no brief, seat template or `AGENTS.md` line tells a session to type a ledger entry or a board line.

**Related:** TD-1330 (the board half, v2.3); ledgerboard target design §1.1, §7.2 (ledgerboard#57); agent-cadence#TD-206 (the board helper and the rule for every consuming repo), agent-cadence#TD-173 and agent-cadence#TD-202 (the ledger's), ledgerboard#TD-008 (the board writers, v2.3); TD-1282 (vendors v2.2 first).
