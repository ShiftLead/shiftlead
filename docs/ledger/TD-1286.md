**Type:** feature

**Owner:** designer
**Kind:** design-first
**Status:** Open 2026-10-30: filed held; the rule and its tools are agent-cadence#TD-206 and ledgerboard#TD-008, whose design rounds have not run 2026-10-30: Paul answered the Ask: ShiftLead's own code calls `ledger.py` and `board.py`, wherever it edits a ledger or board. **Blocked by:** agent-cadence#TD-206
**Location:** `src/sessionorc/board.py` (`add`, `add_decided`, `edit_line`, `_insert`: the only code here that writes either file); `src/shiftlead/briefs/entry.md` (the drafting brief the Add entry flow and `ao td add` hand an ask to), `AGENTS.md` and `docs/briefs/` (each step that tells an agent to write a ledger entry or board item); `docs/cadence.toml` (the pin that brings `ledger.py` and `board.py`); `scripts/vendor_ledgerboard.sh` (v2.3)

**Why:** Paul set the rule on 2026-10-30: every repo that uses ledgerboard writes its ledger and its board only through the helpers, `ledger.py` and `board.py`, never by hand. agent-cadence carries it (agent-cadence#TD-173 and its builds agent-cadence#TD-197 to agent-cadence#TD-202 for the ledger, agent-cadence#TD-206 for the board and for every consuming repo), and ledgerboard#TD-008 adds the board writers it needs. ShiftLead is one of those repos, and its sessions still type ledger entries and board items by hand wherever a brief or a seat tells them to write one. Its own code already goes through ledgerboard for most board writes (`board.py` adds plain and decided items through `item_line()` and `decided_line()`, and edits through `edit_line()`), but has no writer for a new `decide` item with `Answers:` and a detail block, or for an archive.

**Fix:** design first, after agent-cadence#TD-206's rounds:
- **Agents:** the Add entry flow and `ao td add` write no file; they hand the words to a drafting seat, whose brief (`src/shiftlead/briefs/entry.md`) has it write the entry by hand, and `AGENTS.md` and `docs/briefs/` tell a session to write ledger entries and board items. Each of those names the `ledger.py` or `board.py` command instead, so no agent here types either file; the cadence check's ledger and board rows (agent-cadence#TD-201, agent-cadence#TD-206) then hold PRs to it. `entry.md`'s step adding a Summary row is stale besides, since the v2 ledger has none.
- **Code (Paul, 2026-10-30: "ShiftLead's own board.py should call ledger.py and board.py. Any place in shiftlead that makes ledger or board edits should do so"):** every ledger or board edit ShiftLead's code makes goes through agent-cadence's `ledger.py` and `board.py`, never ledgerboard's writers directly. Today that is `src/sessionorc/board.py` (`add`, `add_decided`, `edit_line`, `_insert`), which keeps ledgerboard for reading only; any later code that writes either file does the same.
- **The pin and the vendor:** bump to the agent-cadence that carries `ledger.py`'s commands and `board.py`, and vendor ledgerboard v2.3 (after TD-1282 brings v2.2), each with its `fmt` PR beside it.

**Done when:** no brief, seat template or procedure here tells a session to edit a ledger or board file, the Ask is answered and built, and this repo pins and vendors the releases that carry the helpers.

**Related:** agent-cadence#TD-206 (the board helper and the rule for every consuming repo), agent-cadence#TD-173 and agent-cadence#TD-202 (the ledger's), ledgerboard#TD-008 (the board writers, v2.3); TD-1282 (vendors v2.2 first).
