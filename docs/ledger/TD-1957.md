## TD-1957: A delegated answer's name is drawn in three places and tested in none of them end to end

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-19
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 9f62de8bf61d45348a4ab4028c3ed64f

**Why:** PR #4108 (TD-1939 slice 2) added three behaviours that no test would catch going back. Each was reverted in a worktree and the suite run; every run stayed green.

- `board_hold` in `src/sessionorc/queue.py` copies a line's `delegate` and `scope` into the held answer's `line` (`line.update(delegate=…, scope=…)`). Deleting those two lines passes `tests/test_delegated_answer.py` (12) and every `tests/test_queue*.py`, `test_handed_cover.py` and `test_refuse_waiting_presses.py` (402 in all). `test_a_board_answers_foot_names_the_delegate` hands `_held_answered` a `line` that already carries `delegate`, so it never sees what `board_hold` writes: with the copy gone, the Queue's foot reads *you answered "Go" on the board* for a delegated answer.
- `inbox_row.html` prints `· <delegate> for you (<scope>)` after *decided: …*. Removing that clause passes all 600 tests in the 30 modules that render `/inbox` or `/repo`. `test_a_board_rows_decided_line_names_the_delegate` stops at `inbox._decided`'s dict.
- `repo_part.html`'s `order_row` prints the delegate and scope beside *decided …*. Removing the clause passes the same run; `test_a_delegated_answer_is_a_work_order_naming_its_delegate` stops at `workorders.orders`.

The module's docstring says *every place that draws who answered names the delegate and its scope*, but it asserts the data only for two of the three places that draw it.

**Location:** tests/test_delegated_answer.py; src/sessionorc/queue.py board_hold; inbox_row.html; repo_part.html

**Fix:** Add to `tests/test_delegated_answer.py`: (1) `board_hold` on a closed delegated line returns a `line` with `delegate` and `scope`, and `_held_answered` of that result reads *<delegate> answered … for you on the board (<scope>)*; (2) the Inbox board row's HTML for a delegated `Decided:` contains *director for you (merge-line)*; (3) the Repo page's decided-lines row does too, and neither does a person's own answer. Each new test fails with its clause removed.

**Done when:** Deleting the `line.update(delegate=…)` pair, the `inbox_row.html` clause, or the `repo_part.html` clause each fails a test in `tests/test_delegated_answer.py`.
