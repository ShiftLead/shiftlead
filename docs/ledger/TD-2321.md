## TD-2321: The note telling a session it holds too many temporary files does not say how to release a finished copy

**Priority:** Low
**Type:** debt
**Added:** 2026-11-26
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** f8c955a9894e47069be307b76e6e20ae

**Why:** #4841 (TD-2313) changed design §4.6, *A seat is told instead*, to say what the one `system` note to a seat over its file budget tells it to do: *move a copy under `copies/`, release a finished one by its rename to `.gone-<name>`, remove what it no longer needs; test runs go by themselves within two hours* (`docs/design/4.6-transport.md`, lines 1341 and 1342 at `71dcbb683`). The PR changed no file under `src/sessionorc/`, and the note says nothing of the rename. `seat_note` (`src/sessionorc/scratch.py`, line 381, sent by `agent_tick.py`) ends *Move a copy you still need under $SHIFTLEAD_SCRATCH/copies/, and remove what you no longer need; test runs go by themselves within two hours.*

Probe at `71dcbb683`, `scratch.seat_note({'record': 'ao-w', 'since': 'T', 'inodes': 260000, 'largest': [{'name': 'copies', 'inodes': 200000}]})`: the text returned holds neither `.gone` nor *rename*.

So a seat told it holds too many files is told to *remove* what it no longer needs, which for a review copy is the `rm -rf` that a permission hook refuses an unattended seat (TD-2313's Why), and is not told the release that works. Of the advice, the note's test (`tests/test_seat_budget.py`, `test_the_note_names_the_count_the_largest_and_what_to_do`) asserts only the `copies/` path and the test-runs clause, so it passes either way. TD-2313's live check reads the temporary space's file count and the seats' `copies/`, not the note.

**Location:** src/sessionorc/scratch.py (seat_note); tests/test_seat_budget.py; design 4.6

**Fix:** Add the release to `seat_note`'s words as §4.6 *A seat is told instead* gives them: release a finished copy by renaming it to `$SHIFTLEAD_SCRATCH/copies/.gone-<name>` (§4.6 *A seat is told instead*), which the next hourly or pressure pass removes (*A seat releases its own*). Extend the note's test to assert it. The design already says this, so it changes nothing there.

**Done when:** The over-budget note tells the seat to release a finished copy by renaming it to `.gone-<name>`, and the note's test fails without those words.
