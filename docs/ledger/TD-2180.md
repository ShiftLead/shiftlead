## TD-2180: Tests of a container node's logins read its offers and print its blockers unchecked

**Priority:** Low
**Type:** debt
**Added:** 2026-11-25
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** b2f703a283294b92a4c7bf383410d5f1

**Why:** #4551 (TD-2071 slice 9) reads a container node's logins; two of its lines can be changed with `tests/test_switchover.py` (93 tests) still passing. Evidence, each by replacing the line in a worktree on `origin/main`: (1) in `host_logins`, `_offer(tools[tool], read_at, ident.get("plan"))` replaced by `_offer(tools[tool], folder, ...)`, the folder as the node writes it (`/shiftlead/profiles/p`, not on the home): the offer would be read from a path that is not there. The test's `Fake` adapter's offer ignores its folder, so only the identity read's path is asserted (`seen == [root / "profiles" / "p"]`). (2) In `cmd_switch_over_check` (`src/shiftlead/cli.py`), the line `blockers += more` after `node_made, more = switchover.node_logins(answers)` removed: a node whose `profiles.yml` cannot be read, or whose login has no name in the answers, is then never printed or counted by the check, and the cli test (`test_the_check_and_its_answers_read_a_container_nodes_logins`) only asserts those two messages are absent.

**Location:** src/shiftlead/switchover.py; tests/test_switchover.py

**Fix:** In `tests/test_switchover.py`: give the `Fake` adapter an offer that records the folder it is given and assert it is the folder on the home; add a cli check where a container node's `profiles.yml` is malformed, asserting the check prints its blocker and exits 1. Check each fails with its line reverted.

**Done when:** A test fails when `_offer` is given the node's own folder instead of where it is on the home, and another when the check drops a container node's blockers.
