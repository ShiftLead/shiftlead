## TD-2098: Release a test run's temporary files when it ends, and make its repos smaller

**Priority:** High
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** c02ec1d9ee7544f6aed11fba51b163c0
**Part of:** TD-2080

**Why:** Part of TD-2080: a test run keeps its inodes after it has finished. Read on 2026-11-23, one suite run held about 188,000 inodes, about 43% of them inside roughly 2,100 throwaway `.git` directories and about 28,000 of them git's sample hooks. Two such trees (`pt` and `t.PQjB/p`, each its own `--basetemp`) held 92% of `grinder-ao-1`'s 410,000 inodes, so pytest's keep-one-run limit did not bound them and the hourly sweep leaves a live seat's scratch alone. TD-2081 reclaims only under pressure. Paul, 2026-11-23: kmaster runs without the `/aot` pool, so what would hit a regular user shows here first, which makes releasing inodes the main defence.

**Location:** tests/conftest.py, pyproject.toml, design §4.6 *Temporary space is a pool of its own*

**Fix:** 1. **Release a run at its end.** When a suite run ends with exit status 0, remove its base temp, a caller's `--basetemp` included; any other status (a failure, an error, an interrupted run, no tests collected) keeps its tree for reading. Do it once, in the xdist controller or a run without xdist, after the workers have finished. Not `tmp_path_retention_policy = "failed"`: `pyproject.toml` records why (it removes a passing test's directory at once, and a later test can get the same path).
2. **Make each test repo smaller.** Point the suite's `git init` at a template holding an empty `hooks/` and an `info/` with an empty `exclude` (`GIT_TEMPLATE_DIR`, set in `os.environ` for the run in `tests/conftest.py`, so subprocess agents, clones and the adopt scripts get it too). No sample hooks are copied, a test that writes a hook still finds the directory, and `tests/test_repo_adopt.py` and `tests/test_disk_book.py`, which write `.git/info/exclude`, still find it.
3. **Say so in the design.** Add the run's release to §4.6 *Temporary space is a pool of its own*, beside the sentence on shiftlead's own tools.

**Done when:** The full suite passes. A passing suite run, with and without xdist and with a `--basetemp` of its own, leaves no base temp behind. A run with a failed test keeps its tree. A concurrent run's tree is untouched. A repo made by the suite's `git init` holds no `*.sample` file and has a `hooks/` directory and an `info/exclude`. A full suite run's peak inode count, read before and after, is recorded in the PR.
