**Resolved:** 2026-11-05 (PR #2936)

**Done when:** tests that each writer appends its record with the text shape the design gives (`FAILED` ids on the home's own main run's status only, none on a PR's); that the open-PR read writes a PR's `precheck-fail` as main's pass writes main's; that a head whose status list holds fail, pass, fail writes two records dated by the statuses' `created_at`, a red re-run green between two readings still one, a re-read of an unchanged status none, a status created before `start` on a head first read after it none, a status older than the kept months none, a restart with an open head's status older than two months none twice, and status ids `12` and `123` on one head two records (the token match); that an `error` status counts as red; that `ao team start` and `ao team flow --apply` write `start` and `apply` with the team's repo, as the card's Start and Apply do, the New session form's plain create and `member_submit` write `new-session` and a scheduled start none, `ao host rebuild` writes `host-rebuild` with no repo, Send to reviewer writes `send-to-reviewer` from inside `inbox_hand`, and push on writes `push-on` for a new endpoint and nothing for a renewal naming a held `replaces`; that a press on a directory in no registered repo, or with an empty `dir`, writes nothing, and `repo_named` maps a checkout through a symlink to its registry name; that `witness_press` forwarded from a node is refused; that `witness_press` is refused to a session (the CLI going on) and for an unknown word, and that a failed Apply sends none; that `start` is written at the agent's start, once; that a colliding id is redrawn; that an unreadable line is skipped on read; that a record from a detached writer lands whole beside one from the loop; that a late record goes in its own month's file and reads in `at` order; that the prune keeps thirteen months; that `witnessed/` is in the nightly tarball; that a node host writes no record; and that a writer's failure leaves its act standing.
