In a copy of it with `blocked_ids` and `gates` added to the fixture, the same change failed it, and the unchanged code passed.

The refusal itself is held elsewhere: that change fails `test_a_chain_of_gated_blockers_that_ends_in_a_wait_is_asked_early_and_counted_nowhere` and `test_the_inbox_and_the_homes_refusal_read_the_held_builds_work`.
