**Why:** PR #3086 (TD-1483) added `[precheck-paths]` to `docs/cadence.toml`: a PR whose diff matches only docs globs runs `pdm run test-docs` (plus host-log validation, ledger check, lint) in place of `precheck`. AGENTS.md (§"Session Hygiene") still says: "`agent-cadence run precheck.py --pr <n>` runs `docs/cadence.toml`'s `precheck` on its head and records it". That is no longer true for a docs-only PR (archived TD-1483: #3090 ran the light command in 91 s, #3086 the full suite in 198 s). Neither AGENTS.md nor design §6 *The precheck on main* (6-policies.md:1626) mentions the narrower gate or that main's own precheck is what still runs the whole suite; the only statement is a comment in cadence.toml. A reader (or a reviewer judging a docs PR's green) cannot learn from the repo's docs that `cadence/precheck` green on a docs-only PR means the `test-docs` list, not the suite.
