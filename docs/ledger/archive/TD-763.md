## TD-763: Build TD-730 (2): the tagging seat — `seat.tags` on the techlead, the tick's `by: tag`, `entry.md`'s Team rule, `ao org check`'s stale and missing declarations

**Priority:** Medium
**Type:** feature
**Added:** 2026-10-15 (TD-730's design, the designer)
**Owner:** grinder
**Kind:** build
**Status:** Resolved
**Blocked by:** TD-762
**Location:** design §4.4 *An entry names its team* (*Who writes it*, *An untagged or unknown entry is handed to a techlead*, *A stale team*), §4.9b *Seats with a trigger*, §6 rule 3 (`tag`), §4.7 `ao org check`, §4.9 *Add an entry to the ledger*; `src/shiftlead/teams.py` (`Launch.trigger` ~L124, the record's `seat` ~L162, `_trigger` ~L957); `src/sessionorc/agent_tick.py` (`_seat_due` ~L2586, its `team` branch's cause model and `seat_filled`, the fill's cause line); `src/shiftlead/briefs/entry.md` and the `techlead` preset's brief; `src/shiftlead/orgcheck.py` (`check` ~L157); the Start's checks in `src/shiftlead/teams.py` and the Start dialog's plan

**Why:** TD-730. An entry filed outside a team, or by hand, lands with no team; somebody has to tag it, and a team removed leaves entries naming it.

**Fix:**
- **`ao team start`** (with a repo whose reading has no `declared_teams` passing) writes the techlead seat's mark as `seat: {trigger: asks, tags: true}` — `tags` a boolean beside the string-valued trigger, so `Launch` gains a `tags: bool` written into the record's `seat` (not into `trigger`'s `dict[str, str]`); `ao team list --json` carries it. It refuses a team whose repo's definitions hold two or more teams and whose ledger's `Team` vocabulary does not name it, in the words of §4.4 *The move from one team to two*, reading `declared_teams` from the home's repo reading; the Start dialog shows the same refusal.
- **The tick**: for each repo whose reading has `needs_team`, the tagging seat is the repo's record carrying `seat.tags` of a **live** team (§4.9), whose `team` is first in `declared_teams`' order (an undeclared team after, by name). `_seat_due` tests `seat.tags` before its `asks` branch: while `asks_waiting`, `by: asks` — the standing `seat_due` kept only when its `by` is `asks`, else a fresh `{at, by: asks}` (today's `s.seat_due or …` would hand back a standing tag due) — else a `_tag_cause(s, records)` — `{by: tag, ids}` only where `s` is the repo's tagging seat (reading the repo's `needs_team` and `declared_teams` and the live-team test), `ids` the set difference from every `seat_filled` tag entry's ids. Neither clears the other's due. The tag entries of `seat_filled` are kept while any of their ids is in `needs_team` (coverage, not `same()`'s equality, which compares `by/member/ask` and would match every tag cause); `_tag_cause` prunes the tag entries of `seat_filled` as the `team` branch prunes its own. **The fill** (agent_tick ~L2791): `cause` is taken for `trigger == "team"` or for a `tags` seat whose `seat_due.by == "tag"`, and for nothing else, so a techlead's `asks` fill gains no cause line, no `seat_filled` entry and no `for:` mark, as today (the handed-entry check that reads `cause.get("ask")` passes a tag cause harmlessly); `filled_for` (~L118) gains an `ids` branch, printing a tag cause from `cause["ids"]` joined by ", ": *you are filled for: tag — TD-801, TD-802*. `_tag_cause` is not reached while a question waits, so its pruning pauses then; coverage is recomputed once the question clears, which is enough. **The idle close**: `_seat_done` (~L2541) is True for trigger `asks` when `seat_due.by == "tag"` (the due is the next fill's, §4.4), and False for an `asks` due, as today. It sets `seat_due: {at, by: tag, ids}` on it while uncovered ids stand. The fill's cause line names them. `ao repo`'s *needs a team* line gains *— handed to <seat>*, or *no techlead seat to tag them*, *<seat>'s team is stopped*, or *no techlead seat carries tags yet — the next Start of <team> writes it*. Rule 3's ceiling and the wait on its own PR apply unchanged.
- **`entry.md`** (and, through it, the techlead preset) says: where the ledger's `Team` vocabulary names two or more teams, write `**Team:**` (and never where it does not: an undeclared field fails `ledger.py --check --since`) — your own team unless the work is plainly another's, a designer's builds the designed entry's, a handed entry the `entry.team` it carries, else the team the words point to. Filled `by: tag`: tag every listed id in one ledger PR; where two readings stand, open the PR with your choice and `steer` the person with it as `--default`.
- **`ao org check`**: a lack for a declared name that no definition of the repo holds (naming its entries); where the repo's definitions hold two or more teams, for each the vocabulary does not name, whatever its size (none included); and for `needs_team` ids where no team of the repo has a techlead seat.
- **Tests** (in `tests/test_cli_teams.py`, `tests/test_seat_policy.py`, `tests/test_cli_org.py`, beside each module's own): the start writes `tags`, refuses an undeclared team of a two-team repo, and passes a one-team repo, a declared team and a repo with no reading; a stopped team's seat is never the tagging seat; an `ask` and a tag set both standing: the due is `asks` while the question waits (a question left standing still holds it), then `tag`; a tag due standing when an ask arrives becomes `asks`; an idle seat with a `tag` due is closed and filled on the next tick, one with an `asks` due is held; an `asks` fill writes no `seat_filled` entry; `filled_for` prints *tag — TD-801, TD-802*; {A, B} filled, A tagged, C joined: the new due carries {C} alone; `ao repo`'s *handed to*, *no techlead seat*, *team is stopped* and *no techlead seat carries tags yet* lines; the tick picks the first declared team's seat, fills it once per id set and again when an id joins, the new due carrying only the new id; no `seat.tags` record means no due; `entry.md` carries the rule (a doc-bound test); `ao org check`'s three lacks.

**Done when** an untagged entry on a multi-team repo fills the first declared team's techlead seat once, `entry.md` tells every filer to write the team, `ao org check` names a stale or missing declaration, and every listed test passes.

**Related:** TD-730, TD-762, TD-764.

**Resolved:** 2026-10-16 (grinder-ao-1) — `ao team start` writes the techlead seat `{trigger: asks, tags: true}` (`Launch.tags`; `ao team list --json` carries `techlead_tags`) and refuses a team a two-team repo's ledger does not declare (`teamrun.undeclared`, read from the home's `repos` reading, so the Start dialog's start says the same); the tick's `_tagging_seat` and `_tag_cause` set `seat_due: {by: tag, ids}` on the first declared live team's seat, `asks` first while a question waits, covered by set through `seat_filled`; `_seat_done` closes an idle seat with a `tag` due, the fill carries the cause and `filled_for` prints *tag — TD-801, TD-802*; `ao repo` says *handed to <seat>* or why nobody is (`teamrun.tagging_seat`); `ao org check` names the three lacks (`orgcheck.team_lacks`); `entry.md` carries the Team rule and the tag fill's one PR, and the techlead brief allows that PR. Tests in `tests/test_seat_policy.py`, `tests/test_entry_team.py`, `tests/test_cli_teams.py`, `tests/test_cli_org.py`, `tests/test_repoconfig.py`.
