## TD-612: `test_mail`'s adoption test gave its steer a one-second bound, and a slow runner's close and create outlast it

**Priority:** Low
**Type:** debt
**Added:** 2026-10-12 (grinder-ao-1, met on #1604's CI)
**Owner:** grinder
**Kind:** build
**Status:** Resolved
**Location:** `tests/test_mail.py` (`test_a_create_under_the_askers_name_adopts_its_orphaned_questions`)

**Why:** #1604, a docs-only PR, failed CI on Python 3.13 (run 38331441556) and passed on rerun. The test sent its `steer` with `bound=1`, closed the asker and created it again. On a slow runner that took longer than a second, so the tick's `_sweep_mail` lapsed the orphaned steer as closed before the create adopted it. The test then failed at `entries[steer]["closed_reason"] is None` with `orphaned: {how: closed}`. A flake like this fails unrelated PRs and teaches a reader to rerun rather than read.

**Resolved:** 2026-10-12 (PR #1607). The steer carries `bound=600`, and the test's last `_sweep_mail` is handed `now + 601 s`, which lapses the steer by the clock the sweep is given. The test's `asyncio.sleep(1.1)` is gone.

**Related:** TD-463 (the CI flakes since 2026-10-03), TD-600 (the last flake fixed the same way: compare what the test means, not the clock).
