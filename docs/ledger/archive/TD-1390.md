**Why:** ledgerboard's TD-045 was revised after TD-1295's design (revision 2, its #141, Paul's go; ledgerboard TD-047/TD-048): a check names a source, agent-cadence's `hostlog.py` reads it and counts, a record counts only when its `repo` equals the ledger's `<repo>` id, and the host's own file allows a folder and marks kinds public.
