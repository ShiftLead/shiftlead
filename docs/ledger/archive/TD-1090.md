## TD-1090: The `sweeper` seat preset and its built-in brief, and the `swept: <duration>` trigger read from the board's `Swept:` stamp

**Priority:** Medium
**Type:** feature
**Added:** 2026-10-26 (the designer, from TD-1061)
**Owner:** grinder
**Kind:** build
**Status:** Done — built in #2467 and #2468 (2026-10-27)
**Location:** `src/shiftlead/repoconfig.py` (the role presets: `sweeper` beside `auditor`); `src/shiftlead/briefs/sweeper.md` (new); `src/shiftlead/org.py` (`TRIGGERS`, the trigger's parse beside `every`'s); `src/sessionorc/agent_tick.py` (the seat pass, beside the `every` cause at ~2916; `_seat_done`; `_fill`, which records the `swept` cause in `seat_filled`); `src/sessionorc/workorders.py` (`read_boards`, `_against_origin` and `Origin`: origin's content kept in every state, `swept: {at, deep_at}` derived from it, beside `source`); `src/sessionorc/agent_tick.py` `_read_boards` (a plain re-read carries `swept` forward); `src/shiftlead/ui/` (the seat card's *on call* words); design §4.9b *Seats with a trigger* and *The sweep* (the preset, its trigger, what it may change), §6 rule 3 (`swept`), §4.8 (the `sweeper` row), glossary *sweeper*

**Why:** TD-1061: the weekly stranded-work sweep (cadence §3.11) ran only when a person remembered `/stranded-work` — 38 of 58 open board items past 14 days on 2026-10-26, two repos never swept. The seat rule already runs this repo's auditors; a sweep needs a preset, a brief and a trigger keyed to the board's own stamp.

**Fix:** (1) A `sweeper` preset in `repoconfig`: `kind: seat`, `brief: sweeper.md`, no lane, no grants, the worker's context, label *Sweeper*, an icon from the existing set, a `message`. (2) `briefs/sweeper.md`: run the repo's procedure from `dev-cadence path procedures/stranded-work.md` in a pinned repo, else `docs/procedures/stranded-work.md`, never copying its steps; deep when `Swept-deep:` is older than the cadence's `deep-sweep-every` or absent, else quick; and §4.9b *What it may change*, line for line (verified closes with how, never on a ref's state alone; ledger overdue work with ids from `ao td next`; the stamp-only push; every other change a PR reviewed as docs; the person's items as one `note` or an `ask` per decision; no answer for the person, no `Due:` moved, no other repo's board). (3) The trigger `swept: <duration>` in `org.py` (`TRIGGERS`, parsed as `every`'s units) and on the record as `seat: {trigger: swept, after: <d>}`. (4) The boards reading gains `swept: {at, deep_at}` per repo, derived in `read_boards` from origin's content whenever `_against_origin` read it — `Origin` carries it in every state (behind, local, both; matching, the checkout's file is the same), after a write-back the tree it wrote — written only by a read against origin, a plain checkout read (`fetch=False`, the clock's re-read) or a skipped fetch (`fetch_case: skipped`) carrying the last `swept` forward, in `_read_boards`, which holds the last reading, copied per board by its `root` and `label`; the cause tests the reading's `error` first and sets nothing while it stands; null for no board file on origin or no origin read yet, `{at: null}` when origin's file lacks the line; the parse per §4.9b (*The parse*: the cadence reader's `SWEEP_RE`/`SWEEP_DEEP_RE` ported verbatim, `.search` over the file — the first `Swept:` line carrying a date; a non-calendar date reads as absent, a future date is not due until it ages). The tick's cause: due when `swept` is a reading and its `at` is null or older than `d` — a null `swept` sets nothing — **and** `d` has passed since the seat's last `seat_filled` entry `by: swept`; `by: swept`; `_fill` appends `{by: swept, at}` to `seat_filled` as it does for `team` and `tag` — its `cause` gate (`trigger == "team" or tagged`, ~3010) takes `trigger == "swept"` too, else nothing is written and a stampless pass refills every tick — but the fill's prompt gets no *you are filled for* line (`filled_for` returns none for `swept`, or the `seat_filled` write is split from the `said` path); an unreadable board sets nothing; `_seat_done`'s trigger tuple (`prs`, `every`) gains `swept`, so a cause met during a run is the next fill's and the idle seat still closes. The brief's stamp push is §4.9b's worktree form (a stamp-only commit on a detached fresh `origin/<default>`, pushed `<sha>:<default>` with `ALLOW_MAIN_PUSH=1`, redone if main moved). (5) The seat card draws §4.9b *What a sweep seat's card says*, the first line of it (the others are TD-1091's). The seat's worktree is `sweep-<team>`, as every team session's (§4.9); the brief names its PR branch `sweep/<date>` and `ao td next` for a ledger id.

**Done when:** tests show a `seats:` line `{role: sweeper, trigger: {swept: 7d}}` parses and starts as a seat with the built-in brief; the reading carries `swept` from origin's board in each `_against_origin` state (a checkout behind, local or both still reads origin's stamp), a plain checkout re-read leaves it unchanged, null for no board file on origin (no cause), `{at: null}` for a board without the line (due), a skipped fetch leaves `swept` as it was, the stamp is the first `Swept:` line carrying a date anywhere in the file (a `Swept: junk` line above it skipped, as `/attention` reads it), `2026-13-45` reads as absent (due), a future date is not due; an `error` reading with a prior `swept` fires no cause; the cause is due with a stamp 8 days old or none, not due with one 2 days old, and not due again within 7 days of a fill whose run wrote no stamp (the fill wrote `{by: swept}` to `seat_filled`, and its prompt has no *you are filled for* line); `_seat_done` closes an idle seat whose `swept` cause was met during its run; an unreadable board fills nothing; the brief names the procedure by both roads and holds every *What it may change* rule (a test reads the brief for them); `pdm run test` and `pdm run lint` pass.
