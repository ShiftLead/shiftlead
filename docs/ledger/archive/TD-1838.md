## TD-1838: cache_capture.py writes a zstd request raw, and show reads no Responses request

**Priority:** Low
**Type:** debt
**Added:** 2026-11-14
**Owner:** grinder
**Kind:** build
**Status:** Resolved 2026-11-14
**Id take:** f3b1fb24f35445d09d38804f43a38149

**Why:** Grok's cache capture (TD-1637, 2026-11-14) found two gaps in `scripts/cache_capture.py`. Its docstring says `serve` writes each request body decoded, but Grok 1.0.77's interactive turn request is sent with a zstd body, which `serve` writes raw (the standard library has no zstd before Python 3.14), so the capture had to be read with `zstd -d` by hand. And `show` has a provider row for Anthropic's Messages shape only: an OpenAI Responses request (`input`, `tools`, `prompt_cache_key`, the usage's `input_tokens_details.cached_tokens`) prints its top-level sizes and raw usage alone, so the block-by-block layout §4.3 records was worked out by a script of the builder's own.

**Location:** scripts/cache_capture.py

**Resolved:** 2026-11-14 (PR #3867)
