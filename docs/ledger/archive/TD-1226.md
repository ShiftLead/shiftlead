**Why:** design §4.2 *No live member* says a manager on call is closed between its fills over working members as its normal state, so the item passes for it, filled or not: the tick runs the members (§6 rule 3) and closing the seat orphans nobody. The card keys the check on the control graph with no seat exemption, so a filled manager on call, idle over working members, reads ✗ *no live members (grinder-ao-1 — stop the team first)* while rule 3 closes it anyway (`agent_tick._seat_pass`). The hint is wrong for a seat.

**Fix:** in the Ready-to-close checks, pass the *no live members* row for a record that is a manager on call (its record's `seat.trigger` is `team`, as `teams.py` writes it for an on-call lead and `agent_tick`'s seat pass reads it; a standing manager has no `seat`), keeping it for a standing manager, a director and a hand-attached controller; add a test beside the existing Ready-to-close tests.

**Done when** a filled manager on call over working members reads the row as passed, a standing manager over working members still reads ✗ *stop the team first*, and the test covers both, building the on-call record with `seat: {"trigger": "team"}`.
