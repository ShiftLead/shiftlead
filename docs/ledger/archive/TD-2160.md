**Owner:** grinder

**Status:** Resolved 2026-11-25

**Why:** Part of TD-2077 (design §4.9c *A closed record is kept thirty days*, §4.4 *The stage record*, §4.7 `ao stage show`). The tick removes a closed stage record from the state branch's head after thirty days, so a comparison weeks after the switch-over would have to replay the branch's history to read the entries it measures.

**Ask:** Should the grinders build the design that records what each flow's run leaves behind, or run one more review round first?

**Location:** src/shiftlead/stage_make.py, src/shiftlead/stage_acts.py, src/shiftlead/stagerecord.py, src/shiftlead/cli.py, src/sessionorc/agent_stage.py, design §4.9c

**Resolved:** 2026-11-25 (PR #4675)
