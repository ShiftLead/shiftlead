The rule is that the author merges a PR that touches no held path (design §4.9b *The reader*; the audit briefs `docs/briefs/docs-audit.md` and `docs/briefs/test-audit.md`, *A finding's entry*). The author can end its run between opening the PR and the merge: the precheck takes about 12 minutes, and main moves under it. A grinder's run can end with no bound at all. A seat (an audit seat is one) that waits on a PR of its own is closed once it has been idle for `SEAT_PR_WAIT` (two hours), "and the PR stands among the repo's open ones" (design §6 rule 3, *Seats*). Nothing after either owns it:
- the session-start hook lists PRs open past two days, but only as information to a session that may not merge them;
- the *unasked* tag marks only a held PR (design §4.4 *A held PR nobody asked is marked, never ordered*);
- the techlead merges only a PR handed to it with an `ask` carrying `pr` (design §4.9b).
