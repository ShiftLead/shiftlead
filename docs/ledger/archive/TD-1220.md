## TD-1220: No test pins `cadence.SEED`'s value, so a wrong seed passes every test and reads every agent-cadence pin as not at the oldest

**Priority:** Medium
**Type:** debt
**Added:** 2026-10-29 (test-audit-ao-1, auditing #2642–#2651)
**Owner:** grinder
**Kind:** build
**Status:** Done 2026-10-29 — #2657 (grinder-ao-2).
**Resolved:** 2026-10-29 (PR #2657) — `test_the_seed_is_a_full_sha_apart_from_both_oldest_points` (40 hex, not `OLDEST` or `OLDEST_V2`) always runs; `test_the_seed_is_agent_cadences_first_commit` asserts the agent-cadence checkout's `rev-list --max-parents=0 HEAD` is exactly `[SEED]`, and fails with `183de9c`. Lasting content: `tests/test_pinned_cures.py`.
**Location:** `src/sessionorc/cadence.py` (`SEED`); `tests/test_pinned_cures.py` (`test_a_pin_after_agent_cadences_seed_descends_on_either_history`), `tests/test_cadence_pin.py`, `tests/test_repo_seams.py`

**Why:** #2642 added `SEED = "183de9c…"` and #2646 changed it to `35b4b4a…` because the first value was not agent-cadence's first commit. Every test reaches the constant symbolically or patches it: `monkeypatch.setattr(cadence, "SEED", seed)` (`tests/test_pinned_cures.py:255`) and `"seed": cadence.SEED` (`tests/test_cadence_pin.py:135`, `tests/test_repo_seams.py:224,295`). Probe from a clean worktree at `origin/main` 92df926: setting `SEED` back to `183de9cfa899e0def9e4420eb4af1e2fd0faa935` and running `pdm run pytest -q tests/test_pinned_cures.py tests/test_cadence_pin.py tests/test_repo_seams.py` gives `31 passed, 1 skipped`, the same as unmutated. So the one value that decides whether a real pin on agent-cadence's orphan history reads an age (`descends`, `seams.py:211`) has no check, and the mistake #2646 fixed would pass again.

**Fix:** a test that holds `SEED` to the fact it names: where `$AGENT_CADENCE_SOURCE` (default `~/agent-cadence`) is a checkout, `SEED` is a commit there with no parents (`git rev-list --max-parents=0`), skipping otherwise; or, with no checkout needed, assert its shape (40 hex) and that it differs from `OLDEST` and `OLDEST_V2`.

**Done when:** setting `SEED` to any other commit fails a test.
