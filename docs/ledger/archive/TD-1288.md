## TD-1288: No test holds three guarantees of #2740's `TaskStop` end: its open-calls drop, its place before the `queued` gate, and its sure end

**Priority:** Low
**Type:** debt
**Added:** 2026-10-30 (test-audit-ao-1, auditing the last ten merged PRs)
**Owner:** grinder
**Kind:** build
**Status:** Resolved
**Location:** `src/sessionorc/agent_tick.py` (`_apply_event`'s `subagent_stopped` block, and `_track_call`'s `threads.pop(stopped, None)`); `tests/test_claude_adapter.py` (`test_a_task_stop_ends_the_listed_subagent_it_names`, `test_a_task_stop_ends_the_stopped_subagents_permission`), `tests/test_subagents_live.py`

**Why:** #2740 (TD-1280) put three decisions in `agent_tick.py` that the tests it added do not pin. The code comment says the end runs *before the `queued` gate and whatever the event's age … so this end is the session's last sure one*, and `_track_call`'s docstring says a thread's open calls go at a `TaskStop` of it. Probes at `origin/main` d013a096e, each edit made alone and restored after, then `PYTHONPATH=$PWD/src pdm run pytest -q -x tests/test_claude_adapter.py tests/test_subagents_live.py` gives `58 passed` every time:
- `_track_call`'s `if (stopped := event.get("subagent_stopped")) …: threads.pop(stopped, None)` deleted: a stopped subagent's open calls stay in `_open_calls`, where `_await_permission` can match a later permission to them;
- the block's `if (stopped := …)` changed to `if not queued and (stopped := …)`: a replayed (`queued`) `TaskStop` then leaves the stopped subagent's waiter and entries standing, against the comment;
- `sure=True` changed to `sure=False` in the block's `_end_entries`: the stop no longer sets the session's last sure end (`_sure_end`).
The Resolved line of TD-1280 claims only that dropping the count-down, the waiter end or the entry end each fails a test (probed: 1 failed each), though it also names the `queued` gate and the open-calls drop; these three are the rest of what the change says. `_await_permission` (`agent_hook.py`) keys a waiter by `_take_call`, which reads `_open_calls`, so a leftover call would be matched by a later permission from that `agent_id` with the same `call_sig`.

**Resolved:** 2026-10-30 (PR #2754) — `tests/test_claude_adapter.py`: `test_a_task_stop_drops_the_stopped_subagents_open_calls`, `test_a_queued_task_stop_still_ends_the_stopped_subagents_prompt`, `test_a_task_stop_that_ends_an_entry_is_a_sure_end`; each of the three edits above, probed alone, fails one of them.
