## TD-1262: A path with a non-ASCII letter, a space, `#`, `,` or `=` in it is cut at that character in the Focus pane, so an existing file is never a link

**Priority:** Low
**Type:** debt
**Added:** 2026-10-30 (grinder-ao-2, found building TD-1259)
**Owner:** grinder
**Kind:** build
**Status:** Done
**Resolved:** 2026-10-30 (grinder-ao-2, PR #2722) — `AO.pathRuns` takes any letter, mark or digit, and `#`, `,` and `=` in a segment after the first `/` (so `--file=src/a.py` still asks `src/a.py`), and a run holding one is followed by its pieces without them, the first the host resolves the link (the review's catch: `src/a.py#L12`, `a/b.py,c/d.py` and `x/a=b/c.py` linked their files before); a trailing `,` is still cut and a space still ends a run. `test_the_runs_a_row_yields` finds the Done-when shapes whole and the pieces after them, `pathLinksHtml` links a piece where the whole is no file, the pane asks eight runs with their pieces eight paths at a time (the second round's catch: pieces had taken the cap's slots), and on a scratch home each underlined and Ctrl+click sent its whole path. §4.6 says which characters a run takes.
**Location:** `src/shiftlead/ui/static/app.js` (`AO.pathRuns`: the character class `[\w.@+-]`, ASCII `\w` with no `u` flag); `tests/test_ui_focus_paths.py` (`test_the_runs_a_row_yields`); design §4.6 *A path in the pane is a link*

**Why:** Paul, 2026-10-30 (TD-1259): *if a file exists on the machine it gets a link*. Probed at TD-1259's branch: `AO.pathRuns` gives `docs/caf` for `docs/café/notes.md`, `Files/a.txt` for `~/My Files/a.txt`, `build/a` for `build/a#1.txt`, `out/a` for `out/a,b.txt` and `dir/name` for `dir/name=v.txt`, so the host is asked a path that does not exist and the file stays text. A path in backticks, quotes or brackets, and one after a bullet, is already found whole.

**Fix:** widen the run to any letter (`\p{L}`, `\p{N}` under the `u` flag) and to `#`, `,` and `=` inside a segment, keeping the tail's sentence stop (`,` at the end is still cut); a space stays a stop, since prose cannot be told from a path with one by shape, unless the design decides to ask the host for a run's longest existing prefix across spaces. Say in §4.6 which characters a run takes.

**Done when:** `pathRuns` finds `docs/café/notes.md`, `build/a#1.txt`, `out/a,b.txt` and `dir/name=v.txt` whole, a trailing `,` is still cut, and the existing shapes in `test_the_runs_a_row_yields` hold.
