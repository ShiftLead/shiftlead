**Owner:** grinder
**Kind:** build
**Status:** Resolved 2026-11-18

**Why:** The precheck of #4087 (2026-11-18) failed in `tests/test_statusline.py::test_the_reporter_leaves_the_status_lines_group_and_holds_none_of_its_pipes` with `OSError: [Errno 98] Address already in use` binding `/tmp/aosl-eaves_the_s0/agent.sock`, and nothing was left at that path afterwards. The `home` fixture names its directory `/tmp/aosl-<the last 12 characters of tmp_path's name>`, and pytest's `tmp_path` name is the test's own name cut short plus a counter, so the path is the same in every run of that test: two prechecks running at once on this machine (two grinders' PRs) bind the same socket, and the second one's test goes red for a reason unrelated to its PR.

**Location:** tests/test_statusline.py (the home fixture)
