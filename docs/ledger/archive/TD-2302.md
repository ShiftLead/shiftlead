**Why:** Test audit of #4790 (TD-2069 slice 2). Design §4.9e *A mark is never left standing*: a host agent that starts clears each `moving` mark; and a move counts toward no restart ceiling only once its launch has succeeded.

Each change below, made alone, left tests/test_login_move.py green (27 passed at ff1c0ef8d; the second at 22f1e01c9, 25 passed):

- `self._clear_moving()` removed from `serve` (`src/sessionorc/agent.py`). `test_a_host_agent_that_starts_clears_every_mark` calls `_clear_moving` itself and starts no host agent on the marked record.
- `self._save(s)` removed from `_clear_moving`.
- `self._save(s)` removed after `_move_login` writes the mark, so a restart before the old session's close saves the record would read none. The PR's fact-check probed it at c225ebf6b: the stored mark is then absent at `handoff_of` and on entry to `_close`, and present after it.
- `and not r.get("error")` removed from `_counted`'s `login-move` row (`src/sessionorc/agent_common.py`). Probe, one failed `login-move` entry: unchanged it is counted, changed it is not.

With these, the changes of the entries filed beside this one and a few more this audit filed nothing on, made together at ff1c0ef8d, the whole suite passed (10475 passed, 26 skipped).

A break would leave a session marked after a restart, which `_movable` then passes over and, while its old session runs, no tick clears; or leave a failed move out of the count toward the session's restart ceiling.
