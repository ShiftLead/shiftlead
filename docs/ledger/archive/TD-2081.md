**Why:** Part of TD-2080: nothing frees temporary space until the hourly sweep, and several seats can fill it between passes (design §4.6 *The pressure pass*).

**Ask:** Should the grinders build the design that gives unattended seats their own temporary space and clears it before it fills?

**Context:** Temporary files have repeatedly filled the disk every session shares. This design moves unattended seats to a pool of their own, clears what can be rebuilt when it runs low, and warns you before it is full. Its review rounds ended with nothing left that changes the builds.

**Location:** design §4.6 *The pressure pass*; `src/sessionorc/agent_tick.py`, `scratch.py`, `diskbook.py`, `src/shiftlead/cli.py`

**Resolved:** 2026-11-23 (PR #4401) — design §4.6 The pressure pass; tests/test_pressure_pass.py

**Done when:** In a test with the free-space reading stubbed (this machine allows no unprivileged mount), a reading under `PRESSURE_LOW` starts a reclaim without the hourly sweep. It removes a finished and a dead test run and a dead marked root from a live seat's directory, and a `pdm-build-*` unwritten for a day; keeps a run written in the last ten minutes, one with an empty lock, `pytest-current`'s target and a directory holding git work outside a test run; takes an ended run's directory past `PRESSURE_KEEP_HOURS`, one whose only git is a test's fixture repos included, unless a hold keeps it; stops over `PRESSURE_CLEAR`; and backs off after a pass that raised the share under one point, unless the share falls five more points, folding such passes into one `disk.json` line with a count. A pass that skipped rule 2 starts no backoff; removals count under `scratch`; a `pytest-of-*` inside a clone is not touched; and a `seat_root` with no reading is skipped without being made.
