## TD-1235: The recent-links tick test failed once in a precheck and passes alone: the read for a new tool session did not happen

**Priority:** Low
**Type:** debt
**Added:** 2026-10-29 (grinder-ao-2, seen on #2667's precheck)
**Owner:** grinder
**Kind:** build
**Status:** Done 2026-10-29 — #2670 (grinder-ao-2). Seen once, not reproduced alone (three runs passed); the failed precheck ran beside a second precheck on the same machine.
**Resolved:** 2026-10-29 (PR #2670) — the likely cause, from the code (the failure was not reproduced), is a concurrent tick. The `agent` fixture runs `serve`'s `_tick_loop` (every `FAST_TICK`, 0.3 s) beside the test's hand ticks, and the test never parked it. A loop tick that is mid-gather when the test clears `_links_checked` writes the record's check time after the clear, and the test's own tick then skips the read. The other cause, a hook whose `adapter_id` had not landed, is ruled out: `rpc_hook` applies the event synchronously before it returns. The test now calls `park_ticks(agent)` first, as `test_crash_restart.py` does. Lasting content: `tests/test_recent_links.py`.
**Location:** `tests/test_recent_links.py` (`test_the_tick_merges_newest_first_a_url_once_and_keeps_twenty`, the `asked[-1] == ("conv-2", 0)` at :209); `agent_tick.py` `_refresh_links`

**Why:** #2667's precheck on c7307c8 (2026-10-29), a clean worktree running the whole suite, failed with `assert ('conv-1', 100) == ('conv-2', 0)` at `tests/test_recent_links.py:209`. The PR adds one ledger file. After the hook names a new tool session, `conv-2`, and the test clears `_links_checked` and ticks, no read happened at all: the last read was still the earlier `conv-1` read at cursor 100. `_refresh_links` reads in a thread (`asyncio.to_thread`) and sets `_links_checked[s.id]` only once the gather returns. So a tick that overlaps the test's own tick and lands after the clear would skip the record, and so would a hook whose `adapter_id` had not landed yet. Neither was shown by the failure itself. This is the third flake of this shape on 2026-10-29, beside TD-1218 and TD-1229, and each one costs a rerun of the whole suite.

**Fix:** `park_ticks(agent)` at the test's start, so every tick is one the test takes by hand.

**Done when** the test parks the fixture's loop and `pdm run test` passes.

**Related:** TD-1218, TD-1229
