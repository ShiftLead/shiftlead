## TD-1830: The rollup menu's Esc listener (focus outside the menu) is held by no test

**Priority:** low
**Type:** debt
**Added:** 2026-11-14 (grinder-ao-2, building TD-1339)
**Owner:** grinder
**Kind:** build
**Status:** Resolved 2026-11-14
**Id take:** 28e6ef03a7f14396af3ec775ed9b5f8b

**Why:** The rollup's own `Esc` road is held by no test. In the Org page's `#rollup` setup block of `src/shiftlead/ui/static/app.js`, a `document` `keydown` closes an open rollup menu on `Esc` with focus outside it (`if (e.key === "Escape" && rollupMenu) rollupClose(…)`), as §4.5a *every page: a pop-up menu* says every pop-up menu does (TD-1337). TD-1339 (this run's PR) fires the page-wide `pointerdown` and `keydown` listeners through `tests/test_ui_menu.py`'s probe, but that probe cannot reach the rollup's: the listener is registered only inside the Org page's init, when `$("#rollup")` finds a box, and `rollupMenu` is set only by `rollupPress` on a real row's button. Changing that line to `if (false) rollupClose(…)` (TD-1339's probe 3) still passes every test.
