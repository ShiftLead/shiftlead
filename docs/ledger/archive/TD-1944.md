## TD-1944: Each session has one scratch directory of its own, named in its environment and its brief

**Priority:** High
**Type:** debt
**Added:** 2026-11-18
**Owner:** grinder
**Kind:** build
**Status:** Resolved 2026-11-19
**Id take:** 688eb9fd6473411eb789bbb5c6f8e253

**Why:** Sessions put temporary files in /tmp, in the tool's own per-user temp directory and under ~/.cache/ao<topic>, where nothing can say whose they are or reap them (TD-1921: 4.4 GB under /tmp/claude-1000 on 2026-11-17). Design §4.6 *A session's scratch* gives each record one directory the sweep can find by its record id.

**Ask:** The disk clean-up design ran a fifth review round, which closed two gaps; should a session run one more round before the build?

**Location:** design §4.6 *A session's scratch*, §4.2 (`TMPDIR`), §4.3, §5; src/sessionorc/, src/shiftlead/adapters/, src/shiftlead/briefs/, docs/briefs/

**Resolved:** 2026-11-19 (PR #4160)

**Done when:** A session started in a scratch home has `SHIFTLEAD_SCRATCH` and `TMPDIR` set to its own existing `0700` directory under `scratch_root`, even where the adapter's launch env sets `TMPDIR`, named in its record's `scratch` and holding `owner.json` with the home; a Claude Code session has `CLAUDE_CODE_TMPDIR` set to it; a restart and a Resume of the same record keep the directory, and a create given a `scratch` outside `shiftlead-<uid>/` or whose `owner.json` names another record gets a new one, on the home and on a node, and a refill gets a new one; a Resume whose scratch directory the test deleted finds it made again, empty; a live record's directory removed by hand is back, with `owner.json`, after the next sweep, and a file under it dated eleven days back, and one under a scratch clone's `.git`, has its access time moved and its modification time unchanged, while a symlink under it to a file outside leaves that file's times unchanged; a `shiftlead-<uid>` that is a symlink stops the host agent's start; a 48-byte `scratch_root` with a ten-digit uid gives a scratch home whose `agent.sock` binds, and a 49-byte one is refused at start; with `SWEEP_TOUCH_FILES` stubbed to 2, a record holding three stale files has two touched and is logged *large scratch*; `scratch_root` shows on the Settings page's Hosts card; a session's own `ao new` cannot pass `scratch`; the briefs name it and no brief names `~/.cache/ao`.
