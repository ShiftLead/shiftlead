**Why:** #3977 (TD-1890) set `tmp_path_retention_count = 1` in `pyproject.toml`'s `[tool.pytest.ini_options]` so a passing run leaves one `pytest-N` directory, not three, in a shared 1M-inode `/tmp`. Its Done when names that value. No test or script reads it: `git grep -n tmp_path_retention tests scripts` finds only a docstring in tests/conftest.py (line 238). In my worktree, deleting the line and running tests/test_no_temp_leaks.py and tests/test_ui_inbox.py changes nothing, so a revert (or a pytest upgrade that renames the option) would let three runs fill the inode table again, which is how kmaster's `/tmp` failed on 2026-11-15, with no red test.

**Location:** tests/test_no_temp_leaks.py; pyproject.toml
