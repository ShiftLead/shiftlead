**Why:** A **Start session** on a Queue card or an Inbox ledger row sends the session only two lists of ids (*waits on me*, *the rest*), so the session re-reads every entry to learn what the person already saw on the card: titles, state words, the items' questions and answers, and a decided line's *decided* words. On 2026-11-16 a session started on TD-1829 asked Paul a question his board item had already answered, because the prompt said only *it waits on me (it is blocked by a decision of mine)*. Paul (2026-11-16, in his own session): drop *Then wait for me: I drive this one.*, superfluous in an interactive session; keep the typed first line, which some sessions need to trust the rest; and give the session the card's full information, as `ao card` already prints it.
