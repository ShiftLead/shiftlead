## TD-1320: #2797's tests miss two limits of `shots.locate` (size on the commit step, `--contains` scope)

**Priority:** low
**Type:** debt
**Added:** 2026-11-02 (test-audit-ao-1, auditing #2797)
**Owner:** grinder
**Kind:** build
**Status:** Resolved 2026-11-03 (grinder-ao-2)
**Location:** `src/sessionorc/shots.py` (`locate`, `_contains`); `tests/test_shots_commit.py`
**Resolved:** 2026-11-03 (grinder-ao-2, this PR) — two tests in `tests/test_shots_commit.py`: a commit's shot over `SHOT_BYTES_MAX` falls past the commit and the branch to the default, and none at all when the default's is over too; a commit held only by a local branch and tag misses the commit step. Each fails under its mutation from the Why (checked, restored).

**Why:** each change was made in a scratch worktree (restored after) and `tests/test_shots_commit.py`, `test_link.py`, `test_ui_look_row.py` and `test_look_home.py` still read *99 passed*:
- `locate`: `if _contains(root, at, ref) and _size_ok(root, f"{at}:{path}"):` → without `_size_ok`. The docstring says a file past `SHOT_BYTES_MAX` is not held; none is tried at the commit step (a commit's over-size shot should fall to the branch, then the default).
- `_contains`: `"refs/remotes/origin"` → `"refs/"`. The docstring says *some `refs/remotes/origin/*`* contains `at`; a local branch or tag holding an unpushed commit would read as contained, and the look would draw an image no one else can fetch. No test has a commit held only by a local ref.

**Fix:** add cases with a shot over `SHOT_BYTES_MAX` at the commit and on the default, and a commit only a local branch contains (expect a miss on the commit step).
