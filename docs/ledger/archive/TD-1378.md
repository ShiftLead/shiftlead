**Location:** design §4.5 screen 12 *Three verbs* (*A board line that names the entry is the question itself and is drawn instead of the entry's own block*), §4.5 Repo page *For you* (*A board line whose `Context:` names the entry is drawn in the row's place*), §4.5a *Queue card: what needs the person*, *Inbox row: ledger entry*; the cadence's end-of-rounds item (agent-cadence `cadence.md` §4.8 *The end-of-rounds item*, one board `decide` with `Answers: Go | One more round | Hold: <note>`), which names the plan's entry and carries no `Parts:`; the code that links a line to its entries: `item_home`, `asked_entries` and `attach` in `src/shiftlead/ui/queue.py` (TD-1355, TD-1362), where a line's entries come from its `Context:` refs alone (`item_home`'s and `asked_entries`'s reading, which `attach` places by); the vendored ledgerboard v2.3's `parse_parts()` (`src/sessionorc/ledgerboard/__init__.py`, SPEC *`Parts:`*), which parses `Parts:` into the item's `parts`, and v2.4's `covers()` (SPEC, vendored by TD-1370), which reads a parent's `decide` with the entry among its `Parts:` as covering it.

**Why:** a design's end-of-rounds question holds its builds with it (the person's layer §2.4 rule), so one board `decide` item gates several entries, and the person should answer it once. On 2026-11-04 the line *Should TD-1286's builds … go ahead as written* (`Context: TD-1286`, `Answers: Go (default) | One more round | Hold: <note>`) gated TD-1286 and its builds TD-1356, TD-1357, TD-1358, TD-1360 and TD-1363, each `Blocked by: decision (paul) — docs/user_attention.md, 2026-11-04 item`. The Queue showed six Decide items with the same question, only TD-1286's offering the line's answers (Go); the builds' blocks offered **Lift the hold** and **Answer…**, each of which would have answered a different question than the one asked (the TD-1355 harm, five times over). The cause, read from the code: TD-1355 draws a line in the place of the entry its `Context:` names, and this line named only the parent; the builds point at the item by its date alone, which no reader resolves, and the line carried no `Parts:` (ledgerboard SPEC, v2.3), the field that lists the parts a parent's `decide` asks about.
