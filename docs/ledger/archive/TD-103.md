**Why:** every mechanical rule in a brief costs a full status read on the strongest model every round, is applied with a model's judgement where none is wanted, and is stale by up to a round; the same rule on the tick is free, exact and immediate. The manager then does only judgement — cadence verdicts, escalation, the wind-down's second reading — and can run far less often, or a team with only mechanical needs runs with `manager: person` and no manager session at all. This is the largest run-cost saving the review found.
