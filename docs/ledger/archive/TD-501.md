**Why:** TD-493: Paul, 2026-10-09 — a file the session names (`src/agentorc/cli.py:364`) is copied by hand; the design makes it the editor button pointed at the file, only where the host says the file is there.

**Fix:** as §4.6 says —
- **The `paths` RPC** (host agent): `paths {id, runs: [str]}` → `{paths: {run: "/abs/real/path" | null}}`. For each run (at most 8 per call, each at most 512 chars; more is refused naming the bound): a relative run against the record's `dir`, `~` the host agent's user's home, `os.path.realpath`; the answer is the real path when it `is_file()` and lies under the real path of the record's `dir` or of its `repo` (§4.1), else `null` — a directory, a file outside both, a symlink out, a missing file and an unreadable one all `null`, one word for all (the page needs no reason). It stats and reads nothing else. Served where the record lives; add it to `NODE_READS` so the home asks a node through `read` as it asks for `transcript`, refused as unreachable while the link is down. A record it does not hold is *no session*. Test: a tmp dir as `dir` with a file, a subdir, a symlink to `/etc/passwd`, a `../` run, a `~/` run, and an absolute run inside and outside; the bound refusals.
- **`editor.file`** (UI): `editor_link` gains the file form — the same template with `{path}` left unfilled (the `vscode` default's local form `vscode://file{path}?windowId=_blank`, the ssh-remote and `reach` forms, a template of the person's own with `{remote}` filled and `{path}` kept) — served to the Focus page beside the header's `editor` as `editor.file`, and `null` wherever the header's button is `None`. Test beside `editor_link`'s.
- **The route**: `POST /api/sessions/<id>/paths` with `{runs}` forwards to the RPC on the record's host and returns its reply; the same errors as the transcript route's (503 → the Org's banner words). No gate beyond the UI's own.
- **The provider** (`app.js`, `AO.focus`): when `editor.file` is set, `term.registerLinkProvider({provideLinks(y, cb)})` after the web-links `loadAddon`. `AO.pathRuns(text)` (pure, tested under node as `tests/test_attach.py`'s `_node` harness runs the page's functions, TD-370) returns the row's candidate runs with their columns: a run matching a shape such as `(?:~|\.{1,2})?/?[\w.@+-]+(?:/[\w.@+-]+)+(?::\d+(?::\d+)?)?` that contains a `/`, trailing `.,;:)]}'"` stripped, a run preceded by `://` or inside a URL match skipped. The provider asks the route once per row text (a `Map` from row text to the reply, kept for the attach's life, cleared on re-attach) and calls back with one link per resolved run: `range` the run's columns, `text` the run, `activate(event, text)` → `AO.pathLink(event, editorFile, resolved, line, col)`, `decorations {underline: true, pointerCursor: true}`; a failed fetch calls back with `undefined` and remembers nothing, so the next hover asks again. `AO.pathLink` is `AO.paneLink`'s shape: no modifier, nothing; else fill `{path}` with `encodeURI`-style percent-encoding (`/` kept, as §5 and TD-011), insert `:line[:col]` right after the filled path, before the `?windowId=_blank` query, only when the template is the `vscode://file` form, and hand the URL to the hidden-iframe handler the editor button uses (`a.editor`'s click code, factored out), with the same toast. Test under node: the runs a row yields; a plain click opens nothing; the `file` form gets the line, the ssh-remote form does not.
- **Help** (`help.py`, and §4.5a's *The help text* list in the same PR — the two are compared by `tests/test_help.py`): a bullet **a path is a link** (Focus pane) — *Ctrl+click (Cmd+click on a Mac) on a file the session named — `src/x.py:12` — opens it in your editor, at the line where the editor's link takes one; it underlines only when the file is in the session's repo, which the host checks when you hover. A plain click or a drag selects, as before; without an editor button on the header there are no file links.*
- **The mockup**: `Focus.dc.html` already draws it (this round); the review shot re-taken from the built page under `docs/mockups/reviews/` as TD-491's rule.

**Done when** a Focus of a session that printed `src/agentorc/cli.py:364` underlines it on hover and Ctrl+click opens VS Code at that file and line; `build/review` in the same pane's prose, and a path outside the checkout, never underline; `open_in: none` registers no provider and the hover asks nothing (the network tab is empty); a read-only Focus and a popped-out window link as the interactive one does; a node's record is asked through `read`; `pdm run test` covers the RPC's bounds and the provider's runs.
