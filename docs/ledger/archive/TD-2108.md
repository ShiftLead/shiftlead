## TD-2108: The disk sweep removes detached worktrees that have fully landed

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Resolved 2026-11-23
**Id take:** 34d3e06c42f5443792713f15526e0c39
**Part of:** TD-2103

**Why:** Part of TD-2103, which designs the rule: the disk sweep keeps every detached worktree, so old ones that have fully landed are never reclaimed. Read on 2026-11-23 with the rule applied read-only: 12 of the 26 detached worktrees under a worktree root would go, about 360 MB. The entry's 3.4 GB counted worktrees the sweep's other tests keep, mostly ignored build output (one holds 2.1 GB).

**Ask:** Should the grinders build the design that lets the disk sweep remove old detached worktrees?

**Context:** The hourly disk sweep keeps every worktree that is not on a branch, however old. This design removes one once it is old, clean, already in the default branch and no session's record points at it, which frees about 360 MB today. A removal cannot be undone, so it comes to you. The independent judge raised it because one fix to the plain-words summary needed a second correction; every fix that changes the build has been read by a review.

**Location:** src/sessionorc/worktreesweep.py, src/sessionorc/gitinfo.py, src/sessionorc/agent.py, src/sessionorc/agent_tick.py, tests/test_worktree_sweep.py, design §4.6 *The disk sweep*

**Resolved:** 2026-11-23 (PR #4420) — design §4.6 The disk sweep, A detached worktree; tests/test_worktree_sweep.py

**Done when:** A detached worktree that is old, clean, landed on `origin/<default>`, with no operation in progress, no commit only in its reflog and no session record at or inside it, is removed by the sweep. One with a commit not on `origin/<default>`, a commit only in its reflog, changes, an operation in progress, a write within `worktree_keep_days`, a `HEAD` that moved during the pass, or such a record in any state while that record exists, is kept, and `ao disk` names the why. Tests cover each case, the fixture against `reap_worktrees.sh` included.
