**Why:** A Claude Code turn that ends on an API error fires `StopFailure`, never `Stop` (checked in Claude Code 2.1.323's hook schema: `error` one of `authentication_failed`, `oauth_org_not_allowed`, `account_on_hold`, `verification_required`, `billing_error`, `rate_limit`, `overloaded`, `invalid_request`, `model_not_found`, `server_error`, `unknown`, `max_output_tokens`, `cloud_credential_error`).
