## TD-2097: The test suite fails across the board from a seat when its temporary paths grow too long for a socket

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Resolved 2026-11-23
**Id take:** 5b7bfb04360f4855b6a65661a78c3435

**Why:** A seat's `TMPDIR` is `/tmp/shiftlead-<uid>/<token>`, so pytest's parallel runs put a test's home at `<TMPDIR>/pytest-of-<user>/pytest-NN/popen-gwN/<test name up to 30 characters and a digit>/home/`, 105 bytes or more, and `agent.sock` beneath it passes the 108-byte limit on a Unix socket path. On 2026-11-23 `pdm run test` from grinder-ao-2's seat gave 1,739 setup errors and 51 failures (`OSError: AF_UNIX path too long`, then *agent socket or tick loop never appeared*). The same commit passed whole (8,641 passed) with `--basetemp` under the seat's scratch, which drops the `pytest-of-<user>/pytest-NN` part. Which tests break depends on the run number and the length of the test's name, so it reads as a broken change.

**Resolved:** 2026-11-23 (PR #4403) — tests/conftest.py tmp_path; tests/test_no_temp_leaks.py

**Done when:** `pdm run test` from a seat whose `TMPDIR` is `/tmp/shiftlead-<uid>/<token>` raises no `AF_UNIX path too long`, at any pytest run number.
