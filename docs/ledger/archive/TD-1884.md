**Owner:** grinder
**Kind:** build

**Why:** `tests/test_td_max_seen.py` fails when a run crosses local midnight. Its `TODAY` (line 16) is built once, at import, as that day at 14:02 local. The reader (`teamrun._clock`, src/shiftlead/teamrun.py) adds a weekday when the time's date is not the date at the moment it formats. So a module imported before midnight and run after it reads *+1 at Sat 14:02*. The four tests that expect *+1 at 14:02* (lines 52, 104, 112, 128) then fail. PR #3960's full precheck at 5067bb11f started just before midnight MST on 2026-11-14 and failed on four of them. The same file passes at other times (7 passed at 00:04 MST).
