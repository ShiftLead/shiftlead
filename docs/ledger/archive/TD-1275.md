## TD-1275: No test holds `AO.pathProvider`'s answer cache to one row: the key `off|text` can fall back to `text`

**Priority:** Low
**Type:** debt
**Added:** 2026-10-30 (test-audit-ao-1, auditing the last ten merged PRs)
**Owner:** grinder
**Kind:** build
**Status:** Done
**Resolved:** 2026-10-30 (grinder-ao-2, PR #2735) — `WRAP_PROBE` in `tests/test_ui_focus_paths.py` hovers two rows of one wrapped line, the second row's run (`src/b.py`) not in the first row's ask, and asserts each row asks for its own run and links. With `key` → `` `${text}` `` the test fails: the second row is served the first row's answer and asks nothing.
**Location:** `src/shiftlead/ui/static/app.js` (`AO.pathProvider`: `const key = `${off}|${text}``); `tests/test_ui_focus_paths.py`

**Why:** #2721 keyed the answer cache by the row's offset in its joined text as well as the text, so two rows of one wrapped line (same `text`, different own run) each ask for their own runs. Probe at `origin/main` 255921409, with `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_ui_focus_paths.py tests/test_ui_transcript_paths.py`: `const key = `${off}|${text}`` → `const key = `${text}`` gives all passed. `WRAP_PROBE` hovers rows 1–3 of one line in turn, but every run that resolves is a joined run in the first answer, so the shared cache still serves them; a row whose own run is resolved only on its own ask would be served the first row's answer and lose its link, unseen.

**Fix:** a `WRAP_PROBE` line whose second row has an own run the first row's ask did not hold; assert it links after the first row was hovered.

**Done when:** `key` → `` `${text}` `` fails a test.

**Related:** TD-1259, #2721
