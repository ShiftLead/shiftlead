**Resolved:** 2026-11-06 (PR #2997) — src/sessionorc/gatesweep.py host_log; tests/test_gate_sweep.py; design §4.4 The check

**Done when:** tests, with the reader stubbed by a script printing given JSON, that a `passed` answer lifts the gate citing its evidence; that `not yet` and `error` reach `sweep()` as they are; that `none` keeps the gate out of `sweep()`'s results, neither lifted nor filed; that a non-zero exit, non-JSON output and the 120 s timeout each reach the sweep as `error`, an unpinned or locked repo, one with no origin, and one whose pinned tree cannot be resolved, `error` without a run, and agent-cadence's own source checkout (a root `cadence.is_source` accepts, with `files/` and `launcher/INTERFACE`) run; that the argv is `cadence.command`'s for the repo's root with `--host-config` the store's `host-log.toml` and the check as its last element, run off the loop and one gate at a time; that the reader is given the repo's `log-sources.toml` from the tree the ledger was read from (and empty input when the file is absent), the repo's origin path as `--repo`, `--visibility private` only for a private repo (an internal GitHub repo, read by `visibility`, unknown and a failed read give `public`, and a failed read is retried), and `--since` the gate's `gate_added()` (left out when it gives none); that the visibility is read once per repo per agent start, by `gh` and by `glab`; that `set` and `edit` are passed `today`; that the `problem` reaches the home's log and not the board; that `.shiftlead.yml`'s `held:` lists `docs/ledger/log-sources.toml` and the `precheck` line carries `validate`; and, against the real reader once the pin carries it, that the committed `log-sources.toml` passes `hostlog.py validate`, and, in a test home whose `witnessed/start` predates yesterday and whose `host-log.toml` the home wrote, a `host-log witnessed kind press "apply ao-grind"` gate added yesterday lifts on a press recorded today and not on one recorded yesterday.
