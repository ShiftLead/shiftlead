## TD-2282: The rule on failed restarts says each one counts, though a refused login list is not counted

**Priority:** Low
**Type:** debt
**Added:** 2026-11-26
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 4e760c664fe64ff0bd8f501430665f6d

**Why:** Audit of #4768 (TD-2068 slice 14) and of the section it extends. Design §6 *Keeping a team running* says without exception: "**A replay that fails** — the worktree reaped, the profile gone, the name taken by a live session — is not retried silently: it counts toward the ceiling as any restart does, keeping its `why` and carrying the error text as `error` on the entry, so an unrepairable record reaches the Inbox row within three ticks rather than never."

That no longer holds for a built-in seat on a node. Design §4.9d *How each one runs*, as #4765 and #4768 wrote it, says a node's refusal of the seat's list, as *no login usable* or *no login offers* the model, writes no `restarts` entry, spends no fill ceiling and "counts toward no restart ceiling". The code agrees with §4.9d: `_replay` returns through `_node_list_refused` before it writes the entry (`src/sessionorc/agent_tick.py`), and `test_a_nodes_list_refusal_of_a_replay_is_no_restart` (`tests/test_builtin_fill_login.py`, 4 passed at 0cdfc7bb6) holds `restarts` unchanged. The seat is drawn unfillable in the node's words and never reaches the ceiling.

The docstring of `_replay` says the same as §6: "A replay that fails keeps its entry with `error` and counts all the same".

**Location:** docs/design/6-policies.md Keeping a team running; src/sessionorc/agent_tick.py _replay

**Fix:** Add the exception to §6's sentence on a replay that fails, pointing to §4.9d *How each one runs*: a node's refusal of a built-in seat's list is no restart and no fill. Say the same in the docstring of `_replay`. Add the history line to this entry's history file under §6. TD-2281 settles which of rule 1's replays the exception covers.

**Done when:** §6's sentence on a failed replay and the docstring of `_replay` both name a node's refusal of a built-in seat's list as the case that counts toward no ceiling.
