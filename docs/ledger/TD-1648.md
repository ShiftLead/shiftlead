**Fix:** Build §4.3 *The live smoke, unattended* as written: `--smoke` on `scripts/conformance.py`, keeping the walk's two homes and its refusals but one (never in CI, never without `--profile`, never on a profile with no `config_dir` or whose `config_dir` resolves to the home the adapter uses for a profile naming none, each agent adapter's new `default_home()` (Claude Code's `$CLAUDE_CONFIG_DIR`, else `~/.claude`; Gemini CLI's `$GEMINI_CLI_HOME`, else `~`), generalised from `scratch_profile`'s Claude Code-only check, Claude Code's refusal keeping `~/.claude` too when `$CLAUDE_CONFIG_DIR` points elsewhere, as the walk's does, this build adding `default_home()` to each agent adapter and, in the offline suite's declaration check, a check that every agent adapter declares it (TD-1647 adds the `binary` one there; neither waits on the other); a `config_dir` shared with other profiles is not refused for the smoke, as `scratch_profile` refuses it for the walk) and differing from the walk in three things: `scratch_profile` keeps the live profile's own `permission_prompts` for the smoke (it forces `all` for the walk) and the launch is `unattended`; the seat's brief is composed by `teams._brief` for `--role` (default `fact-checker`), the role resolved from the `.shiftlead.yml` of a checkout the launch code takes as a parameter (the smoke passes its scratch clone; TD-1649's judge passes the checkout it starts in) over the built-in roles with no org overlay, its one seat member there, `{repo}` filled as a team start fills it, `{lane}` empty, as a seat's is (`teams._launch`), `flow` `None`, `{techlead}`, `{manager}` and `{context}` empty, handed as the create's first prompt — a role with no seat line, or more than one, refused unless `--brief <file>` is given, which replaces the role's template and is composed with the same slots; the ask is a plain `ao msg --kind ask`, never `--pr`. The seat is created with `name`, `adapter`, `profile`, `dir` the clone, `role`, `unattended` and the brief as its `prompt`, and no `seat`, `team`, `supervised`, `controllers` or `worktree`, in a scratch clone of the running checkout's `HEAD` (the output naming it and any uncommitted change under the repo's brief paths) whose `origin` is a local bare repository with the same commits. However it ends, it kills the seat it started, stops the walk's host agent and removes its scratch homes and clone, unless `--keep` names them.
