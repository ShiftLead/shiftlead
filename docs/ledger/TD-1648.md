## TD-1648: Build TD-1577: the live smoke, an unattended seat answering a nonce ask with no needs-you

**Priority:** Medium
**Type:** feature

**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** c3fc299e652443688726739f6ea478d6
**Part of:** TD-1577
**Location:** design §4.3 *The conformance suite* *The live smoke, unattended*; scripts/conformance.py

**Why:** TD-1577's design (§4.3 *The live smoke, unattended*): the live walk declares its profile with `permission_prompts: all` and answers each permission as the person, so it never runs a seat the way an unattended one is launched and could not have seen TD-1576's untrusted-flags prompt. The smoke runs the real tool as a seat is launched and passes only when a nonce comes back with no `needs-you`.

**Fix:** Build §4.3 *The live smoke, unattended* as written: `--smoke` on `scripts/conformance.py` (the walk's two homes and refusals: never in CI, never without `--profile`, never on the person's tool home); the profile declared in the scratch home with the live profile's own `permission_prompts` and `unattended` set; `--role` (default `fact-checker`) for the role's brief as the live team's briefs give it, `--brief <file>` in its place; the seat started in a scratch clone of the repo; after its first hook one ask from the walk's record, *reply to this ask with the token `<nonce>` and nothing else*, the nonce 12 hex digits from `secrets`, new each run; pass when a reply on that thread carries the nonce within 10 minutes and the record never read `needs-you`; fail at the first `needs-you` (pane captured with `capture-pane -e`, the record's `pending` printed) or at 10 minutes (the record's state); the last line *smoke: passed* or *smoke: failed — <step>: <what it read>*, with the tool's `--version`. No tick runs it.

**Done when:** `pdm run conformance <adapter> --profile <p> --smoke` passes on a Claude Code seat profile, and run against Gemini CLI 0.66.0 with the fact-checker brief from before TD-1582 (`--brief` from `git show`) it fails at `needs-you` on the untrusted-flags prompt (TD-1576); both runs' last lines in the PR.
