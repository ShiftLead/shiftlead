## TD-1227: Own work reads *working* whether or not a wait reads: the one order on the card and in `ao status`

**Priority:** Medium
**Type:** debt
**Added:** 2026-10-29 (the designer, from TD-1222's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Part of:** TD-1222
**Location:** `src/shiftlead/ui/cards.py` (the pill composition after `waiting_view`, ~:450–478: `own_work` is drawn only `if … not d["wait_reason"]`), `src/shiftlead/cli.py` (`shown_state`, ~:252: `own = None if waiting or s.get("pending") else own_work(s)`), `src/shiftlead/ending.py` (`own_work`, the helper both share); `tests/test_ui.py`, `tests/test_cli.py`

**Why:** design §4.2 *One order* (TD-1222): the pill answers only *what is it doing*. An `idle` record whose own work is live (`subagents_live`, `shells_live`) reads *working* whether or not a wait reads; with none, a wait reads *waiting*; with neither, `idle`. Today the card draws *waiting* over own work and `ao status -v` drops own work when the home reads a wait, so a session waiting on its own background `gh pr checks` reads *working* or *waiting* by whether it also has an ask out.

**Fix:**
- **The card.** Draw *working* when `own_work(s)` and `state == "idle"`, whatever `wait_reason` holds, and *waiting* only when there is no own work. The slot's ending is the *working* ending with the wait after it when one reads (*working · 1 shell: <cmd> · 4m · waiting on you: TD-222*), and the pill's hover says the same. A declared ending still comes first.
- **`ao status`.** `shown_state` ignores `waiting`: own work wins, and nothing pending still keeps it out. Under `-v` the wait is still printed on its own line.
- **One rule.** Put the choice in one helper beside `ending.own_work` (say `ending.pill_of(s, waiting) -> "working" | "waiting" | None`) that both callers use.
- **Leave alone.** Leave *idle · unseen* as it is: TD-1228 replaces it with the mark.

**Done when** a card and `ao status -v` both read *working* for an `idle` record with a live background shell or subagent and an open ask naming a reference (the card's slot ending also naming the wait), the same record with no own work reads *waiting*, and a test pins each case.
