**Why:** Audit of #3701 (TD-1761 slice 1). Mutations in `src/shiftlead/ui/static/app.js`, each run with `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_ui_holds_still.py` (16 passed every time): (1) `AO.qRankFrom`: `if (how && how.after) anchor = { after: how.after };` → `if (false) …` — a drop *after A* is sent as ↑/↓ from the drawn order instead of keeping its own anchor; the only drop case, `rank_drop`, is `{ before: "C" }`, though the doc comment names *after A* first; (2) `AO.qRankFrom`: `rest[i + 1] ?? null` → `rest[i + 1]` — a move to the end of the reading sends `next: undefined`; (3) `AO.qBlockOf`: the `details.qread` line and (4) the `details.qfold` line removed — an item in a card's Read fold or its ✓ n done fold is read as a row and, when it is gone, is not told apart from a row (`qModel`'s `units` are keyed by block, so a *Read* item moving to *Do* would count); (5) `AO.qModel`: `.filter((u) => u.closest(".qcard") === c)` removed — a card nested in a card takes its child's units as its own; (6) `AO.qModel`: `if (cards.has(id)) return;` replaced by `if (false) return;` — a card drawn twice is read at the later place; (7) `qModel`'s `catch (e) { upnext = []; }` → `throw e`, a damaged `data-upnext` kills the re-read, where the code reads it as empty; (8) `AO.qLis`: `xs[tails[m]] < x` → `<=` (equal indices cannot occur there, so this one is equivalent; it is listed only so the next auditor does not chase it). `test_ui_holds_still.py`'s fixtures draw only a Decide section, a Do section and rows, so the Read and ✓ n done folds, nesting and a malformed `data-upnext` are never in any copy it reads.

**Fix:** In `CASES` of `tests/test_ui_holds_still.py` add: a rank drop `{ after: "B" }` and a move whose card lands last in the reading (its `next` is `null`); a card with a Read fold and a ✓ n done fold, asserting `AO.qModel(...).cards.get(id).units` keys by `read` / `done`; a card nested in a card; the same card drawn in two groups (read once, in the first); and a `data-upnext` that is not JSON (reads as `[]`). Assert each from the model, not from the source.

**Done when:** Mutations (1)–(7) above each fail a test in `tests/test_ui_holds_still.py`.
