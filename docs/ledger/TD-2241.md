## TD-2241: The test of answering an early question presses a question that is not early

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-26
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 17dbb6df77ee41849e219017d5b084f1

**Why:** #4700 (TD-2185) says a `ledger_decide` answer on an early question is read end to end, written as a decided line and not refused (docs/design/4.4-host-agent.md, *A question whose entry only waits is asked early*: "a press is written as any (no 409: the home's stale refusal reads the fact alone)"). `test_a_press_on_an_early_answer_is_written` (tests/test_queue_asked_early_end_to_end.py) never has an early question to press.

The test sets `agent._repos` by hand with entries that carry `blocked_by` and no `blocked_ids` or `gates`. `src/sessionorc/ledger.py` writes `blocked_ids` for every entry it reads, and `gates` where there are any, and the home's refusal reads those two (`_open_blockers` and `gate_waits` in src/sessionorc/queue.py), not the `blocked_by` strings.

- A probe run inside the test at cd2826f33, over the test's own four entries: `counted_work(…)` gave `work {}`, `wide {}`, and `asked(…)` gave `early {}`. TD-001 is an ordinary question with no wait.
- With `_open_work` in src/sessionorc/agent_inbox.py changed to return `counted.wide` in place of `asked(…).fact`, so that the home refuses a press on any entry that waits, the test passed. In a copy of it with `blocked_ids` and `gates` added to the fixture, the same change failed it, and the unchanged code passed.

The refusal itself is held elsewhere: that change fails `test_a_chain_of_gated_blockers_that_ends_in_a_wait_is_asked_early_and_counted_nowhere` and `test_the_inbox_and_the_homes_refusal_read_the_held_builds_work`. So the gap is this test, which claims the case end to end and would pass whatever the home did with an early member.

**Location:** tests/test_queue_asked_early_end_to_end.py

**Fix:** Give the test's entries the shape the reading writes: `blocked_ids`, and `gates` for each `until`, or read them from a ledger directory as the module's other tests do (`_case`). Assert before the press that TD-001 is asked early. Press an early entry with an open blocker that carries no gate as well (TD-003, blocked by the build TD-004, given answers): with the corrected fixture a press on TD-001 alone stays green where the refusal reads all counted work (`counted.work`), since TD-001's blockers are gated and are not in it.

**Done when:** The test fails when the home's refusal reads every counted wait in place of the fact, by either `counted.work` or `counted.wide`.
