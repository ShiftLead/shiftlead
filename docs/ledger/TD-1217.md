## TD-1217: `test_the_starts_note_is_the_stops_formatter_on_a_scheduled_record_only` fails whenever three days ahead crosses a DST change

**Priority:** High
**Type:** debt
**Added:** 2026-10-29 (ao-dev-cadence-dc-tds, through `ao td add --repo`; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `tests/test_start_time.py` (`test_the_starts_note_is_the_stops_formatter_on_a_scheduled_record_only`, its `far` case); `src/sessionorc/models.py` (`start_note`, which is right)

**Why:** the test builds `soon` as an aware local datetime, so it carries today's fixed UTC offset. Then `far = soon + timedelta(days=3)` keeps that offset. `start_note` renders the instant in the local zone's real offset on that day, so when a DST change falls inside the three days the expected and actual clocks differ by an hour. Seen 2026-10-29 08:30 MDT: `'starts Sun 07:35' != 'starts Sun 08:35'` (US DST ends Sun 2026-11-01). It fails on `origin/main` unchanged (reproduced at 9883daee6). It first turned #2646's precheck red, and it makes every shiftlead PR's precheck red until Sunday's window passes. It will do the same for three days around each March and November change. The code is right; the test's expectation is wrong.

**Fix:** derive the expectation the way `start_note` does: render `far.astimezone()` (the instant in the local zone) rather than `far`. Or build `far` in local wall time and let the zone resolve it, e.g. `(soon.replace(tzinfo=None) + timedelta(days=3)).astimezone()`. Add a case pinned across a DST boundary with a fixed zone (`monkeypatch.setenv("TZ", "America/Denver")` and `time.tzset()`, restored after), so the case does not depend on the run date.

**Done when** the test passes on a run whose three days ahead cross a DST change, and the pinned case fails on today's expectation and passes on the fix.

**Related:** TD-152 (the start time and its *starts* note); `tests/test_cli.py` `test_stop_note_reads_in_the_local_clock` (the same clock, the *stops* note); #2646 (first precheck it turned red).
