## TD-1544: Cross-repo work goes to the other repo's question seat by ao td add --repo; a board Do item only where it has none, saying so

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-07 (Paul, through ao-led-tds-ledger; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 2bc801750ebe4ab58893bb7a65570b28
**Location:** src/shiftlead/briefs/grinder.md, designer.md, manager.md; design §4.7 *Entries*; docs/ledger/README.md

**Why:** When a session meets work in another repo, it sometimes writes a Do item on this repo's board for the person ("X has no question seat, so no session here can file it"), even where X has a seat that `ao td add --repo X` reaches (design §4.7 *Entries*, TD-995). The person then carries work a session could have handed over. Seen 2026-11-07 by Paul through `ao-led-tds-ledger` (m-89f5d7001d44): TD-1025's board line, about dev-cadence (now agent-cadence, which has a seat). The ledger README already says another repo's work is filed with `ao td add --repo`. Nothing in the briefs tells a session to check for a seat first, or what the Do item says when there is none. `grinder.md`'s line about another repo's done board line is a different case, and `techlead.md`'s *An entry a session asks for* is the receiving side.

**Fix:** Write the rule where sessions read it: the packaged briefs (`src/shiftlead/briefs/grinder.md`, `designer.md`, `manager.md`) and, if the design should say it, §4.7 *Entries*. The rule: for work in another repo, use `ao td add --repo <repo>` where that repo has a question seat. Write a Do item on the board only where none does, and the item names the cause ("<repo> has no question seat"). The part that holds in every cadence repo goes to agent-cadence with `ao td add --repo agent-cadence`, not into this repo's copy of cadence. This entry is independent of TD-1543, which makes such a Do item doable by a session.

**Done when:** The briefs say the rule, and a test checks the sentence is in each brief that carries it (the builder names the test it follows; `tests/test_briefs_layout.py` checks layout slots, not sentences). Any cadence part is filed on agent-cadence's ledger, its id named in this entry's Log.
