## TD-2131: A failed or killed hand-run test suite in a live seat is released within hours

**Priority:** High
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 55ba7464d84b45dcb8fc589d480c796e
**Blocked by:** TD-2130
**Part of:** TD-2126

**Why:** Part of TD-2126, design §4.6 *A live seat's rebuildable copies*, parts 2 and 3. A hand-run suite with its own `--basetemp` that fails or is killed is not recognised, and one seat held 188,046 inodes that way.

**Location:** tests/conftest.py, src/sessionorc/scratch.py, src/sessionorc/agent_tick.py, design §4.6 *A live seat's rebuildable copies*

**Fix:** In `tests/conftest.py`, the controller writes the mark and, for a caller's `--basetemp` under `SHIFTLEAD_SCRATCH`, the run-list file named `<pid>-<time_ns>`, skipping xdist workers and a suite run inside a test, a failed write never failing the run; `pytest_unconfigure` removes a passed run's list file with its base temp. In `scratch.py` and the hourly pass, read the list with its path checks, remove a file whose path is gone or whose mark names another pid, and release runs after `TEST_KEEP_S` for every directory `_seats` returns, under the guards the design names (given `named`, no blind adapter, transcript overlap, the deadline), `_quiet` taking its bound as a parameter (`RELEASE_WALK_S` hourly, a cut walk kept with the why *walk cut short*; `diskbook.WALK_S` under pressure); `pytest-current` as the design says; rule 1 reads the list too.

**Done when:** A killed or failed hand-run suite at any depth in a live seat is removed by the hourly pass two hours after its last write and by the pressure pass after ten minutes. A passed run leaves no list file, and a failed write of the mark or the list never fails the run. A live run, a listed path through a symlink or outside the seat, a list directory that is a symlink, an oversized list file and a nested suite are not touched.
