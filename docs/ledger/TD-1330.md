## TD-1330: Vendor ledgerboard v2.3 as a package, with the agent-cadence pin bump, and route every board write through ledgerboard's `board.py`

**Priority:** medium
**Type:** feature
**Added:** 2026-11-03 (ao-led-tds-ledger, through `ao td add --repo`, from ledgerboard's target design; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** agent-cadence#TD-213, TD-1326
**Part of:** TD-1286
**Location:** `docs/cadence.toml` (`[agent-cadence]`, the pin); `scripts/vendor_ledgerboard.sh`; `src/sessionorc/ledgerboard.py` (becomes the `src/sessionorc/ledgerboard/` package); `src/sessionorc/seams.py` (`LEDGERBOARD_COPIES`, the payload path, :29, :60); `src/shiftlead/doctor.py` (:459, the vendored copy's header); `src/sessionorc/agent_ids.py` (:184, `_cadence_fields` reads the file as a literal for `CADENCE_FIELDS`); `scripts/look_home.py` (:165, copies the pinned tree's `scripts/ledgerboard.py`); `pyproject.toml` (ruff `extend-exclude`, :108); `tests/test_ledgerboard_fixtures.py` and the tests that seed the pinned path; `src/sessionorc/board.py` (every write); `src/sessionorc/workorders.py` and the Inbox's board read; `docs/user_attention.md`; ledgerboard `docs/plans/target-design.md` §1.1, §1.2, §6, §7.2 step 0

**Why:** ledgerboard v2.3 turns `ledgerboard.py` into a package, `ledgerboard/` (the module as `__init__.py`, with the board writer `board.py` beside it), and changes `snooze` to write `Hide until:` and leave `Due:` alone, adds a `due` action, and gives the module `needs_you(board, today)` (target design §1.1, §1.2, §6; Paul's go 2026-11-02, ledgerboard#57). ShiftLead reads the single file in several places, some of them through its agent-cadence pin, so the pin bump to agent-cadence's step-0 release (agent-cadence#TD-213) and the vendor of the package must be one PR (§7.2 step 0). Left apart, a reader of the old path breaks — `agent_ids.py` would silently stop writing `Taken by` — and the Inbox would keep showing an item the person hid. Python also prefers a package over a stale `ledgerboard.py` beside it, so the old file goes in the same PR.

**Fix:** one PR (target design §7.2 step 0):
- **Bump the agent-cadence pin** to the release that carries agent-cadence's v2.3 vendor (agent-cadence#TD-213), and **vendor the package** in the same PR, removing the old single file.
- **Every reader of the old single file** moves to the package: the files under Location, and whatever else `git grep -n 'ledgerboard.py'` finds.
- **`src/sessionorc/board.py` calls ledgerboard's `board.py`** in-process for every board write (`add`, `add_decided`, `edit_line`, `_insert`), keeping its own lock, temporary worktree, commit and push (target design §1.1 *What the consumer keeps*); it exposes `due`, and the Inbox reads `needs_you`, so a hidden item is not shown. This is TD-1286's board half. The design's sentences on how ShiftLead writes and reads a board (design §8 *Which side a thing lives on* — its ledgerboard sentence too, to [ADR 2026-11-03](../decisions/2026-11-03-ledgerboard-writers.md)'s row — and wherever the design says what the Inbox shows from a board) change in the same PR.
- **The board** `docs/user_attention.md` gains its `People:` line.
- **The `Hide until` data check** (target design §6): the PR shows that no board ShiftLead writes already holds a hand-written `Hide until:`.

**Done when** ShiftLead runs on ledgerboard v2.3 through the package, its board writes go through ledgerboard's `board.py`, the Inbox reads `needs_you`, its board carries `People:`, and `pdm run test` passes.

**Related:** TD-1286 (its board half is this entry); TD-1326 (the ADR that moves ledgerboard's boundary, which must land first); agent-cadence#TD-213 (agent-cadence's v2.3 vendor, waiting on ledgerboard#TD-019, v2.3's last build); ledgerboard#57.
