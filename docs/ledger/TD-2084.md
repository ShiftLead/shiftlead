## TD-2084: Move the test suite and scripts off the bare shared temporary directory

**Priority:** High
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 41c245182c72424d865c5e2261ff8111
**Part of:** TD-2080

**Why:** Part of TD-2080: temporary files keep filling the space every session depends on, and nothing reacts until it is full (design §4.6).

**Location:** tests/conftest.py, scripts/judge.py, scripts/conformance.py

**Fix:** Move the repo's own writers off bare `/tmp` (design §4.6 *A session's scratch*): `tests/conftest.py`'s scratch roots go under `$TMPDIR` where the resulting root fits `scratch.MAX_ROOT`, else `/tmp` as today, each writing its pid to `.shiftlead-test-run` inside it (§4.6 *The pressure pass*, rule 1), and `sweep_stale_scratch_roots` reads `/tmp` and every seat's directory under `shiftlead-<uid>/` by that file, as `_run_parents` does, the `OWNERS` files staying for the roots at the top of `/tmp`; `scripts/judge.py` and `scripts/conformance.py` use `SHIFTLEAD_SCRATCH` when set.

**Done when:** A suite run inside a seat leaves no new `aoscr-*` directory at the top of `/tmp`, a killed run's root in another seat's directory is removed by the next suite run, and `judge.py` and `conformance.py` make their homes under `SHIFTLEAD_SCRATCH` when it is set.
