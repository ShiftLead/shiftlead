## TD-1868: The gate sweep rewrites a ledger id inside a file path when it files an item on another repo's board

**Priority:** low
**Type:** debt
**Added:** 2026-11-15
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 51d08ac5598843b399fe8ba39da99b4d

**Why:** The gate sweep's `_qualify` (`src/sessionorc/gatesweep.py`) writes a bare `TD-n` in an item filed on another repo's board as `<repo>#TD-n`, matching `(?<![#\w])TD-n\b`. A `/` before the id and a `-` after it both pass, so an id inside a file path is rewritten too: #3913's item for ledgerboard's TD-109 tells the person to read `docs/plans/shiftlead/ledgerboard#TD-109-decision-missing.md`, a path that does not exist, in its line and its Question (ledgerboard's file is `docs/plans/TD-109-decision-missing.md`). Seen 2026-11-15 bringing #3913 up to main.

**Location:** src/sessionorc/gatesweep.py (_qualify); tests/

**Fix:** In `_qualify`, leave an id that is part of a path or a longer name alone: no `/`, `.` or `-` immediately before it, and no `-`, `.` or `/` immediately after it (or match only an id standing alone between spaces and punctuation). A test in the gate sweep's tests: an item whose text names `docs/plans/TD-109-decision-missing.md` and `TD-109` keeps the path as written and qualifies the bare id.

**Done when:** Done when an item the sweep files on another repo's board keeps a path that names a ledger id as written, under a test.
