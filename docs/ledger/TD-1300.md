## TD-1300: The key bar: the soft-key row reshaped — `esc tab ⇧tab ctrl ◂▴▾▸ ↵ 1–9`, ctrl latched, the drag pad's repeating arrows, the digit page

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-01 (phone-view, from TD-003's design)
**Owner:** grinder
**Kind:** build
**Status:** Open — the design's review rounds run first, then Paul's go.
**Blocked by:** decision (paul)
**Part of:** TD-003
**Location:** `src/shiftlead/ui/templates/focus.html` (`#softkeys`), `src/shiftlead/ui/static/app.js` (`AO.softKey`, the row's pointer handlers ~6135), `app.css` (`.softkeys`), `src/shiftlead/ui/help.py` (`soft-key-row`), `tests/test_ui_soft_keys.py`

**Ask:** Now the phone layout's review rounds have converged, should a grinder build the key bar?

**Why:** TD-003's design: §4.5a **soft-key row**, reshaped as the key bar, so a phone answers a menu or question in the terminal (questions stay there, Paul 2026-11-01) with one press and no sideways scroll.

**Fix:**
1. The row's keys: `esc` `tab` `⇧tab` `ctrl` `◂▴▾▸` `↵` `1–9`, sharing the row's width, `touch-action: none`; `AO.softKey` gains `BackTab` (`ESC [ Z`).
2. **ctrl**: latched for the next key from the bar or the phone's keyboard (the control byte; a letter `0x01`–`0x1a`, `[` Esc), a 500 ms press locks it; drawn pressed while latched or locked.
3. **The drag pad**: nothing on a press; 16 px of slide sends the main direction's arrow, repeating every 150 ms while held away, every 60 ms past 64 px, until the finger lifts or returns within 16 px; pointer captured.
4. **`1–9`** turns the row to `1`–`9` and `‹`; **`⌄`** in its place while the phone's keyboard is up for the terminal, blurring it.
5. `help.py`'s `soft-key-row` wording and the design's help list, in the same PR.
6. Tests in `test_ui_soft_keys.py`: each key's bytes (application cursor mode included), the ctrl latch and lock over a letter, the pad's first arrow, repeat and stop by a scripted pointer, the digit page's flip and back.

**Done when** the key bar answers a Claude Code menu by digit and by the pad on a phone, and the tests hold its bytes.
