**Why:** #3021's precheck on c5ee8c6 (2026-11-06, a docs-only diff) failed with `worker 'gw4' crashed while running 'tests/test_ui.py::test_a_jump_over_the_term_socket_lands_or_misses_and_says_so'`, 5069 others passing; it ran beside #3023's precheck on the same machine. Run alone three times it passes (about 7 s). The test drives the `/term/` websocket of a shell session on the test tmux socket (TD-983), already made to wait for its row (TD-1008). A crashed xdist worker is not an assertion: something under load killed or hung the process, so the log names no cause. A precheck red for it costs a whole rerun and reads as the PR's fault.

**Fix:** Reproduce under load (the file beside a second full suite, or `-n` with a CPU hog) and read what the worker died of: run with `-p no:randomly --max-worker-restart=0 -x` and pytest's `faulthandler_timeout`, so a hang prints its stack before the worker is killed. Fix the cause (a socket left open, a tmux call with no bound, the jump's copy-mode left set), not a timeout.

**Done when:** The cause is named in this entry and fixed, or the entry says why the crash cannot recur.
