**Why:** Part of TD-2104: the shiftlead clone's pack is 654 MiB. Measured on a mirror on 2026-11-23: a plain `git gc` alone takes it to about 122 MiB, the landed branches free about 6 MiB more and the old `origin-all` refs about 15 MiB more. The bulk is duplicate copies across 29 packs, which git's automatic gc has not yet merged because it waits for 50. The one-off refs are the person's to approve (TD-2104's Fix).

**Location:** the shiftlead clone's refs and pack, design §4.6 *The disk sweep*

**Ask:** Should a session delete the old copied references in the main repository and repack it, freeing about 530 megabytes?

**Context:** Almost all the space comes from the repack, which loses nothing. The copied references are 2,699 from September and October that nothing uses, plus 13 other leftovers, and each is deleted only if origin still has its commit. Two recovered references, two stashes and the tags are kept either way.

**Answers:** Yes, and repack (default) — a session deletes the copied references, repacks and records the size | Repack only — a session repacks and deletes nothing | Neither — a session records the size and drops this

**Lifts:** Yes, and repack | Repack only | Neither

**Fix:** Do what the answer on this entry's board item says, once, in the shiftlead clone, and record `git count-objects -v`'s `size-pack` before and after in this entry's Log. The earlier figure of about 122 MiB came from a mirror, which holds no worktree's reflogs or index, so the real result will be somewhat larger.
- **Yes, and repack:** list the refs when the work runs, since they drift. Delete those under `refs/remotes/origin-all/`, `refs/remotes/pr*`, `refs/scratch/`, `refs/techlead/`, `refs/tmp*` and `refs/pr[0-9]*`, each only when its commit is listed by `git ls-remote origin` or is an ancestor of `origin/main`, and its reflog, where it has one, has not moved within a day, since a reviewer may be reading it. Any other is kept and named in the Log, and so is any ref in a namespace on neither this list nor the never-touched one. Then run plain `git gc` (its default two-week prune, never `--prune=now`, since sessions are working in the clone's worktrees).
- **Repack only:** run that `git gc` and delete nothing.
- **Neither:** record the size and archive this entry as dropped.

Never touched under any answer: `refs/recovered/*` (2), the two stash entries, the tags (`promote/live` is live), `refs/heads/*` (the sweep's) and `refs/remotes/origin/*`.

**Done when:** The answer is carried out, every ref it names is deleted or named as kept with why, nothing on the never-touched list changed, and the pack size before and after is in this entry's Log.
