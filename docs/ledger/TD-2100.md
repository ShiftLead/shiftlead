## TD-2100: Remove precheck directories that a killed run leaves on disk

**Priority:** High
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** d479a6810d64484fbb956ab18ca5b62a
**Part of:** TD-2080

**Why:** Part of TD-2080: a precheck's `/var/tmp/pc.*` directory is removed only by its shell's `trap`, which a SIGKILL skips, and `precheck.py` sends SIGKILL on a drain timeout or exception. Nothing else removes them: agent-cadence's `check_tmp.py` reaps only `tmp*` and `precheck-*`. Read on 2026-11-23: 224 directories, 215 over a day old, at least 494,553 inodes on the root disk.

**Location:** docs/cadence.toml, src/sessionorc/agent_tick.py (the hourly sweep)

**Fix:** Keep the directory on disk and its path short (TD-1052: the suite's sockets are capped near 108 bytes), so do not move it under `/tmp`. Have the precheck command write its shell's pid to a marker file in `$T`, in both `precheck` commands of `docs/cadence.toml` that make one. The hourly sweep removes a `/var/tmp/pc.*` of this uid whose marked pid is dead, or that has no marker and has been unwritten for a day. It never follows a symlink. Its first pass clears the existing directories.

**Done when:** A directory whose marked pid is dead is removed by the next sweep. One with a live pid, and one unmarked and written within a day, are kept. A symlink named `pc.*` is not followed. After the build is live on kmaster, no `pc.*` over a day old remains unless a live run holds it.
