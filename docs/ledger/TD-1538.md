## TD-1538: A board line that needs the person has no PR anchor: the design never says whether one ties by a PR

**Priority:** Low
**Type:** debt
**Added:** 2026-11-07
**Owner:** designer
**Kind:** design-first
**Status:** Open — designing (§4.5 screen 6 Every item that needs the person draws on a card): a board line whose Context names no entry but a PR ties by that PR; build TD-1552. Class in-repo (one paragraph of ShiftLead's own UI reading; cap 4)
**Id take:** fd9e459ddcbb4e07a8c29f176bd40755
**Location:** design §4.5 screen 6 (Every item that needs the person draws on a card); src/shiftlead/ui/queue.py (item_home); src/sessionorc/queue.py (pr_card)

**Why:** TD-1468's Done when (TD-1453's second build) asks that "an undecided Decide line or an ask in the tick before its `merged` close, whose merged PR is found only in `recent`, ties by that PR's title". The ask half was built (#3200: an item whose only anchor is a PR, its `pr` or an `about` of `#n`, names the entry that PR names). A board line has no PR anchor: design §4.5 screen 6 *Every item that needs the person draws on a card* names only a mail item's `pr` and an `about` of `#n`, and a board line's refs are its `Context:` and `Parts:` alone. So the board-line half has nothing to read, and the design must say whether a board line carries a PR (a `PR:` field, a `#n` in its `Context:`) and how it is read. Raised by the techlead's read of #3200 (m-58840274589f), which names TD-1526 (a design's Design PR field) as touching a board line's PR link.

**Fix:** Decide in design §4.5 screen 6 (and §4.4 where a board line's fields are listed) whether a board line that needs the person can carry a PR as its anchor, how it is written and read, and how it ties to the entry the PR names, as a mail item's PR does (`queue.pr_card`); or say plainly that a board line names entries only and drop the board-line half of the test. Coordinate with TD-1526's design (a Design PR field on a design's items).

**Done when:** The design says whether a board line can carry a PR anchor, and either a build entry carries it or the design states a board line ties by its `Context:` and `Parts:` alone.
