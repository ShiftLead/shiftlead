**Fix:** Build design §4.9a *The third declaration* (TD-1485's changes to it) and §4.10 *Outcomes*' added sentence:
1. **The later declaration stands** (`src/sessionorc/agent.py` `_ending`): a `restart` while `out_of_work` stands clears `out_of_work` and `lane_seen` and writes `restart_wanted`; a `none` while `restart_wanted` stands clears that dict (its `early`, `decided` and `repeat` with it) and `restart_blocked` and `restart_blocked_sent_at` (never `restart_ceiling`) and writes `out_of_work`. The `other`-refusal block is deleted whole. A `none` refused by the balance check clears nothing (that check runs before any clearing). The docstrings' *they refuse each other* (`_ending`, agent.py ~3999–4005, and `rpc_progress`, ~3683), `models.py`'s `restart_wanted` comment (~1278), the owed check's comment (~4017–4024, *A restart owes them for a reason of its own*), the owed refusal's message (naming `none`, and a restart of a member that is not supervised), `src/shiftlead/cli.py`'s `cmd_progress` docstring (~3046) and `tests/test_cli.py` (~1995–2019, *already wants a restart*) say the new rule.

No caller of `ao close` can set it, so a person's Close, a controller's, a stop's, a wrap-up's (`_finished_close`), a seat's own (`_seat_done`) and `_forget` settle as today. Only the home's close settles, so a node member's routed close needs nothing.
4. **A create that does not carry the mail settles the debt** (home-host records; a node member's records settle at the home as their mail is the home's): once a create under a name whose `kept` is false (no `keep_mail`, `succeeds`, same-conversation resume or scheduled start) has succeeded — where `s.supersedes = [{…, "mail": kept}]` is written with `kept` false (agent.py ~1689), and `_take_supersession`'s replace in place for a node member (agent_remote.py ~960) — the home settles each owed person-inbox entry whose `from_` is the old run's address `asker_gone`, by a helper split from `_asker_gone`'s owed loop, touching no open question.
