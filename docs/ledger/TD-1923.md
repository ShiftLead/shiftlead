## TD-1923: A run sent away at its context bound reads early and waits on the person, so nobody restarts it

**Priority:** High
**Type:** debt
**Added:** 2026-11-17
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 8ae43dbfe6f6425ba3244ed830825dce
**Part of:** TD-1900

**Why:** A run the home itself sent away at its context bound (§6 rule 5's line) declares `ao progress restart` and is read early when it reported nothing done inside `RESTART_EARLY`, so no rule performs it and it waits on the person: designer-ao-1 sat idle twenty hours that way on 2026-11-15/16 with the person's One more round on TD-1829 behind it (TD-1900).

**Fix:** Build design §4.9a *Early is decided from the record*, the paragraphs *A pushed commit is new work* and *A run past its context bound is not early*, and *What counts toward the ceiling* (TD-1900):

1. `gitinfo.pushed_since(directory, since_iso, timeout=5.0)`: the branch's own remote ref (`refs/remotes/<remote>/<branch>`, from the branch's configured remote, else `origin`; never `@{upstream}`, which a fresh worktree sets to `origin/main`), and on it `git log <ref> --not origin/HEAD --no-merges --format=%H %aI` under `read_only_env`; the first commit whose author date is at or after `since_iso`, compared in Python, else None — None on no such ref, a failed or timed-out read, or a directory not a worktree.
2. `agent.rpc_progress`'s `restart` branch, for a record whose host is the home, runs `pushed_since(s.dir, s.created)` with `asyncio.to_thread` before `_restart_reading` and hands it in (a node's record: `pushed=None`). `_restart_reading(s, now, pushed=None)` decides in this order: `said and not new` (a repeat, early, as today); `thrice`, only when `pushed` is None; a `pushed` sha → `{"early": False, "repeat": None, "words": "not early: pushed <sha[:7]> this run", "pushed": sha}`; inside `RESTART_EARLY` and not new, where `models.context_over({"context": s.context, "context_bound": s.context_bound})` → `{"early": False, "repeat": None, "words": "not early: context over its bound"}` (the last reading taken, a reading just under the bound reads under); then today's branches. The mark keeps `pushed` as `restart_wanted.pushed`.
3. The replay (§6 rule 1) copies the mark's `pushed` into the `restarts` entry beside `done` and `left`; `_counted` leaves out a `wanted` entry with a `pushed` sha, as it does one with a new `done`. A new `RESTART_PUSHED_CEILING = 6` in `agent_common`: `_wanted_restart` (rule 2) writes `restart_ceiling` with `why: "pushed"` when the wanted restarts inside `RESTART_WINDOW`, pushed ones included, reach it; `restart_waits`' short word for it is *restarts exhausted*.
4. A brief change or a relaunch still overrides the whole restart reading (`{early: False, repeat: None, words: None}`), as today, so neither new word is replied there.
5. Comments: the *a run that is over before it began did not run out of context* comment in `rpc_progress` (and the like one in `models.py`) names the two exceptions; `_idle_nudge`'s docstring names its `restart_wanted` return (design §6 rule 4).
6. Tests (`tests/test_restart_reading.py`, the tick's, gitinfo's): inside `RESTART_EARLY`, nothing new, over its bound → not early, *context over its bound*, and rule 2 replays it when idle, clean and pushed; the same under its bound → early; a repeat of the same `done` over its bound → still early; a pushed commit since `created` → not early, *pushed <sha> this run*, and not a repeat though the claim is in the last two entries' `left` (the 2026-11-15 sequence: two prior entries leaving TD-1895, the third run pushed); the same with nothing pushed → repeat; `_counted` leaves out an entry with `pushed`, and four context-bound restarts with nothing pushed trip `restart_ceiling` at the fourth; six pushed wanted restarts in the window trip it with `why: "pushed"`; `pushed_since` on a branch tracking `origin/main` with no own remote ref → None, on a rebased branch with old author dates → None, on a merge of main → None.

**Done when:** A restart whose run pushed a commit of its own branch, authored since its record began, is not early, not a repeat of a claim left and not counted toward `RESTART_CEILING`, but counts toward `RESTART_PUSHED_CEILING`; one declared over the record's context bound with nothing new and no repeat is written not early (*not early: context over its bound*); rule 2 performs both on the next tick; a repeat of the same `done` stays early; tests above pass.
