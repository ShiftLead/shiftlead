## TD-2225: The home writes the person's Go on a design's review record, which today stays pending

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-25
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 7aa7ac1c9a524d9fa5b57c4af701997d
**Part of:** TD-2222

**Why:** A press that lifts a design's gate with *Go* lifts the gate and closes the board line, so no session is sent after it, and nothing writes the Go on the design's review record. Forty-nine records read `Decided: pending` (seventeen also `Go by: pending`) although each design's Log ends `gate lifted: decision (paul)` (TD-2222). Design §4.4 *The same pass records a design's Go* (TD-2222) gives the record to the home's daily gate-sweep pass.

**Location:** src/sessionorc/gatesweep.py; the home's event runner pass; tests

**Fix:** Build design §4.4 *The same pass records a design's Go* (in the event runner's paragraph), in `src/sessionorc/gatesweep.py` and the home's daily pass that calls it.

1. **`record_owed(root) -> list[dict]`**: read the swept repo's ledger, its archive included, from the same `origin/<default>` reading the sweep uses. Take every entry with `Kind: design-first` that has a review record (`docs/reviews/TD-<n>.md`, in the repo's own form: three-digit ids as `TD-NNN`). An entry is owed a record when the newest gate line in its Log is a `gate lifted: decision (<p>) — by <by>; answer "<a>"` line (any answer, any road) and the record's `**Go by:**` reads `pending` or is missing, or its `**Decided:**` has no `YYYY-MM-DD` at its start (`review_stats.py`'s `DATE_RE` reading). A newer gate line of any other kind (a gate set again for a Hold, `kept waiting`) means nothing is owed. Each result carries the id, `by`, and the lift line's date.
2. **The write**, one PR for the repo on `record/<UTC date>`, from a worktree of the sweep's own (never the registered checkout), through `_ship`. It changes each owed record's header lines and nothing else. A `**Go by:**` reading `pending` becomes `**Go by:** <by>`; a missing one is added after `**Source:**`, else after `**Verdict:**`, else after `**Decided:**`. A `**Decided:**` with no date at its start becomes `**Decided:** <the lift line's date>`. A `Go by:` naming anyone else, and a `Decided:` starting with a date, are left. The subject is `shiftlead: record the Go on TD-a, TD-b (session n/a)`, and the body lists each record with its entry's lift line.
3. **The rules are the sweep's**: the home opens the PR and merges none. Nothing is written while an earlier `record/` PR is open. A record PR closed unmerged makes its records not owed for `reask_days`, read from `prs(…, "record/")` as the notices rule reads closed PRs. The pass runs on the event runner's schedule (once a UTC day, and on the tick after a live-ref push), after the lifts and the board PR, for every repo it sweeps. The run log says what it wrote or why it wrote nothing.
4. **A work order from its first reading**: add `record/` to the branches the reading treats as the gate sweep's PRs (*A PR the gate sweep opens is the team's at once*, TD-1854), so a grinder reviews and merges it as it does a `sweep/` PR.
5. **Tests**: a scratch repo with a design entry whose Log ends in a lift and whose record reads `pending` gets one PR changing those two lines. A missing `Go by:` is added in place. A record that names a judge, or already has a date, is untouched. A newer gate line means nothing is owed. An open `record/` PR blocks the write, and a recently closed one holds its records for the window. An archived design is read. Running the pass twice gives no second PR.

The first live pass writes the forty-nine records TD-2222's Why lists. Check its diff against each entry's lift line before merging it.

**Done when:** The home's daily pass opens one `record/<UTC date>` PR per repo with the Go of every lifted design whose record reads pending, and that PR is a work order. The tests above pass. Once the change is live, the first pass's PR is merged and no shiftlead review record of a design lifted with a Go reads `Go by: pending` or a dateless `Decided:`.
