## TD-1689: cache_capture.py's request decoding, error passthrough, 502 and deflate paths have no test

**Priority:** low
**Type:** debt
**Added:** 2026-11-11
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 7eaaa8a65a274803be620749647e5ac2
**Location:** scripts/cache_capture.py; tests/test_cache_capture.py

**Why:** **Why:** #3491 (TD-1664) added `scripts/cache_capture.py` with `tests/test_cache_capture.py` (5 tests). Its first test is named "passes each response through and writes the decoded bodies and no header", and the script's docstring says it writes "each request body and each response body, decoded". Reverting each of these lines in `scripts/cache_capture.py` in an audit worktree left all 5 tests passing (`PYTHONPATH=src pdm run pytest -q tests/test_cache_capture.py`):

- `rec.write(n, "request", decode(body, self.headers.get("content-encoding")))` → `rec.write(n, "request", body)`: the test posts plain JSON requests only, so a gzip-encoded *request* body being decoded before it is written is never exercised (only the gzip *response* is).
- `resp = e  # an error status is still the upstream's answer` → `raise`: no test has the stub upstream return a 4xx/5xx, yet the comment says the error is "passed on as it came".
- `self.send_error(502, ...)` → `send_error(500, ...)`: no test points `--upstream` at a closed port.
- `return zlib.decompress(body, -zlib.MAX_WBITS)` → `return body`: the raw-deflate fallback in `decode` has no case, and `deflate` has none at all.
- `k.lower() not in ("server", "date")` → `True`: the response would carry two `Server`/`Date` headers; no test reads the header set.
- `except (BrokenPipeError, ConnectionResetError): break` → `raise`: a client that goes away mid-stream is never simulated.

The recorded bodies are the whole point of the tool (TD-1684's measurement reads them), and a proxy that 500s or drops an error response in the live measurement would only show then.

**Fix:** **Fix:** In `tests/test_cache_capture.py`, add cases against the same stub upstream: a gzip-encoded request body whose recorded `NNNN-request.json` is the decoded JSON; an upstream 429 whose status, body and `retry-after` header reach the client and whose body is recorded; an `--upstream` on a closed port answering 502; a `deflate` response (zlib and raw) recorded decoded; the client response carrying one `Date` and one `Server` header. Each must fail when its line above is reverted.

**Done when:** **Done when:** each line quoted in **Why** fails `tests/test_cache_capture.py` when reverted in a worktree.
