**Fix:** - **The worked reading.** For each instant in the home's team record's `work_started` not yet in its new `work_worked` list: the start is *worked* when a record of the team (`by_team`, from `self._graph()`, live and ended) has as its newest `restarts` entry the start's own (`why == "work"` and `start` equal to the instant) and holds a `progress` entry with `source == "declared"`, `status` `claimed` or `done`, and `at` strictly after that entry's `at`. `_replay` restamps the waiting claims it carries with the entry's `at` (~3081–3086, *a renewal of the lease*), so `>` excludes them; a member the start did not replay, and a record a later restart (a person's Start, a schedule's, rule 2's) has superseded, never credit it. Append each newly worked instant to `rec["work_worked"]`.
- **Where it runs.** In the per-team loop (~2207), on every tick the team has `work_started`, **before `_work_mark` and `_work_start`**: a replay supersedes the record in place and its progress with it (`tests/test_work_start.py` ~361), so the reading must see the claim before the tick's own replay erases it — that is why `work_worked` is kept. The same step prunes both lists to `WORK_DAY` (today only `_work_start` prunes `work_started`, ~2461, and only under a standing mark), `work_worked` to the instants still in `work_started`, and pops each when empty. The loop's change check (~2220, `rec.get("work_started") == starts`) compares `work_worked` too, so a newly worked start is written.
- **The cap.** `_work_held` (~2554): `if len([t for t in started if t not in worked]) >= agent_common.WORK_STARTS_DAY` holds `{why: day, count: <that number>}`. `WORK_EARLY` still reads `started[-1]`, every start. `WORK_STARTS_DAY` stays 3; the comment at `agent_common.py:89` says idle starts.
