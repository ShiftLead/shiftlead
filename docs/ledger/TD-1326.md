## TD-1326: Amend ADR 2026-10-12 for ledgerboard's new boundary: the file-level writers `ledger.py` and `board.py` move into ledgerboard

**Priority:** medium
**Type:** debt
**Added:** 2026-11-03 (ao-led-tds-ledger, through `ao td add --repo`, from ledgerboard's target design; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** designer
**Kind:** build
**Status:** Open
**Location:** `docs/decisions/2026-10-12-ledgerboard-dev-cadence-shiftlead.md` (*Decision* — *The three layers*, ledgerboard's row and its API); ledgerboard `docs/plans/target-design.md` §1.1, §1.2 (ledgerboard#57, merged)

**Why:** ShiftLead's ADR 2026-10-12 sets ledgerboard's boundary at the formats as text: `SPEC.md`, one stdlib module and conformance fixtures, nothing else. ledgerboard's target design (agreed with Paul's go 2026-11-02, ledgerboard#57) moves the file-level writers `ledger.py` and `board.py` into ledgerboard, as a `ledgerboard/` package beside the module (§1.1), because both consumers need the same file handling and each wrote its own — the drift the ADR was written to end. The ADR is ShiftLead's, so its amendment is a PR here; until it lands, ledgerboard's v2.3 release contradicts the decision it cites.

**Fix:** amend the ADR (cadence §7.5's edit of a decided ADR: a dated amendment line in its Status and the changed row, not a rewrite): ledgerboard holds `SPEC.md`, the module, the two file-level writers (`ledger.py`, `board.py`, in the `ledgerboard/` package) and the fixtures; never git, the network, the roster, forges, trackers, delivery, sweeps, sessions, or logic that knows either consumer. What a writer needs from outside — the next id, cross-repo state, who answered, the date — is passed in; branches, commits, PRs, the id counter and attesting the session stay the consumers'. Cite the target design §1.1, and §1.2 (more format logic as pure module functions: the id rule, the sweep's decisions, the lift-PR verdict, the *needs you* list).

**Done when** the ADR states the amended boundary, the PR is read by the techlead and merged, and ledgerboard's v2.3 release can cite it. It must merge before that release.

**Related:** ledgerboard#57 (the target design, Paul's go 2026-11-02); ADR 2026-10-25 (ShiftLead requires dev-cadence, which already supersedes part of ADR 2026-10-12); TD-1286 (the ledger and board written only through the helpers).
