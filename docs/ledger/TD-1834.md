## TD-1834: #3815's Focus release call to AO.releaseAct has its arguments held by no test

**Priority:** low
**Type:** debt
**Added:** 2026-11-14 (test-audit-ao-1, auditing #3815, which built TD-1279)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 66a790e6695c4900a0a9428f84300df2

**Why:** #3815 (TD-1279) moved the Focus release's decision to `AO.releaseAct` and probed it under node, but the listener's call to it is held only by source-text asserts (`"AO.releaseAct(" in release`, `'r.act === "note"'`, `copySel(r.edge)`), not by running it. The call's arguments are the behaviour and no test sees them. Probes at origin/main a1db5964d, each edit made alone to `src/shiftlead/ui/static/app.js` line 8453 (`const r = AO.releaseAct({ fire: up.fire, pos, rows: term.rows, copyOn: !!(cos && cos.checked && !cos.disabled), text: t });`), restored after, then `PYTHONPATH=$PWD/src pdm run pytest -q tests/test_ui_menu.py tests/test_ui_focus_copy.py tests/test_ui.py -k "menu or copy or release or toast"` gives `13 passed` every time:
- `!cos.disabled` dropped from `copyOn`: copy on select disabled (the page is not a secure context, so `cos.disabled`) is then treated as on, and a release copies and fails where the edge's note belongs (§4.6 *A selection is one screen*);
- `rows: term.rows` replaced by `rows: 24`: the bottom edge stands only on a 24-row screen;
- `fire: up.fire` replaced by `fire: "top"`: every moved release reads as a top-edge release.
The same probes on the mousedown, the `copySel(r.edge)` call and `AO.pressEvent` do fail a test, so only the release's arguments are bare.

**Location:** src/shiftlead/ui/static/app.js (the Focus terminal's mouseup listener calling AO.releaseAct); tests/test_ui_focus_copy.py, tests/test_ui.py

**Fix:** Run the release listener against a stub, as `tests/test_ui_menu.py` does for the page's capturing listeners (TD-1339): a fake `term` (`rows`, `getSelection`, `getSelectionPosition`, `onSelectionChange`), `$("#term")`, a `cos` checkbox (checked, disabled) and `document.addEventListener` keeping its handlers, then fire a `mousedown`, `mousemove` and `mouseup` through them and assert whether `copySel` or the edge's toast ran. Or build the argument object in a pure `AO.` function (from `up`, the terminal and the checkbox) and probe that.

**Done when:** Each of the three edits above fails a test.
