## TD-1650: The home notices a seat profile's tool upgraded since its last smoke and asks for the smoke, spending nothing

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-11
**Owner:** designer
**Kind:** design-first
**Status:** Designed (PR #3569, review rounds running): builds TD-1726 (each launch reads the tool's version through the adapter's tool_version() onto the record) and TD-1727 (the home notes the person once when a seat profile's version changes on a host). Class: in-repo — the adapter contract, the launch and the home's tick, all in this repo; cap `design-rounds` (4). Who gets the note: the person; the techlead took the steer's default (m-e68556b8d924).
**Id take:** 5d2c02ce92f44638b765e67b45322c38
**Location:** design §4.3 *The live smoke, unattended*; §4.4; src/sessionorc/adapters.py (a version read)

**Why:** TD-1577's live smoke (§4.3 *The live smoke, unattended*) runs by hand, and one of its triggers is a tool upgrade on a seat's profile. TD-1576 came from an upgrade no entry named, so a trigger that waits for someone to file the upgrade misses the case that prompted TD-1577. The techlead's answer to the steer on TD-1577 (m-87af98f8e810, 2026-11-11) asks for a cheap middle way: the home notices that a seat profile's tool version changed and says so, asking for the smoke, without running it, so no quota is spent. A scheduled smoke stays the person's to choose, as a standing spend.

**Design PR:** #3569

**Fix:** Design round (§4.3 *The live smoke, unattended*; §4.4 the home's tick; §4.5 where the person sees it). Settle:
- how the home reads a seat profile's tool version without spending quota (the tool's `--version`, read where the launch already resolves the binary, or the version a hook payload or transcript carries), per adapter, through the adapter contract and naming no tool in core;
- where the last smoke's version is kept (the profile's last passing smoke line, quoted in a PR, is not machine-read today) and what counts as changed;
- what the home says and to whom: a board line or a note to the team's techlead asking for the smoke on that profile, once per version, never repeated each tick;
- that nothing is run: no smoke, no prompt, no quota.

**Done when:** A merged design that says how the home reads a seat profile's tool version, where the last smoked version is kept, and what it says when they differ, with its builds filed `Part of` this entry.
