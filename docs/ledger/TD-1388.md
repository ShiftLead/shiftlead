## TD-1388: The event runner answers `check: host-log` from the witness log

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-04 (the designer, from TD-1295's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** TD-1387, TD-1376, ledgerboard#TD-045
**Part of:** TD-1295
**Location:** the event runner (TD-1376: `src/sessionorc/agent_tick.py`, `src/sessionorc/ledger.py`); `src/sessionorc/witness.py`; the vendored ledgerboard release that carries `host-log` (`src/sessionorc/ledgerboard/`); design §4.4 *The home keeps a log of what it witnesses* (*The check*)

**Why:** TD-1295's design: ledgerboard's `host-log <kind> "<text>" [times N]` check (its TD-045) is answered by the host; until the runner answers it, a wait on what the home witnesses can be written only as the retired `Waits: event` line, which nothing resolves.

**Fix:** as design §4.4 *The check* says: in the runner, answer `host-log` from `witness.count` over every repo's records with `since` the gate's `gate added` Log date; passed when the count reaches N, not yet otherwise, never impossible, error for a kind not in `KINDS`, a refused query (a `since` older than the log keeps — never a short count) or an unreadable log. The lift line's evidence gives each counted record's `at` and `text` where its `repo` is the ledger's own or one the registry knows to be at least as visible, and its `at` alone, marked *(a private repo's)*, for any other. Vendor the ledgerboard release that carries TD-045 if TD-1376's vendor does not already.

**Done when:** tests that a `host-log` gate lifts once its Nth record comes, that a record dated before the gate's `gate added` date never counts, that a private repo's record counts for a public ledger but its lift line carries its `at` alone, never its text, and that each error outcome (an unknown kind, a `since` older than the log keeps) reaches the sweep as an error, never as not yet.

**Related:** TD-1295 (the design); TD-1386, TD-1387; TD-1376 (the event runner); TD-1385 (a live check's gate, which may use it); ledgerboard#TD-045.
