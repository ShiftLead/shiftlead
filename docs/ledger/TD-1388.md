## TD-1388: The event runner answers `check: host-log` from the witness log

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-04 (the designer, from TD-1295's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** TD-1387, TD-1376, ledgerboard#TD-045
**Part of:** TD-1295
**Location:** the event runner (TD-1376: `src/sessionorc/agent_tick.py`, `src/sessionorc/ledger.py`); `src/sessionorc/witness.py`; the vendored ledgerboard release that carries `host-log` (`src/sessionorc/ledgerboard/`); design §4.4 *The home keeps a log of what it witnesses* (*The check*)

**Why:** TD-1295's design: ledgerboard's `host-log <kind> "<text>" [times N]` check (its TD-045) is answered by the host; until the runner answers it, a wait on what the home witnesses can be written only as the retired `Waits: event` line, which nothing resolves.

**Fix:** as design §4.4 *The check* says: in the runner, answer `host-log` from `witness.count` with `since` the gate's `gate added` Log date and `repos` the ledger's own repo and every registry repo at least as visible; passed when the count reaches N, not yet otherwise, never impossible, error for a kind not in `KINDS`, a refused query or an unreadable log; the lift line's evidence is the counted records' `at` and `text`. Vendor the ledgerboard release that carries TD-045 if TD-1376's vendor does not already.

**Done when:** tests that a `host-log` gate lifts once its Nth record comes, that a record from before the gate's `gate added` date never counts, that a private repo's record never counts for a public ledger, and that each error outcome reaches the sweep as an error, never as not yet.

**Related:** TD-1295 (the design); TD-1386, TD-1387; TD-1376 (the event runner); TD-1385 (a live check's gate, which may use it); ledgerboard#TD-045.
