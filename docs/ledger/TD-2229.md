## TD-2229: A design's end-of-rounds question can recommend another review round where the shared rules now recommend otherwise

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-25
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 75590b2dcc4148f5bdb982208d1c9fc5

**Why:** Audit of #4672 (round 5 of TD-2182's design). `docs/briefs/designer-ao-1.md` holds a rule written as temporary: "**A fix no review has read recommends One more round** (agent-cadence#TD-243, until a pinned §4.8 says it, when this line goes): while any build-changing fix is unread by a review … the end-of-rounds item recommends `One more round`, never `Go`". TD-1490 added it (#3124, 2026-11-07).

The pinned cadence says it now. agent-cadence#TD-243 is archived `Resolved 2026-11-18`: "no build-changing fix ends the rounds unread — a closing read reads it — and the item recommends the counted verdict; written into cadence.md §4.8 by TD-287". This repo's pin first carried that commit with #4106 (c7fb0c1ac, 2026-11-18), and the line stayed. §4.8 as pinned says the item's recommendation is "the counted verdict, never the author's (after a bought round: `Go` on a counted `Go`, `Hold` on a counted `Hold`, `One more round` on a counted `Closing read`)", reached through `review_stats.py --verdict`, a closing read and a judge, and it has the record carry `Reach:`, `Go by:`, `Holds:` and `Bought:` lines. The brief names none of the verdict, the closing read or the judge, and its closing-fact-check bullet repeats *recommend One more round*.

What it did in #4672: `agent-cadence run review_stats.py --verdict TD-2182` on that PR's record prints `build-changing per round (design reviews / fact-checks): 1: 10/1, 2: 4/0, 3: 1/0, 4: 1/0, 5: 8/0`, `last 3 rounds not falling: yes`, `verdict: Hold: split or narrow` (the same with a `Bought: 4` line added to a scratch copy). The board item that PR raised, `docs/user_attention/2026-11-25-8805257a.md`, answers `One more round (default)` and shows the person neither the counted verdict nor the per-round counts (its context says only that round 5 found more than round 4); it also names its five unread fixes in words, not by finding id (F54 to F58), which the brief itself asks for. `docs/reviews/TD-2182.md` has no `Reach:`, `Go by:`, `Holds:` or `Bought:` line (the verdict warns `no Reach: line — read as far-reaching`).

The harm: the person is recommended another round on a design the shared count says to split or narrow, and is not told that the two differ.

**Location:** docs/briefs/designer-ao-1.md

**Fix:** In `docs/briefs/designer-ao-1.md` (a held path), drop the *A fix no review has read recommends One more round* line, and bring the closing-fact-check and end-of-rounds bullets into line with the pinned cadence §4.8 and `procedures/cadence.md` step 3: follow `review_stats.py --verdict`'s `next:` line, recommend the counted verdict, and write the record's lines; say only what this repo does differently. If board item 2026-11-25-8805257a is still open and undecided when this is picked up, close it as superseded and file a corrected one carrying the counted verdict, the trend and the unread findings by id (cadence §3.11's pair).

Should the repo mean to keep recommending `One more round` over the counted verdict, that is a local rule to be written as one, without the expiry clause, and is the person's to decide.

**Done when:** `docs/briefs/designer-ao-1.md` holds no rule that recommends a different answer from `review_stats.py --verdict` on the pinned cadence, or states a local rule that does so on purpose; and no open end-of-rounds item recommends against its design's counted verdict without saying so.
