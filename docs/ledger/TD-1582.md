**Why:** TD-1576's design (design §4.3 *The untrusted-flags guard*, §4.7 `ao reply`, §4.9b *The fact-check*): Gemini CLI 0.66.0 asks before any shell command carrying an option word that appeared in an earlier command's output, under yolo too and whatever a policy says, so ao-grind's Gemini fact-check seat stopped on every `ao msg --reply-to` (four prompts in five minutes, 2026-11-10). The design gives the seat's road positional forms, so nothing on it is an option the guard can stop on.

**Ask:** Should this build go ahead as TD-1576's design writes it, after four review rounds ended at the cap? The board's TD-1576 decide item asks it; Go lifts this gate.

**Fix:** Build design §4.3 *The untrusted-flags guard* and §4.7's `ao reply` and `ao inbox` text:
