## TD-2101: Stop test runs leaving tmux sockets and owner files behind

**Priority:** High
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** d479a6810d64484fbb956ab18ca5b62a
**Part of:** TD-2080

**Why:** Part of TD-2080: `tests/test_ui_term_mark.py` names its own `ao-mark-*` socket and only runs `kill-server`, which leaves the socket file, and `sweep_stale_test_servers` looks only at `ao-test-*`. 5,124 such sockets were removed by hand on 2026-11-23, at up to 240 a day. `private_socket_name()` also writes an owner file at once, and the sweep walks sockets, so an owner file with no socket stays: 2,720 files in `/tmp/ao-test-owners-1000`, about 350 added that day.

**Location:** tests/test_ui_term_mark.py, tests/conftest.py

**Fix:** Make the test use `private_socket_name()` and remove its socket as `kill_private_server` does. Have `sweep_stale_test_servers` also remove an owner file whose pid is dead and whose socket is gone, and any `ao-mark-*` socket left by an older run that nothing is listening on.

**Done when:** A full suite run adds no `ao-mark-*` socket to `/tmp/tmux-<uid>`. An owner file with a dead pid and no socket is removed by the next run, and one with a live pid is kept.
