## TD-1772: The replay kit: scripts/design_replay.py prepares a replay's cut-off tree, runs it outside the org and audits it

**Type:** feature

**Kind:** build
**Status:** Open

**Part of:** TD-1722

**Why:** Part of TD-1722's trial of the new shape (design §4.9c *The trial of the new shape*). A replay needs a tree cut off from what came after the design, the new shape laid over it, a run outside the org, and an audit that the run stayed inside the tree.

**Ask:** Is TD-1722's trial design (three cut-off replays scored blind against the originals' findings, then the first ten real designs read against the ten before them) ready to build, or does it take one more review round to read its last three fixes (how a replay run ended; what --max-turns counts; the bound set again where it counts the reviewers' turns too)?

**Location:** scripts/design_replay.py, tests/test_design_replay.py

**Fix:** Build `scripts/design_replay.py` with three subcommands, as design §4.9c *The trial of the new shape* says. **prepare TD-<n>** — the next run number `k`; the trial commit, `origin/main` at the first `prepare` of all, written to `~/replays/trial` and read by every later one; the base (`origin/main` as it stood when the first PR of the entry's `Design PR:` was opened, its time from `gh pr view`, by `git rev-list -1 --before`); its files by `git archive` committed as the root commit of a new repository at `~/replays/TD-<n>.<k>` with no remote, and `~/replays/TD-<n>.<k>.tmp` made; the overlay commit `replay overlay (TD-1722)`: `scripts/design_prep.py`, `REPLAY.md` (the replay's brief as the section words it, the trial commit's `docs/briefs/designer-ao-1.md` whole less any sentence naming a replayed design, §4.9c from *What a design's author prepares before a review* through *The gate*, less the checklist paragraph's sentences naming the replayed designs), `.claude/settings.json` with its `SessionStart` hook removed, and `AGENTS.md` with its *First, every session* section replaced by *a replay runs no session-start hook, follows `REPLAY.md`'s rules over this file's, and reads `REPLAY.md` again after any compaction*; then the base's agent-cadence pin made available, and `scripts/design_prep.py --entry TD-<n> --advisory` run once on a scratch commit over the overlay adding an empty prep file, `--base` the overlay commit, the scratch commit then dropped, each CANNOT RUN cause it prints (one `;`-separated item of a CANNOT RUN line, or a tool's could-not-run line under a FAIL) written into `REPLAY.md` as allowed (a run that cannot start stops `prepare`); and `ledger.py new --id TD-9001` and a `ledger.py note` run on that scratch commit under the base's pin, each that refuses (a tree with no `origin` has no id counter) written into `REPLAY.md`, for the replay to write by hand in the base's form. It prints the trial commit, the base, the overlay commit and `k`. **run TD-<n>** — for the newest run: `claude -p` in its tree, `REPLAY.md`'s text the prompt, `--model claude-opus-5-5`, `--max-turns <n>` (`run --max-turns`, required when `run` starts a run), `--permission-mode bypassPermissions`, `CLAUDE_CONFIG_DIR=~/.claude-conformance` (the conformance profile, never `~/.claude`), `--setting-sources project`, stream JSON to `~/replays/TD-<n>.<k>.stream.jsonl`, every `SHIFTLEAD_*` variable removed, `TMPDIR` the run's temporary directory, and a stub directory first on `PATH` whose `ao` and `gh` log the call to the run's directory and exit 2, detached by `setsid` under `timeout` (24 hours; 72 when the original's record has more than six rounds), its pid in `~/replays/TD-<n>.<k>.pid`, printed as `run` returns; refusing while any replay's pid is alive; the wrapper under `setsid` writes the run's exit code to `~/replays/TD-<n>.<k>.exit`; `run --wait` never starts a run: it waits for that file, or for the pid to be gone with no file written, and prints how the run ended, one of `result` (the tree's last commit's subject is `replay result (TD-1722)`), `max-turns` (the stream's last result is the max-turns error), `timeout` (exit 124), `limit` (the stream ends on the account's limit), `stopped` (a `Decided: replay stopped` line in the tree's `docs/reviews/TD-<n>.md`), `signal` or `other` (a wrapper gone with no exit file among them), exiting 0 on `result` alone. **audit TD-<n> <k>** — run `k`'s transcripts in the conformance profile's project directory for its tree (subagents' with them): a flag for each `Read`, `Edit`, `Write`, `Glob` or `Grep` path, and each absolute or `~` path in a `Bash` command's text, outside the four allowed places (the tree, the agent-cadence tree, the main checkout's `.venv` directory and the run's temporary directory); and for every `ao`, `gh`, `agent-cadence hook`, `agent-cadence run` of a script but `ledger.py` and `cadence_config.py`, remote `git`, `git -C` on another path and web tool, and every call the stubs logged; never flagging a fixed harmless set its output lists (`/dev/` paths, system binaries and libraries under `/usr`, `/bin` and `/lib`, Claude Code's own files for the run under its project directory); its output says it cannot see a path a script computes; exit 1 on any flag. Every path is under `--root` (default `~/replays`); `prepare --script-from <commit>` takes `scripts/design_prep.py` from a later commit after a fix to the trial's own tool, recorded beside the trial commit. Tests in `tests/test_design_replay.py` with a scratch repository, `--root` a scratch directory, and transcript fixtures; `run`'s command and environment are checked, never run.

**Done when:** Done when `prepare` on a scratch repository builds run 1 and then run 2 beside it, each with the base's files as its root commit and an overlay commit holding `REPLAY.md`, the script, no `SessionStart` hook and the replaced `AGENTS.md` section; `audit` flags each forbidden call in a fixture and passes a clean one; `run` builds the command and environment the section names; and the tests pass.
