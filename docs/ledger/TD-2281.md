## TD-2281: The design says a built-in seat that crashes on another machine is restarted, which never happens

**Priority:** Low
**Type:** debt
**Added:** 2026-11-26
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 4e760c664fe64ff0bd8f501430665f6d

**Why:** Audit of #4768 (TD-2068 slice 14). It added to design §4.9d *How each one runs*: "**Nor is it a restart**: rule 1's crash and lost-brief replays of a seat on a node send its launch record's list as names, so the node picks again, and its refusal of that list counts toward no restart ceiling". Rule 1 makes no crash replay of such a seat.

- Design §6 *Keeping a team running*, rule 1, restarts after a crash "A supervised member **other than a seat**" (an extra seat excepted), and says "a seat's ending is its own, and rule 3 is the only rule that fills one, save the replay of a seat whose run never started".
- The only caller of `_replay(s, "crash")` is `_crash_restart`, which returns unless `_crashed` holds, and `_crashed` takes a seat only where it is an extra that owes a reading (`src/sessionorc/agent_tick.py`). After the cut-over `_rules_reach` lets rules 1, 3, 4 and 5 act only on a built-in seat's record or the director's, each of which carries `seat`.
- Probe at 0cdfc7bb6, with the fixtures of `tests/test_builtin_fill_login.py`: the held tech lead seat set `exited` with `pane` true gives `_rules_reach` True and `_crashed` False, and `_crash_restart` leaves `restarts` unchanged and launches nothing; the same record with `seat` cleared gives `_crashed` True.
- `test_a_nodes_list_refusal_of_a_replay_is_no_restart` passes for `crash` because it calls `_replay` itself, past that test.

The comment over `NODE_LIST_REPLAYS` and the docstring of `_node_list_refused` say the same as the design.

**Location:** docs/design/4.9d-teams.md How each one runs; src/sessionorc/agent_tick.py NODE_LIST_REPLAYS, _node_list_refused; tests/test_builtin_fill_login.py

**Fix:** In §4.9d *How each one runs* name the lost-brief replay alone, a built-in seat that exits being rule 3's to fill (§6 rule 1). Take `crash` out of `NODE_LIST_REPLAYS`, its comment and the docstring of `_node_list_refused`. In `tests/test_builtin_fill_login.py` take out the `crash` case of `test_a_nodes_list_refusal_of_a_replay_is_no_restart`, and move `test_a_replays_mark_is_read_against_the_list_it_sends`, which calls `_replay(s, "crash")` and fails once `crash` is out of the list, and `test_a_replay_of_a_launch_record_with_no_list_is_sent_as_before` to `lost-brief`. Add the history line to this entry's history file under §4.9d. Where a crash replay of a built-in seat is wanted after all, that is a change to §6 rule 1 first, for the tech lead.

**Done when:** Neither §4.9d nor the code's comments, docstrings or tests say that rule 1 replays a built-in seat or the director after a crash, or §6 rule 1 and the code make that replay.
