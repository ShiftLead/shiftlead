**Why:** Once flows run, a pickable live check is offered to the stage that takes `other` or `any`, which is a build stage (design 4.9c *Ways in*; the techlead's reply m-cf7d359d2157). **Ask:** Should the grinders build the design that tells a live check session how to read, wait and finish?
