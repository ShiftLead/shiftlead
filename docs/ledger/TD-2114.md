## TD-2114: A session offered a live check is told to build, because the standard build brief has no words for a check

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-23
**Owner:** designer
**Kind:** design-first
**Status:** Open
**Id take:** 5f46ea1dd9884de9a940d8e2e626036c

**Why:** Once flows run, a pickable live check is offered to the stage that takes `other` or `any`, which is a build stage (design 4.9c *Ways in*; the techlead's reply m-cf7d359d2157). A live check is read against the running system, never pressed, and ends in one of four ways (design 4.9b *A live check is a grinder's once its build is live*). 4.9c *What a stage's session is told* does not say how the standard build brief handles one, so a session offered a live check would be told to build.

**Location:** docs/design/4.9c-flows.md (What a stage's session is told)

**Fix:** Design what the standard build brief, or the mechanics in a stage's opening prompt, tells a session whose entry is a live check: read the live copy and never press it, the four endings, and which `ao stage end` outcome each is. Write it in 4.9c *What a stage's session is told*, and file the build.

**Done when:** Design 4.9c says what a build stage's session does with a live check, and the build that carries it is filed. It lands before the tick's wiring (TD-2051) offers a live check to a session.
