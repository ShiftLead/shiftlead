## TD-2122: A killed precheck's dependency install leaves build directories in shared temporary space

**Priority:** Low
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 62f3e165384745c19c71628b5f9e28f2
**Part of:** TD-2106

**Why:** Part of TD-2106. A `pdm sync` killed partway leaves its build directories in bare `/tmp`, because the precheck sets `TMPDIR` only for its test step. Read on 2026-11-23: 382 such directories in eight batches of 34 to 88, while a finished sync removes its own.

**Location:** docs/cadence.toml, design 4.6

**Fix:** Design §4.6 *The pressure pass*, last sentence of its rules. In `docs/cadence.toml`, in both the `precheck` command and the docs command under `[precheck-paths]`, change `pdm sync -G ui -G dev` to `TMPDIR="$T" pdm sync -G ui -G dev`. Nothing else in either command changes. Add a test that takes each command's text from `T=$(mktemp` onward, so the leading `find` over the real `/var/tmp` never runs, and runs it with a stub `pdm` on `PATH` that exits 0 and records `TMPDIR` for each subcommand. It asserts that the `sync` call saw the run's `/var/tmp/pc.*` directory.

**Done when:** Both precheck commands run `pdm sync` under the run's own directory, a test holds it for both, and a sync killed partway leaves nothing new in `/tmp`.
