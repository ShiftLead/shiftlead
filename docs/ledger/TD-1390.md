**Location:** `src/sessionorc/witness.py` (`OWN_REPO`, `KINDS`, `repo_named`, `query`, `ensure_start`); `src/sessionorc/agent.py` (`_witness_repo`, `rpc_witness_press`, `rpc_host_log`, the agent's start); `src/sessionorc/reports.py` (`witness_prechecks`, the open-PR read), `src/sessionorc/promote.py` (`witness_main`) (the `precheck-fail` writer's repo); `src/sessionorc/agent_tick.py` (`_refresh_repos`, where the id cache empties); `src/sessionorc/modes.py` (`HOME_READS` and its comment) and `src/sessionorc/identity.py` (`READS`); `src/shiftlead/cli.py` (`ao host-log`) and `src/shiftlead/skill.md`; `src/sessionorc/agent_common.py` (`BACKUP_MEMBERS`); `tests/test_witness.py`; design §4.4 *The home keeps a log of what it witnesses*

**Why:** ledgerboard's TD-045 was revised after TD-1295's design (revision 2, its #141, Paul's go; ledgerboard TD-047/TD-048): a check names a source, agent-cadence's `hostlog.py` reads it and counts, a record counts only when its `repo` equals the ledger's `<repo>` id, and the host's own file allows a folder and marks kinds public. TD-1386 and TD-1387 were built to revision 1: their records carry the registry name (`shiftlead`), which equals no ledger's id, so no record would count; each kind declares a class the host file now holds; and the `host_log` read and `ao host-log` are a second count beside the reader's, built on revision 1's rules (a record of no repo tied to `shiftlead`, `covers_from`), which could disagree with it.

**Fix:** as design §4.4 *The home keeps a log of what it witnesses* now says:
1. **A record's `repo` is the repo's `<repo>` id**, the path of its origin as the vendored `origin_path()` reads it, lowercased (`shiftlead/shiftlead`). The `precheck-fail` writer's callers (`reports.witness_prechecks`'s `repo`: `reports.pr_reading`, which passes the registry name today, and `promote.witness_main`) pass `origin_path()` of the origin they already hold (`pr_reading`'s `remote` parameter, `witness_main`'s `r["origin"]`), never another `git_origin` call. The press writers (`_witness_press_of`, reached from `rpc_witness_press`, `inbox_hand` and `push_subscribe`) take it from a cache keyed by registered root, filled on a miss by `reports.git_origin(root)` under `asyncio.to_thread` and emptied at each repo facts reading; `repo_named` still gives the registry name for the press text. `OWN_REPO` becomes `shiftlead/shiftlead` and is written into the record of a word with no `dir` (`host-rebuild`, `push-on`). A press or a precheck in a repo with no readable origin is not recorded, and `append` refuses an empty `repo`. Records already written keep their registry name.
2. **`at` is written ISO 8601 with `Z`** within the reader's subset (`YYYY-MM-DDTHH:MM[:SS[.ffffff]]Z`), as `_iso` does today; a test pins it.
3. **`KINDS` drops `class`** for a `public` flag (both kinds true), from which the host file's `public_kinds` is written.
4. **The home writes `host-log.toml`** in its store at the agent's start when it is absent, after `ensure_start` has made `witnessed/`, whole or not at all (a temporary file renamed), and never rewrites it: a comment that a `[repos."<repo>"]` table the person adds replaces `[repos."*"]` for that repo whole (rule 9); `[repos."*"]` with `profiles = []`; `[repos."*".sources.witnessed]` with `path` the store's real `witnessed/` path and `public_kinds` the kinds flagged public; one `[[allow]]` root, that folder, `visibility = "private"`, `require_repo = true`; paths written as TOML basic strings, escaped as JSON escapes them. At each start, when no `[[allow]]` root in the file is the current `witnessed/` (a moved home, another `SHIFTLEAD_HOME`), the home logs a warning naming both. A node writes none. `host-log.toml` joins `agent_common.BACKUP_MEMBERS`.
5. **The `host_log` home read and `ao host-log` go**: `rpc_host_log`, its `HOME_READS` and `identity.READS` entries (and `modes.py`'s comment naming it), `witness.query`, `witness.covers_from` (`start` read as coverage; `boundary()` stays, for `prune` and `append_precheck_fail`), `ao host-log` and `--kinds`, their lines in `skill.md`, and their tests in `tests/test_witness.py`. `witnessed/start` stays, as the writers' floor alone.

**Done when:** tests that a press in a registered repo records the repo's lowercased origin path in `repo` and its registry name in the text; that a cold cache is filled off the loop and an origin changed between two repo facts readings is read again; that `host-rebuild` and `push-on` record `shiftlead/shiftlead`; that a press, and a precheck failure, in a repo with no origin records nothing; that a `precheck-fail` record from the open-PR read and from main's pass carries the repo's id; that `append` refuses an empty `repo`; that `at` matches the reader's subset; that `KINDS` carries no `class` and `public_kinds` is written from its `public` flags; that `host-log.toml` is written once, after `witnessed/` exists, with the comment, the root, `require_repo` and `public_kinds` above, a store path holding a `"` or `\` escaped, left as the person edited it on the next start, a warning logged when its root is not the current `witnessed/`, and absent on a node; that it is in the nightly tarball; and that `host_log` and `ao host-log` are gone (an unknown method, an unknown command), with `witness.query`'s and `covers_from`'s tests.
