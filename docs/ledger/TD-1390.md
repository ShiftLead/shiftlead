**Why:** ledgerboard's TD-045 was revised after TD-1295's design (revision 2, its #141, Paul's go; ledgerboard TD-047/TD-048): a check names a source, agent-cadence's `hostlog.py` reads it and counts, a record counts only when its `repo` equals the ledger's `<repo>` id, and the host's own file allows a folder and marks kinds public. TD-1386 and TD-1387 were built to revision 1: their records carry the registry name (`shiftlead`), which equals no ledger's id, so no record would count; each kind declares a class the host file now holds; and the `host_log` read and `ao host-log` are a second count beside the reader's, built on revision 1's rules (a record of no repo tied to `shiftlead`, `covers_from`), which could disagree with it.

**Fix:** as design §4.4 *The home keeps a log of what it witnesses* now says:
1. **A record's `repo` is the repo's `<repo>` id**, the path of its checkout's origin as the vendored `origin_path()` reads it (lowercased, `shiftlead/shiftlead`): `repo_named` gives the registry name (for the press text, unchanged) and the id (for `repo`); `OWN_REPO` becomes `shiftlead/shiftlead` and is written into the record of a word with no `dir` (`host-rebuild`, `push-on`), never left empty; a press whose `dir` is in a repo with no readable origin is not recorded; the `precheck-fail` writer writes its repo's id the same way, which its callers now pass (`reports.witness_prechecks`'s `repo`: `promote.py`'s pass, `agent_tick.py`, `agent_promote.py`, and the open-PR read in `reports.py`, which passes the registry name today). Records already written keep their registry name.
2. **`at` is written ISO 8601 with `Z`** within the reader's subset (`YYYY-MM-DDTHH:MM[:SS[.ffffff]]Z`), as `_iso` does today; a test pins it.
3. **`KINDS` drops `class`**: each kind keeps its text shape and a `public` flag the host file's `public_kinds` is written from.
4. **The home writes `host-log.toml`** in its store at the agent's start when it is absent, and never rewrites it: `[repos."*"]` with `profiles = []`; `[repos."*".sources.witnessed]` with `path` the store's real `witnessed/` path and `public_kinds` the kinds flagged public (`precheck-fail`, `press`); one `[[allow]]` root, that folder, `visibility = "private"`, `require_repo = true`. A node writes none. `host-log.toml` joins `agent_common.BACKUP_MEMBERS`, and §4.4a's backup list names it.
5. **The `host_log` home read and `ao host-log` go**: `rpc_host_log`, its `HOME_READS` and `identity.READS` entries, `witness.query`, `witness.covers_from` and the retention boundary it reads, `ao host-log` and `--kinds`, and their lines in `skill.md`. `witnessed/start` stays, as the writers' floor alone.

**Done when:** tests that a press in a registered repo records the repo's origin path in `repo` and its registry name in the text; that `host-rebuild` and `push-on` record `shiftlead/shiftlead`; that a press in a repo with no origin records nothing; that a `precheck-fail` record carries the repo's id; that `at` matches the reader's subset; that `host-log.toml` is written once with the root, `require_repo` and `public_kinds` above, left as the person edited it on the next start, and absent on a node; that it is in the nightly tarball; and that `host_log` and `ao host-log` are gone (an unknown method, an unknown command).
