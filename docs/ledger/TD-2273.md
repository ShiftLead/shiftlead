## TD-2273: The command that shows a built-in set does not say a seat is held back on another machine

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-26
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 4ef238fdbf174967acae34f25d3e8a99

**Why:** Audit of #4760 (TD-2068 slice 12). Design §4.9d *Where a seat's session launches* says of a node's mark that a built-in set cannot run a seat there: "`ao builtins show` gives it on the seat's row (`node_cannot_run`, the words per node)". *The page* says "**`ao builtins show [<set>]`** prints what the page shows", and #4760's history line says the mark is "given on the seat's row of `ao builtins show`".

Only `--json` gives it. `_builtins_show_prose` (`src/shiftlead/cli.py`), the command's text, never reads a seat's `node_cannot_run`.

Probe at 22675a930: `set_node_cannot_run("default", "the sweeper", ["claude-code:a"], "haiku", {"node1": {"model": "haiku", "logins": ["claude-code:a"]}})` answers `{"node1": "default cannot run the sweeper: no login in its list offers haiku on node1"}`. A `builtins_show` reading carrying that on the sweeper's seat, printed by `_builtins_show_prose`, is three lines, none naming the node or *cannot run*:

```
default: used by r
sets: default
  sweeper  haiku on claude-code:a  acts for the repo
```

While the mark stands the home sends that node no launch of the seat: a job's only trace there is a log line (`on_set_node`, `src/shiftlead/stage_start.py`). The Built-in seats page draws no node mark yet (TD-2068's *Left*; TD-2274 is the design's half of that). So a person reading the command sees the seat on a usable login while it is held on a node.

**Location:** src/shiftlead/cli.py _builtins_show_prose; docs/design/4.9d-teams.md

**Fix:** Print each seat's `node_cannot_run` words under its row in `_builtins_show_prose`, one line per node, the director's row left as it is.

**Done when:** A test reads a built-in set with a standing node mark and finds the node and its *cannot run* words in the text of `ao builtins show`.
