## TD-2053: Audits on a clock, and board answers and pull requests nobody holds as built-in seats

**Priority:** Medium

**Kind:** build
**Status:** Open

**Blocked by:** TD-2050, TD-2051, TD-2066, decision (paul)
**Part of:** TD-1954

**Why:** The design replaces the auditor seats with audits a flow lists, each started on a clock with its own brief, and turns two free-pick work orders, a decided board line and a pull request nobody holds, into built-in seats, since a format-3 flow has no lane.

**Ask:** Should the builders start on audits that run on a clock and the two new built-in seats?

**Fix:** Build design §4.9c *Audits start on a clock* and *Two of the five are not seats today*: an audit's run record, its lease and its count from a merge commit, its three outcomes, the plain board line for an audit's other; a session started for each decided board line and each unheld pull request, on the seat's model. This entry also owns the tick's sixth act, start an audit, the checks `ao stage end` makes on an audit's outcomes (`findings-filed`, `nothing-found`, `other`), and the holder of an audit's run. The store for audit run records is TD-2048's; this entry builds what uses it: the run record's writes, its lease and its count.

**Done when:** An audit starts when its clock comes round and never while its last run holds its lease; a lost run is offered again once. The board-answers seat never takes a decided line whose Context is an entry whose record waits on the person; held, for a pull request, means any record names it. Both seats start only while one of the repo's teams is started, on the model and the logins of the built-in set the repo uses (design §4.9d *The built-in seats and their page*), and wait where no login of that set is usable. `ao stage end` from an audit's session takes `findings-filed` only when it names at least one entry filed in the run, and `nothing-found` and `other` only with a reason; an `other` puts one plain line on the board, of the form the gate's append class accepts, naming the audit and the run.
