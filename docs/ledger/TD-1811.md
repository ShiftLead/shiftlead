**Why:** A ledger-filing PR whose author's run ended has no owner, so it stands open and its entries never reach main (19 such PRs on 2026-11-13, TD-1804). The design makes one a work order in the grinders' lanes a day after it opened (design §4.4 *A filing PR nobody holds is a work order*).

**Location:** design §4.4 A filing PR nobody holds is a work order; src/sessionorc/workorders.py (red_prs, pr_order, red_holders, pr_note), agent_common.py, agent_tick.py (_red_prs), queue.py; src/shiftlead/teamrun.py (red_prs, lane_entries), cli.py (ao repo), ui/repo.py, ui/inbox.py, briefs/grinder.md, team_skill.md

**Fix:** Build the order half of design §4.4 *A filing PR nobody holds is a work order*, the bullets *The order* and *What the taker does*, on TD-1810's `filing` stamp:
- `FILING_AFTER = timedelta(days=1)` beside `ORPHAN_AFTER` in `agent_common.py`.
- `workorders.red_prs` (or a sibling the tick calls beside it): a PR with `filing` true, not a draft, not a fork, `held` empty, checks not red, not conflicting and not `not_run`, `created` at least `FILING_AFTER` ago, with no holder (`holds_pr`) is an order; held with every holder `idle`, the holders are told once (`pr_note`: *filing PR #<n> has been open since <t>: merge it or say why*), and `ORPHAN_AFTER` later, still idle, it is an order; the `told` memory keyed on `created` as a red spell's is on `red_since`. A red or conflicting filing PR stays the red rule's alone (never two orders for one PR).
- `pr_order`: `filing: true`, `filing_since` (its `created`), priority *Medium*, `Context` the URL and *filing, open since <date>, nobody holds it: review and merge it, or close it if superseded*; sorted after the sync and red orders.
- `ao repo` (design §4.7): the line `pr:<n> · <title> · filing, open since <date>: nobody holds it`, counted as *n filing PRs nobody holds* beside the red count. The Repo page's Review row reads *nobody's — the grinders' order* for it past `FILING_AFTER` (design §4.5 screen 11 *Review*).
- `src/shiftlead/team_skill.md` (the line that lists `board:<key>` and every red or sync PR nobody holds as work orders): add a filing PR nobody holds past a day, and what its taker does (close if superseded, else review if unreviewed at its head, precheck, merge).

**Done when:** A filing PR nobody holds, green or pending and not a draft, fork or held PR, is a `pr:<n>` order in the grinders' lanes once it has been open `FILING_AFTER`, and not before; a held one with idle holders is told once and ordered `ORPHAN_AFTER` later; a red filing PR is one red order, not two; `ao repo` prints its line and count. Tests hold each of these in `tests/` (beside the red-PR order tests).
