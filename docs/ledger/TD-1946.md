## TD-1946: The person can read what the disk sweep holds, frees and keeps on every host

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-18
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 688eb9fd6473411eb789bbb5c6f8e253
**Blocked by:** TD-1945
**Part of:** TD-1921

**Why:** The person cannot see what the disk sweep frees or keeps, so a disk that fills again looks like the sweep's failure or nobody's (TD-1921). Design §4.6 *The sweep's reading* and §4.7 `ao disk` show it per host, before a pass and after it.

**Location:** design §4.6 *The sweep's reading*, §4.7, §4.4a (`NODE_READS`); src/sessionorc/, src/shiftlead/cli.py

**Fix:** Build design §4.6 *The sweep's reading* and §4.7 `ao disk`: each pass writes `disk.json` in the host's home from TD-1945's pass result (per kind the bytes held and removed this pass, each kept item with its why, the free space of the file system holding `scratch_root`) and keeps a dated line per pass for 30 days, from which the 30-day totals are read; the host agent answers `disk` (the reading) and `disk_dry_run`, both added to `NODE_READS` (§4.4a) so a node's is reached over the link; a dry run removes nothing, writes no `disk.json`, leaves the worktree pass's place, weighs worktrees oldest first for at most `SWEEP_DRY_S` (300 s) saying *partial* when it stops short, and is refused while a pass holds the sweep's lock; `ao disk [--host] [--dry-run] [--json]` prints every host's, a host that does not answer named *unreachable*, and a `scratch_root` under a tenth free drawn as a warning.

**Done when:** In a scratch home, after a sweep `ao disk --json` prints each kind's bytes held, removed in the pass and in 30 days (a pass dated 31 days back left out), each kept item's why and `scratch_root`'s free space; with that free space under a tenth (a test's stubbed reading) `ao disk` prints the warning; `ao disk --dry-run` lists what a pass would remove, is refused while a pass runs, and leaves `disk.json` and the worktree pass's place unchanged; a stopped node reads *unreachable*.
