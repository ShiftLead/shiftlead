## TD-1946: The person can read what the disk sweep holds, frees and keeps on every host

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-18
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 688eb9fd6473411eb789bbb5c6f8e253
**Blocked by:** TD-1945
**Part of:** TD-1921

**Why:** The person cannot see what the disk sweep frees or keeps, so a disk that fills again looks like the sweep's failure or nobody's (TD-1921). Design §4.6 *The sweep's reading* and §4.7 `ao disk` show it per host, before a pass and after it.

**Location:** design §4.6 *The sweep's reading*, §4.7; src/sessionorc/, src/shiftlead/cli.py

**Fix:** Build design §4.6 *The sweep's reading* and §4.7 `ao disk`: each pass writes `disk.json` in the host's home (per kind the bytes held, removed this pass and in 30 days, each kept item with its why, and the free space of the file system holding `scratch_root`); the host agent answers a read of it and a `--dry-run` pass that removes nothing, over the link for a node; `ao disk [--host] [--dry-run] [--json]` prints every host's, a host that does not answer named *unreachable*, and a `scratch_root` under a tenth free drawn as a warning.

**Done when:** In a scratch home, after a sweep `ao disk --json` prints each kind's bytes held and removed, each kept item's why and `scratch_root`'s free space; with that free space under a tenth (a test's stubbed reading) `ao disk` prints the warning; `ao disk --dry-run` lists what a pass would remove and a following `ao disk` shows nothing removed by it; a stopped node reads *unreachable*.
