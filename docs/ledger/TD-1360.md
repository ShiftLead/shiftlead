## TD-1360: A new entry is filed with ledger.py new: entry.md and every brief that files one name it, once ledger.py new can file here

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-04 (the designer, from TD-1286's design)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** TD-1357, TD-1358, agent-cadence#TD-188
**Part of:** TD-1286
**Location:** `src/shiftlead/briefs/entry.md` (the number, the shape, the Summary row step); every brief under `src/shiftlead/briefs/` and `docs/briefs/` that files an entry; `AGENTS.md`

**Why:** `ledger.py new --id TD-n` is the helper for a new entry, but here it refuses every filing: it writes the take's `**Taken by:**`, and this ledger's `Fields:` line declares vocabularies, so `--check --since` reads `Taken by` as an undeclared field and `new` refuses (tried 2026-11-04 at the pin and at agent-cadence's main, unchanged since). agent-cadence#TD-188 replaces `Taken by` with the cadence's own `Id take` field, which needs no declaration. Until it lands, `entry.md` gives the entry's shape to type, and keeps a step adding a Summary row the v2 ledger no longer has (TD-1286).

**Fix:** As design §4.4 *A session writes the ledger and the board only through the helpers* and §4.9 *Two ways out*, once agent-cadence#TD-188 is built and this repo's pin is past it (`agent-cadence bump`, in this PR if not done): `entry.md` files the whole entry with `ao td reserve`'s id and `agent-cadence run ledger.py new --id TD-n` and its flags (`--title`, `--priority`, `--type`, `--added`, `--owner`, `--kind`, `--part-of`, `--blocked-by`, `--location`, `--field Team=…`/`Waits=…`, `--why`/`--fix`/`--done-when` from files), its Summary row step removed now in any case; every other brief here and `AGENTS.md` that tells a session to file an entry names the same command. Check it by filing this PR's own ledger edits through the helpers.

**Done when:** `ledger.py new --id` files an entry in this ledger, and no brief, template or `AGENTS.md` line tells a session to type a new entry.
