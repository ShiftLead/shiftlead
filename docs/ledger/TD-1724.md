## TD-1724: The person's own idle session reads 'with you in', never 'stalled', and a holder's state word opens its Focus

**Priority:** Medium
**Type:** debt
**Added:** 2026-11-11
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 54d0d777e25e4789901f327d92a652f2
**Part of:** TD-1567
**Location:** src/sessionorc/queue.py (_state, _state_word, _holder_stuck); src/shiftlead/ui/templates/queue_row.html (state, holder), queue_card.html; design §4.4 A row's state, §4.5 screen 12, §4.5a Queue card: holder's word

**Why:** The Queue tells the person a team is stuck when it is the person's own interactive session sitting idle (TD-1529's card read *td-1529 stalled*, 2026-11-11), and the state words that stand for a session (*with you in <name>*, *held by <name>*, *stalled*) are plain text, so the word does not take the person to the session. TD-1567 designs both: design §4.4 *The person's own session is never stalled*, §4.5 screen 12 *A holder's word opens the holder*, §4.5a *Queue card: holder's word*.

**Fix:** 1. `queue._state` / `_state_word` (src/sessionorc/queue.py): a row any live record with `unattended: false` claims is never *stalled* — no claim on it is read by `_holder_stuck` — and its holder is the first such record by id whatever other claim stands. A row waiting on the person reads *with you in <name>* first, as today. Any other such row keeps the PR words (*#n conflicting*/*#n failing* · *being fixed*, *in review #n*, the pill beside them) and reads *with you in <name>* where it would read *held by <name>*. Its `need` stays None: no grey *with you* item (§4.5 screen 12 *Three wants*), no change to the card's need. A stopped holder's state row still makes the card *needs you* (TD-1453).
2. *Stalled*'s holder: the row carries the record a *stalled* stands for — the first by id of the claims' records `_holder_stuck` reads — as its `holder` (the pill and the word name one session; `ao card`'s holder follows); a red PR nobody holds has none. The card carries `stalled_holder`, the holder of its first stalled row in pick order that has one, computed where the status is and re-read wherever the status is re-read (`lay_held`, ~queue.py:1062).
3. `queue_row.html` macro `state`: *with you in <name>*, *held by <name>* and *stalled* with a holder are `<a href="/focus/<id>">`, keeping the word's class, colour and mark; the Repo page's builds line (`queue_row.html` ~56) keeps *held by* plain. `queue_card.html` header (~47): the top entry's pill stands and *held by* is not drawn, as today; a top entry reading *with you in <name>* with no need draws the word, a link, in the pill's place (today the template would draw pill and word both — draw one); its *stalled* beside the pill links the stuck record; the card's status *stalled* links `stalled_holder`, plain where it has none. *Needs you* is never a link. A link's hover changes colour only (§4.5 *A hover changes colour, never layout*).
4. Tests: TD-1529's case — an idle `unattended: false` record holding a derived claim on an entry with no `decision (paul)` reads *with you in <name>*, never *stalled*, and the card's status is not *stalled*; the same row with an open PR reads *in review #n* with the session's pill; an unattended idle holder still reads *stalled*, its pill the stuck record's; each word's link goes to the right Focus, the header's *with you in* drawn once; a red PR nobody holds reads a plain *stalled*.

**Done when:** An idle interactive holder on an entry that needs nothing of the person reads *with you in <name>*, never *stalled* (a test of TD-1529's case), and every holder state word on a card — row and header — opens that holder's Focus as §4.5 screen 12 *A holder's word opens the holder* says, a test per word.
