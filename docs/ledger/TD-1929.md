**Why:** TD-1153's design (§4.9 *A team's own page*: *The definition, as text*, *Every edit is checked before it is written*, *An org.yml team is written in place*): a team's definition is edited on its page as text, checked, and an `org.yml` team's edit written in place.

**Location:** src/shiftlead/org.py, src/shiftlead/ui/app.py, src/shiftlead/ui/team_page.py; design §4.9 *A team's own page*, §4.5a *Team page: Definition*

**Fix:** 1. `org.edit_block(text, team, read, edited) -> str` in `src/shiftlead/org.py`: `text` the file, `read` the indent-stripped block the page drew, `edited` the person's lines; returns the new file text or raises `ValueError` with the reason. The key's indent put back on every non-blank line. Refusals, in this order and in these words (§4.9): the block on file is not `read` (*the definition changed since you opened it: reload*); the first edited line is not the team's own key (*a team is renamed by hand: settings follow its name*); the new text does not parse, or `_team` refuses the team (its own words); anything outside the team parses differently from before (*the edit reached past ao-grind's block*); the org built with it (`with_repos`, `with_settings`) fails, `shared_names` finds a session named twice, or `flowdefs.unfollowable` reads a listed flow unfollowable (those checks' words). A brief named that the checkout does not hold is returned as a warning list beside the text (`edit_block` returns `(text, warnings)` if that reads better; name it in the PR), never a refusal.
2. `POST /api/teams/{name}/definition {read, edited}` for an `org.yml` team: `edit_block`, then the write, `org.load` again and the bytes restored if it fails, as `edit_members` does; nothing created or wound down. A repo team's call is refused here until TD-1930 (*a repo's team is proposed as a PR*).
3. The page's Definition section (TD-1928) gains **Edit** (a text area of the block), **Save** and **Cancel**; a refusal drawn under the text area in the check's words with the text kept; warnings under it (§4.5a *Team page: Definition: Edit, Save, Cancel*).
4. Tests: each refusal with a file it fires on; comments and spacing outside the block byte-identical after a save; a comment inside the block kept; a flow-style one-line team; a save that `org.load` rejects restores the bytes; a live team's card reads *definition changed — Apply* after a save that adds a member line (the existing reading, not new code).

**Done when:** An `org.yml` team's definition is edited on its page and written in place, every refusal of §4.9 *Every edit is checked before it is written* drawn in its words, and the file outside the block byte-identical; the tests above pass.
