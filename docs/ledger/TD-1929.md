## TD-1929: A team's definition is edited as text on its page, checked, and an org file team's edit written in place

**Status:** Open

**Why:** TD-1153's design (§4.9 *A team's own page*: *The definition, as text*, *Every edit is checked before it is written*, *An org.yml team is written in place*): a team's definition is edited on its page as text, checked, and an `org.yml` team's edit written in place.

**Location:** src/shiftlead/org.py, src/shiftlead/ui/app.py, src/shiftlead/ui/team_page.py; design §4.9 *A team's own page*, §4.5a *Team page: Definition*

**Fix:** 1. **The splice**, `org.edit_block(text, team, read, edited) -> str` in `src/shiftlead/org.py`, pure on the file's text: `read` the indent-stripped block the page drew (`org.team_block`, TD-1928), `edited` the person's lines; returns the new file text or raises `ValueError` with the reason. The key's indent put back on every non-blank line, the file's own line ending (`\n` or `\r\n`) on every line. Refusals, in this order and in these words (§4.9 *Every edit is checked before it is written*): the block on file is not `read` (*the definition changed since you opened it: reload*); the first edited line, parsed alone, is not a mapping keyed by the team's own name (*a team is renamed by hand: settings follow its name*); the new text does not parse (the parser's words; a tab in an indent among the causes); anything outside the team parses differently from before (*the edit reached past <team>'s block*).
2. **The org check**, `org.check_edit(source, text) -> tuple[list[str], list[str]]` (refusals, warnings): builds the org with the candidate text standing in for its file from a scratch copy — an `org.yml` candidate written to a temporary file and read by `org.load`; a repo's written as `.shiftlead.yml` in a temporary directory passed to `with_repos` as `stand_in` for that repo — then `_team`'s refusal, `with_repos` / `with_settings` failing, `shared_names`, `flowdefs.unfollowable`, in their words; a brief a member names that the checkout does not hold is a warning, never a refusal.
3. **The member edit split**: `edit_members`' one-line text edit becomes `org.members_edit(text, team, …) -> str`, the text in and out, its refusals worded without naming `org.yml`; `edit_members` keeps the read, the org check (`check_edit`), the write and the restore around it, so Add member and Remove make the same checks as Save. TD-1930 calls `members_edit` on a repo's text.
4. `POST /api/teams/{name}/definition {read, edited}` for an `org.yml` team: `edit_block`, `check_edit`, then the write, `org.load` again and the bytes restored if it fails, as `edit_members` does, then the client asks `commit_defs` with *org: <team> definition edited* (§4.9 *What is left at the home has a history*); nothing created or wound down. A repo team's call is refused (*a repo's team is proposed as a PR*), and on a repo's team the page draws **Edit** disabled with *changed by PR* until TD-1930 replaces it with **Propose as PR**.
5. The page's Definition section (TD-1928) gains **Edit** (a text area of the block), **Save** and **Cancel**; a refusal drawn under the text area in the check's words with the text kept; warnings under it (§4.5a *Team page: Definition: Edit, Save, Cancel*).
6. Tests: each refusal of both steps with a file it fires on; comments and spacing outside the block byte-identical after a save, a CRLF file kept CRLF; a comment inside the block kept; a quoted key; a flow-style one-line team edited; a tab-indented edit refused; a save that `org.load` rejects restores the bytes; the `commit_defs` call with its words; Add member through `members_edit` gives the file it gave before; a live team's card reads *definition changed — Apply* after a save that adds a member line (the existing reading, not new code).

**Done when:** An `org.yml` team's definition is edited on its page and written in place and committed, every refusal of §4.9 *Every edit is checked before it is written* drawn in its words, and the file outside the block byte-identical; Add member and Remove go through the same org check; the tests above pass.
