**Type:** debt

**Why:** #4662 (TD-2158 slice 3) puts the holder's run on the row an `ao stage end` writes (docs/design/4.9c-flows.md, *Each holder leaves a `run`*): `rpc_stage_end` in src/sessionorc/agent_stage.py hands `call` the session record's fields and a spend reader, and `call` in src/shiftlead/stage_end.py hands both on with `session=session, spent=spent` to `end`. Nothing tests that second step, and the test of the first step cannot tell which session's spend is read.

- Deleting the `session=session,` line of `call`'s `end(...)`, the `spent=spent,` line, or both, each left 21 test modules (those naming `stage_end`, `stage_pass`, `stage_tick`, `stage_make`, `stagerecord` or `agent_stage`, with test_flow_save.py, test_stage_fetch.py and test_stage_start.py) passing (898 passed at 957e4b75b). With both deleted, `pdm run test` at 6cb9bb90b also passed (10153 passed, 24 skipped; TD-2228's change and the reader change below applied in the same run). Every entry row a real `ao stage end` wrote would then carry a `run` with model, tool, tool version, start, asks and models all null, and `_repeat` would match a later run under the same session id on `None == None`. The tests of the run's content call `end` directly (`_end_run` in tests/test_stage_end.py); `test_the_call_hands_each_route_the_counts_it_read` replaces `end` with a function taking `**k` and reads the counts alone.
- Changing `rpc_stage_end`'s reader to `seats.record_reading(self._seats, "somebody-else")["models"]` failed nothing, alone over the same 21 modules (898 passed). `test_a_session_on_a_node_ends_its_stage_with_its_own_worktrees_facts` sets `agent._seats = {"days": {}}` and asserts `got["spent"]() == {}` with the message "the node's session's spend is read by its bare id from the home's seat ledger": an empty ledger reads as `{}` for every id.

**Location:** tests/test_stage_end.py

**Fix:** In tests/test_stage_end.py: a test that calls `stage_end.call` for an entry with `end`'s collaborators faked and asserts the `session` and `spent` it was given reach the row (or reach `end`); and give the RPC test a seat ledger holding rows for the calling session and for another, asserting the calling session's sums alone.

**Done when:** Deleting `session=session,` or `spent=spent,` from `call`'s `end(...)` fails a test, and a `rpc_stage_end` reader that reads any other session's id fails a test.
