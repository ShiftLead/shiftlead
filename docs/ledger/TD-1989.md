## TD-1989: A path printed with a brace set opens the first of its files that exists

**Priority:** Low
**Type:** debt
**Added:** 2026-11-18
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 0c9dd298f224443ba2308e0a7afb6013
**Part of:** TD-1959

**Why:** A path the session prints with a brace set, such as `docs/mockups/reviews/2026-11-18-td1953-tools-house-{1440,420}.png`, is not a link: the path reader cuts the run at the brace and resolves nothing (TD-1959, design §4.6 *A path in the pane is a link*).

**Location:** src/shiftlead/ui/static/app.js (AO.pathRuns, AO.pathLinksHtml); design §4.6

**Fix:** Build design §4.6 *A path in the pane is a link*'s brace set (TD-1959): `AO.pathRuns` (`static/app.js`) admits one `{a,b,…}` in a run — two to eight choices, each a non-empty run of the segment characters without `/`, `,`, `{` or `}` — and asks the run as its expansions, in the set's order, as it asks a run's pieces (the `paths` asks' batching of eight paths unchanged); the first the host resolves is the link, the whole run underlined, and the press opens that choice; none resolving leaves it text. A run with a second set or a nested one is cut at its first `{`, as today. Tests: `a/x-{1440,420}.png` with only `a/x-420.png` on disk links to it; one with neither stays text; `a/{b,c}/{d,e}.py` and `a/{b,{c,d}}.py` are cut at the first `{`; a set of nine choices is cut too.

**Done when:** A printed path holding one brace set links to the first of its choices that is a readable file on the record's host, and stays text where none is; each case in the Fix is covered by a test.
