## TD-2130: The disk sweep ignores file dates set in the future when it judges a tree quiet

**Priority:** High
**Type:** debt
**Added:** 2026-11-23
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 55ba7464d84b45dcb8fc589d480c796e
**Part of:** TD-2126

**Why:** Part of TD-2126, design §4.6 *A live seat's rebuildable copies*, part 1. A full suite's fixtures date two files in 2033 and 2065, so the quiet test never passes on a full suite's tree and the pressure pass cannot reclaim it.

**Location:** src/sessionorc/scratch.py, design §4.6 *A live seat's rebuildable copies*

**Fix:** In `scratch.py`, `_quiet` and `_newest_write` leave out of the time comparison an entry dated more than `FUTURE_AFTER_S` (a day) past `now`, the root included, and still walk a directory so dated; `_newest_write` gains `now`. Test a tree holding a future-dated file and directory, old and with a new real file, and a write a few seconds past `now`, which counts as a write.

**Done when:** A killed suite's tree holding a future-dated file is reclaimed by rule 1 once quiet, and a tree with a recent real write beside a future-dated file is not.
