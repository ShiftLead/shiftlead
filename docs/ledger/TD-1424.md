**Why:** Asked by the person's session `ao-led-tds-ledger` (m-19c414447e4d), from the independent review of #2970 (TD-1368 slice 2). `board_hold`'s *answered — waiting on TD-m* word drops a carried-to entry's repo: `src/sessionorc/queue.py` takes `tq.partition("#")[2]` as the asker. So a shiftlead board line closed *— carried to agent-cadence#TD-221* reads *waiting on TD-221* on a shiftlead card, which reads as shiftlead's own TD-221. The same review found behaviour the code handles but no test pins, in `tests/test_queue_board_hold.py`:
- F61: a member whose Log has a `kept waiting` line, whose picked line is open or closed in other words, does not read *waits until*;
- *carried to TD-m and TD-k* with only the second open;
- a new undecided line naming the parent design asks again for a build;
- `Decided: … (by Paul)` with a capital P (real lines are capitalised; only `by paul` is tested);
- Lift the hold on a build covered only by its design's line (a Done-when item of TD-1368).

TD-1368's Done when *once stale it is the card's one Decide item, standing in the member's place* is neither tested nor in slice 3's scope (#2980). Two nits: a capitalised repo in a qualified ref (`Ledgerboard#TD-050`) covers nothing, which fails safe. TD-1368's Blocked by still lists the archived TD-1370 and TD-1375.

**Fix:** In `board_hold`, keep the qualified `<repo>#TD-m` as the asker word when its repo is not the member's, and the bare `TD-m` when it is (§4.4 *The card's status*, §4.5 screen 12 *Where a row is drawn*: a bare id is its own board's repo's). Add the tests listed in the Why to `tests/test_queue_board_hold.py` (and `tests/test_ui_answered_hold.py` for the stale Decide item, built if a test finds it missing). Drop the archived TD-1370 and TD-1375 from TD-1368's Blocked by with `ledger.py set`.

**Done when:** A test that a line closed *carried to agent-cadence#TD-221* on shiftlead's board makes a shiftlead member read *answered — waiting on agent-cadence#TD-221*. Each listed case is a test that passes, or is a fix with its test.
