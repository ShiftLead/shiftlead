**Why:** Build TD-1434, slice 1 of 2 (design §4.5 *A taken-over member*, §4.5a the Session card's *mode* row, §4.4a the home's fields). On 2026-11-06 the techlead seat went `interactive` some time after 05:39Z, and nothing could say when, by whom, or from which control. `rpc_set_mode` writes no log line and keeps no field. The seat then slept through five messages for about 11h. This slice is the trace, which the entry says needs no design.

**Fix:** - `src/sessionorc/models.py`: three fields on the record, `mode_at`, `mode_by` and `mode_via` (str | None). They are home-owned, in the merge-by-owner list beside `unattended` (§4.4a), and carried to a node's replica as `unattended` is.
- `src/sessionorc/agent.py` `rpc_set_mode`: gains `via: str | None = None` and `caller`. When the mode actually changes (`bool(unattended) != s.unattended`), it stamps `mode_at` = now, `mode_by` = `closer_of(caller, None, at)["by"]` (`person` or the session's id) and `mode_via` = `via` when it is one of `focus`, `card`, `inbox`, `cli`, else None. A call that leaves the mode as it was writes nothing. It writes one log line through the host agent's logger: name, new mode, by, via.
- `src/shiftlead/ui/app.py` (the mode act's handler) passes `via` from the press: `focus` from Focus's acts line, Watching line and narrow sheet, `card` from the card's more ▾. The page's `data-act="mode"` buttons carry a `data-via`, and app.js sends it. `src/shiftlead/cli.py` (`ao mode`) passes `via: "cli"`.
- The Focus Session card (`focus.html`, its view in `src/shiftlead/ui/cards.py`): a *mode* row on an agent record. It reads *interactive since `<time>` · by you from Focus*: *you* for `person`, else the session's name; the via words are *from Focus*, *from its card*, *from the Inbox*, *by `ao mode`*, and are left out when none. With no stamp it reads *since before this was recorded*. It is not drawn on a record with no agent.
- Tests: a flip stamps all three and a same-mode call stamps nothing; a session caller's id lands in `mode_by`; an unknown `via` is dropped; the log line is written; the node replica carries the fields; the Session card row draws each wording and the unstamped one.

**Done when:** `set_mode` stamps `mode_at`, `mode_by` and `mode_via` on every real change and logs it. The page and `ao mode` pass their `via`. Focus's Session card shows the mode row. Tests cover each case above.
