## TD-1318: #2797's tests miss four hop behaviours of a look's shot read (`ref` to a node, `where` at the home, the `at` echo, the `from` default)

**Priority:** medium
**Type:** debt
**Added:** 2026-11-02 (test-audit-ao-1, auditing #2797)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Location:** `src/sessionorc/agent_link.py` (`_from_home`, the `shot` branch); `src/sessionorc/agent_remote.py` (`rpc_host_shot`); `tests/test_link.py`, `tests/test_shots_commit.py`

**Why:** each line was changed in a scratch worktree (restored after) and `PYTHONPATH=$PWD/src pytest -q tests/test_shots_commit.py tests/test_link.py tests/test_ui_look_row.py tests/test_look_home.py` still read *99 passed* (the base run too):
- `agent_link.py`: `params.get("ref") or "",` → `"",`. The node never receives the branch to read; the `ref` step is lost on every node. Only a dropped `at` fails (`test_link.py:2408` passes `ref="main"`, but `main` is also the default, so the node's answer is the same).
- `agent_remote.py`: `at, ref = shots.where(at, ref)` → `pass`. The line's comment says a malformed one is dropped and a lone `ref` ignored at this hop too; no test sends one through `host_shot`.
- `agent_remote.py`: `"at": got.get("at") if isinstance(got.get("at"), str) else None` → `"at": at`. The docstring: `at` is the reading's own echo, *never filled from this request* (a node that predates it answers none) — the line that tells the home a node is old.
- `agent_remote.py`: `str(got.get("from") or ("default" if exists else ""))` → `""`. A reply with no `from` is documented to read `default`.

**Fix:** in `test_link.py` give the node a branch whose file differs from the default's and assert `host_shot(... ref=…)` serves it; send a malformed `at` and a lone `ref` and assert they are dropped; fake a node reply without `at` and `from` and assert `at` is None and `from` reads `default`.
