## TD-1951: A person's own unheld entry reads as theirs on the Queue, and the person's owner word is read the same in every repo

**Priority:** Medium
**Type:** feature
**Added:** 2026-11-18
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 34f5776cd39e43cfba4a498a0a67f000
**Part of:** TD-1920

**Why:** TD-1920's design (design §4.4 *The card's status*, *A row's state*, *The page's kinds*, *Waiting*) reads a person's step — an open entry the person owns that nothing holds — as theirs on the Queue, never *ready*, and reads the person's owner words the same in every repo. This builds the reading in `sessionorc`; TD-1952 draws it.

**Location:** src/sessionorc/ledger.py, src/sessionorc/queue.py, src/sessionorc/agent_inbox.py, src/sessionorc/board.py, src/shiftlead/ui/inbox.py, src/shiftlead/ui/app.py; design §4.4

**Fix:** Build design §4.4 *The page's kinds* (the person's owner words), *A row's state* (*yours to <verb>*, *after your TD-n*), *The card's status* (*A person's step reads as theirs, never ready*) and *Waiting* (a person's step is the person's own):
- `ledger.is_person(owner)`: the owner lower-cased is in `PERSON_WORDS` — `PERSON_OWNER` (`paul`) and `person`; replace every `Owner:` compare against `PERSON_OWNER` with it (`ledger.lane_gap`, `queue.py`'s owner tests, `agent_inbox.py`, `board.py`'s owner test, `shiftlead/ui/inbox.py`, `shiftlead/ui/app.py`, the lift helper's *yours to do*); `decided_by` and every `decision (<person>)` written stay on `PERSON_OWNER`.
- `queue.py`: a person's step test over a reading's entry — `is_person(owner)`, no `decision (…)`, no non-gate blocker, no open part, not settling, no `waiting` mark; `_state_word` returns *yours to <verb>* in *ready*'s place (verb from `Kind:`: design-first → design, live-check → check, evaluation → evaluate, decision → decide, else start), every earlier word standing first.
- the relation words: a blocker that is a person's step is marked so the row draws *after your TD-n*; a `<repo>#TD-n` blocker is tested against that repo's reading where the home reads the repo, else not a step.
- `_status`: *yours* between *steer* and *stalled* (`STATUSES`): a card some open member of which is a person's step, or waits only on person's steps; `_own` (the *Waiting* test's person's own) includes a person's step, so a member blocked only by one does not wait.
- no count reads it: the Queue tab, the top bar, the rail and a repo's count are unchanged.
- tests: an `Owner: person` and an `Owner: paul` entry with no gate read *yours to start* / *yours to design*, each word above *ready* standing first (a claim, a PR, settling, an `until` gate); a parent blocked only by one reads *waiting* with the step marked, its card *yours*, not Waiting; a parent blocked by a step and another open id reads *waiting*, card as today; a cross-repo step from a read repo is a step, an unread repo's is not; `lane_gap` never marks an `Owner: person` entry; a gated `Owner: paul` entry is unchanged (*for you*, Do).

**Done when:** `ledger.is_person` is the one owner predicate; a person's step reads *yours to <verb>* and its card *yours* in the Queue reading, a parent waiting only on one reads *waiting* with its blocker marked and its card *yours*, `pdm run test` passes with the tests above, and no count changes.
