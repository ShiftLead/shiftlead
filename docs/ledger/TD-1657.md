## TD-1657: One-open-question tests miss the repo check and the landing wiring (TD-1547, #3417)

**Type:** debt

**Owner:** grinder
**Kind:** build

**Location:** src/sessionorc/mail.py seat_records; src/sessionorc/agent_mail.py _landing_refusal; tests/test_td_max_seat_one_open.py

**Why:** PR #3417 (TD-1547) changed one-open-question-per-sender-per-seat to count over the seat's records (`mail.seat_records`, `mail.open_question`). Two parts of it no test would catch going back; `tests/test_td_max_seat_one_open.py` is unit-level over `mail.py` only.

1. `seat_records` keeps an extra only when `x.team == r.team and x.repo == r.repo`. The docstring says "of its team and repo", but `_rec` gives every record `repo = "/r"` and the "another team" case varies `team` alone. Dropping `or x.repo != r.repo` from `src/sessionorc/mail.py`: `tests/test_td_max_seat_one_open.py` 6 passed; `pytest -k "landing or moved or question or one_open or mail" tests` the same single failure as at baseline (`test_gemini_start.py::test_the_adapter_declares_its_mail_a_turns`, unrelated).
2. `agent_mail._landing_refusal` now calls `mail.open_question(records, mine, target, thread=moved.root)` so a moved ask's copy does not block itself. Reverting that line to the old `next((x for x in r.inbox if x.kind == "ask" and x.open and x.from_ in mine), None)`: 6 passed, and the same `-k` run again only the baseline failure. The test file never drives `_landing_refusal` (it names `open_question(..., thread=)` directly), so the wiring that the thread argument is passed at all, and that the landing check counts over the seat, is unchecked: the "moved ask" case is the one the PR's own docstring calls out.

Both reverts made in a scratch worktree on origin/main 0c3fc6629 and restored.

**Fix:** Add to `tests/test_td_max_seat_one_open.py` an extra of the same team and name but another `repo` that is not counted; and a test through `_landing_refusal` (an agent-level move of an open ask to an extra of the same seat succeeds, a second distinct ask is refused).

**Done when:** Reverting the `repo` comparison and reverting `_landing_refusal`'s `open_question(... thread=...)` call each fail a test.
