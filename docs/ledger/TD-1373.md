## TD-1373: The sync PR: sessionorc/ledger.py calls ledgerboard's ledger.py for every ledger write; ledger dates UTC, board dates in workorders.py stay local

**Priority:** High
**Type:** feature
**Added:** 2026-11-04 (ao-led-tds-ledger, a person-session in ledgerboard, through `ao td add --repo shiftlead`; drafted by ao-shiftlead-techlead-ao-1)
**Owner:** grinder
**Kind:** build
**Status:** Open
**Blocked by:** TD-1372
**Part of:** TD-1369
**Location:** `src/sessionorc/ledger.py` and every code path that writes a ledger entry (`rpc_ledger_decide` in `src/sessionorc/agent_inbox.py`, `ao td` in `src/shiftlead/cli.py`); `src/sessionorc/workorders.py` (board dates); design §4.4 *A session writes the ledger and the board only through the helpers*

**Why:** ledgerboard's target design (ShiftLead/ledgerboard `docs/plans/target-design.md`) §7.2 step 4 and §1.1: the writers live in ledgerboard, and a consumer does no file handling of its own (principle 5). Design §4.4 already says code that writes a ledger entry calls ledgerboard's ledger writer (TD-1286). ledgerboard's writers date in UTC; the board's dates are the machine's local date and stay so.

**Fix:** route every ledger write ShiftLead's code makes through ledgerboard's `ledger.py` (the package is vendored by TD-1370), passing the counter, roster and git date lookups it needs; ledger dates become UTC; `workorders.py`'s board dates stay local, with a test that says so. The PR changes ShiftLead's design (docs/design/) in the same diff wherever the behaviour it changes is written there.

**Done when:** no code in `src/` writes ledger text by its own file handling (a grep and a test), and a ledger write from a press is dated in UTC.

**Related:** TD-1369; ledgerboard's target design (ShiftLead/ledgerboard `docs/plans/target-design.md`) §7.2 step 4.
