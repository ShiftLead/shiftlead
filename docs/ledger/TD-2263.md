## TD-2263: Nothing tests that a bad value in the director's list of logins is refused

**Priority:** Low
**Type:** debt
**Added:** 2026-11-26
**Owner:** grinder
**Kind:** build
**Status:** Open
**Id take:** 4b7b061367fa4b668ec64f630c457e34

**Why:** Audit of #4737 (TD-2068 slice 8), which reads `director.logins` from `org.yml` and lets a held `create` carry `seat_model` and `login_list` with no login (design §4.9e *The launch on a login*). Two checks of those values have no test of the new case:

- `src/shiftlead/org.py` `_director` refuses a list entry that is not a non-empty string. The one test (`tests/test_director_on_login.py`, `test_org_yml_reads_a_directors_model_and_logins`) gives a string in place of the list, never a bad entry. With `not all(isinstance(x, str) and x for x in order)` replaced by `False`, tests/test_builtin_fill_login.py, test_director_on_login.py, test_director_seat_start.py, test_org.py, test_stage_tick.py and test_stage_seats.py passed at eb5547a84 (169 passed). Probe: `logins: [1]` and `logins: [""]` are refused unchanged and accepted changed.
- `src/sessionorc/agent_common.py` `_on_login` checks the types of `seat_model` and `login_list` before its no-login branch, which the PR moved them above so that a held record is checked too. With each of the two checks conditioned on `login` (where they stood before, for a create with no login), the seven test modules naming `_on_login` or `login_list` passed at eb5547a84 (195 passed). Probe, `held=True` with no login: `seat_model=5` and a `login_list` that is one string are refused unchanged; changed, both are accepted and the string is stored as a list of its characters.

With all eight changes of TD-2262, TD-2263 and TD-2264 made together at eb5547a84, the 196 test modules that name the touched modules, calls or the director passed (`pytest -n 4`: 4811 passed, 8 skipped); the whole suite was not run to a result.

**Location:** tests/test_director_on_login.py; src/shiftlead/org.py _director; src/sessionorc/agent_common.py _on_login

**Fix:** In `tests/test_director_on_login.py`: add `logins: [1]` and `logins: [""]` to the `org.yml` refusal, and call `_on_login(None, ..., held=True)` with a `seat_model` that is not a string and a `login_list` that is not a list, asserting each is refused.

**Done when:** Removing the entry check from `_director`, or running either type check of `_on_login` only where a login is named, fails a test.
