Can it run?

Every pull request is reviewed and merged. Build opens them; the reviewer reads; the author or the second reader merges.

Every Owner has a step. design and build are both taken.

ao-grind has a login and a smoke pass for opus, sonnet and fable.

cm-grind has no login that offers fable, which the round reader needs.

Whichever step holds the work also does, with no model of its own: claim, worktree, open the pull request, precheck, wait for checks, archive, report done. The host does: settle a new entry, pull main, precheck main, promote, smoke. Yours, always: the last word, and anything passed up.
