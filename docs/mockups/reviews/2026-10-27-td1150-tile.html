TD-1150 — the Tile set (direction A), whole

Eleven state icons, one per state class a Focus pill draws, and nine page icons. Each is a 16-unit rounded square with a one-unit edge, so the dark page tile still reads on a dark tab strip. Each cell shows 16 and 32 px on a light strip, then on a dark one. The file name under each cell is the build's static/icons/<name>.svg.
