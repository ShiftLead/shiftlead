## TD-222, PR #892: how a Snooze, Done, Reply or Decide reaches origin. My default: the host agent makes the edit in a detached tree of its own at origin/main and pushes it (under ALLOW_MAIN_PUSH=1), so your checkout is never written by a press and is only ever behind, which the pull you decided today cures; every board row becomes actionable, including the ones read from origin that sit disabled today. The alternatives: (a) the host agent pushes the commit it makes in your checkout, which leaves the checkout ahead after every press and needs a rebase it must never make when origin moved first; (b) as today, the anchor's next push carries it. Nothing to do if the default is right; it merges at the bound — Paul, 2026-10-01: go with the default: the host agent makes the board edit in a tree of its own at origin's head and pushes it; the checkout is never written and catches up by the pull.
