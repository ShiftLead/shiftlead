## **Before the promote that carries TD-147 (PR #682): copy into the home's `settings.yml` anything a node's own `settings.yml` holds that the home's does not.** From TD-147 on, the home sends its file to every node on each dial and each write, and the node's copy is overwritten. So a reserve, a team's stop time or a `person:` block set only at a node is lost at the first dial after the promote. The nodes are those in the home's `hosts.yml` under `nodes:`, and the container nodes it supervises. Look at each one's `~/.agentorc/settings.yml` and merge what is missing with `ao gate` / `ao team until` or by hand at the home. With no node holding its own settings, there is nothing to do.
