## **Give unattended sessions their own temporary space on kmaster by mounting it and turning it on** — only you can do this

**Kind:** act
**Added:** 2026-11-23
**Context:** TD-2082
**Due:** 2026-11-24

- **Context:** TD-2082 built the setting, and only the person has sudo on kmaster. In order: sudo mkdir /aot; add to /etc/fstab the line tmpfs /aot tmpfs rw,nosuid,nodev,nofail,size=6G,nr_inodes=2m,uid=1000,gid=1000,mode=0700 0 0; sudo mount /aot; set seat_root: /aot under local in the home's hosts.yml; restart the host agent; stop and start the teams, since a live seat keeps its old directory until its next fresh start.
