  - Measured on the main repository: the first run deletes 190 of 406 unused branches, about 180 more go over the following weeks, and 37 stay.
  - Fixes no review has read, by build: TD-2112: three small wording fixes to how the age is read (F36, F37, F38). Every build-changing fix has been read by a review.
- **Question:** Should the grinders build the rule, or run one more review round first?
- **Caveats:** A branch you keep only as a bookmark, on the default branch and past the age, is deleted; the log names its commit so it can be put back. This rule frees little disk: the space comes from the separate one-time repack, which has its own question.
- **Recommended:** Go — the counted verdict is Go, and the judge confirmed it. **Otherwise:** One more round, if you want another read first; Hold, if the rule should change.
