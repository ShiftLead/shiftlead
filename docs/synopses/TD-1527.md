# TD-1527: Every design carries a plain-words synopsis for the person, linked from its Queue card

## What it does

Every design gets a short page written for you: what the design does, the choices it makes and why, what it
leaves out, and what you will see. The designer writes it in the first design PR and rewrites it in every
later round, so it always says what the design says now. Your Queue card links it, and you open it in your
editor, or on GitHub from your phone.

## The key choices, and why

- One page per design, in a folder of its own, not beside the design's history file. The history file only
  holds dated lines, and the synopsis is rewritten whole each round.
- A bought round rewrites the design's own page rather than starting a new one, so there is one page to read.
- The link appears in two places: on any question about the design (a steer, an ask, the end-of-rounds
  item), right after the link to the design's PR, and on the design's own line on the Queue and the Repo
  page, so you can read it while the rounds run and nothing is asked of you yet.
- Before the design merges, the link opens the designer's working copy; after, the main copy. It uses the
  same editor link the rest of ShiftLead uses, so it opens in your usual window.
- A GitHub link sits beside it for the phone. Where the editor link cannot work, the word itself goes to
  GitHub.
- The page has a fixed shape and a writing rule (plain words, no finding numbers, no code or file names), and
  a test checks every page against it. The final fact-check reads it against the design.

## What it rules out

- No change to the review record or the end-of-rounds item's detail: those stay written for reviewers.
- Older designs get no page, except those waiting on your decision when this lands: each of those gets one.
- A design pushed from somewhere this machine has not fetched shows no link until this machine fetches it,
  at the latest when its PR merges. A design proposed from a fork shows none.
- The GitHub link is drawn only for a repo hosted on GitHub.

## What you will see

A question about a design reads, at the end of its first line: design #3188 · synopsis · GitHub. A design on
the Queue or the Repo page shows synopsis · GitHub at the end of its title. Pressing synopsis opens the page
in your editor.
