# TD-1551: Order what a started member reads so sessions share the prompt cache

## What it does

It measures what a session ShiftLead starts reads from the prompt cache, and finds that reordering ShiftLead's own
text would save nothing. Across 511 starts on kmaster, no session's first request read more than Claude Code's own
fixed opening, about 27 to 29 thousand tokens. A start in the shiftlead checkout writes the rest, about 35 thousand
tokens, fresh. ShiftLead's own parts (the preface, the typed line, the brief) are already the same for every member
of a team line. What differs from session to session is Claude Code's own: the working directory, the session's
scratch folder, the git status and the date. Those come before ShiftLead's text in the system prompt.

So it files one build, TD-1651, to try the one lever there is: a Claude Code option that moves those
per-session parts out of the system prompt.

## The key choices, and why

- No reorder of the brief and no change to agent-cadence's session-start output: the measure shows it buys
  nothing, and the techlead agreed.
- The build first commits a small script that reads the cache figures from session transcripts, so the
  measure can be repeated by anyone.
- The option is tried in eight short, harmless runs outside any team, never on a real brief, since a brief
  would start real work. They cost a few cents on your own login.
- It is adopted only if the second run of each pair reads at least 300 tokens more from the cache, in both
  repeats, and writes correspondingly less. A host whose Claude Code lacks the option launches as before, and
  the first start after a host agent restart may go without it.
- Once adopted, a re-check two weeks after the merge compares real members' warm starts with their cold
  ones. If members do not read more, the option comes out again. If the evidence never arrives, it comes out
  as undecided after two deferrals.

## What it rules out

- Changing what the brief says or the order of its parts.
- Filing anything with Claude Code's makers: that is outward-facing and yours.
- Leaving the option on without real members showing the gain.

## What you will see

- A decision on the board: Go, one more round, or hold with a note. Go is recommended.
- If it lands, nothing on screen changes. The gain is small: at the threshold, about a quarter of a US cent a
  start at metered prices, and on a subscription only usage-window headroom.
