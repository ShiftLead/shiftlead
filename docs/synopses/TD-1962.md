# TD-1962: A failed layer listing refuses Add entry and Start session, and the design says nothing of it

## What it does

When agent-cadence's listing of your layers fails (it cannot run, hangs past its timeout, exits with an error, or
prints nothing usable), every start that would have read your own rules is refused in the listing's own words. The
code already behaves this way; the design now says so.

## The key choices, and why

- A failed listing is never treated as "no layer set": you set a layer, so a start without your rules and no word
  saying so would be wrong.
- Anything that reads a team's plan meets it: a team's Start, a member line's Start and Apply after a flow switch
  refuse before any session starts. Adding a member or raising a size on a running team is written first, then
  refused, so the next Start brings it; a team's max is written and its extras wait for the next Start.
- A session from the command line or the New session form, with a role that has a brief, is refused with the words.
  Add entry is refused, so no Add entry session starts. Start session on an entry lands on its form with the words
  as the reason; pressing Start there is your choice, and with no such role it starts without your work additions.
- With no agent-cadence at all to list your layers, a start still goes on, naming the lack. A single layer the
  listing itself could not read is left out, and agent-cadence's own session-start report names what it read.
- In the web page, a failure is remembered for a minute, so one team start runs a failing listing once; a command
  run again lists afresh.

## What it rules out

- A team half-started past a failed listing.
- A start that reads your rules going on without them, unless you press on from the form that told you why.

## What you will see

The listing's error, word for word, in the refusal: the team's message, the command's error line, the form's reason,
or the Add entry press's refusal. Mend the listing and press again; in the web page, within a minute of the failure,
the press meets the same remembered words.
