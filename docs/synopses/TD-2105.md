# TD-2105: Expire ShiftLead's status-line, launch and dead board files

## What it does

The hourly disk sweep starts clearing small files that pile up in ShiftLead's home because nothing ever expires them.
It removes old status-line readings, start-context files and launch scripts that no session record holds, and the
private board copies of repos that are no longer registered. It also removes old copies of agent-cadence shipped to a
container node once nothing pins them. The age limit is the one run logs already use, 30 days by default.

## The key choices, and why

- A file goes only when it is past the age and nothing owns it. Anything a session record names is kept, whatever
  state the session is in.
- Sessions gain one new remembered fact: the conversation their start-context file belongs to. Clearing a conversation
  changes the session's current id while the running tool still reads the old file, so without this the sweep could
  delete a file a live session needs.
- Launch records are never swept. A container node's members look ownerless from the home, and these records are
  already removed along with their session.
- A board copy goes only when no registered repo has its name, and never during a board press.
- A node's copy of agent-cadence stays while the node's checkout or any registered repo pins it.

## What it rules out

- It removes no transcript, no git work and no launch record.
- It does not clear temporary space under the system's temp directory, which is separate work.
- A session cleared before this ships could lose its old start-context file, and would then begin its next clear with
  no start context. This is accepted as a one-time risk.
- Setting the run-log age to zero turns these removals off.

## What you will see

The disk report gains a home files line showing what is held and removed, and its dry run lists what would go. About
3,000 stale status-line files and up to about 100 MB of dead board and node copies on this machine clear after the
builds, less whatever a pin still holds.
