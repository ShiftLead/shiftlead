# TD-2126: Keep a working seat's own test and review copies from filling temporary space

## What it does

A working seat keeps everything it makes until the seat ends, and one seat recently held 188,000 files that way.
This design releases what a seat can rebuild while it is still running, and tells the seat about the rest.

- A failed or killed test run is removed two hours after its last write, or ten minutes when space is short.
- A review copy goes in one named folder in the seat's scratch space, and is removed after a quiet day, or two
  quiet hours when space is short.
- A seat holding over 250,000 files on two hourly checks running gets one note naming its three largest items.

## The key choices, and why

- Only test runs and the folders in the copies folder are newly removed from a live seat, beside the old build
  leftovers already cleared when space is short. Anything else stays, since only the seat knows what it holds.
- A copy is kept while a process is using it, while it holds unpushed git work or a conversation's transcript, and
  whenever the check of what is in use cannot be read. Loose files in the copies folder are never aged.
- The ages are two hours for a failed test run and a day for a copy, so a failure can still be read.
- The budget sits above what a full test run uses at its peak, so a normal run does not trigger the note.
- File dates set far in the future no longer count as recent. Test fixtures set such dates, and they had
  stopped the existing cleanup from ever reclaiming a full test run.

## What it rules out

- It adds no new command, setting or Inbox row, and the note goes to the seat, not to you.
- It does not remove a seat's other folders, including hand-run test trees made before this change.
- The copies folder is for review copies, exported trees and hand-made precheck trees; a precheck's own tree keeps
  its own cleanup.
- It does not cover other repos' test suites, or files left outside a seat's scratch space (TD-2129 covers those).

## What you will see

Temporary space should stay lower during long grinding without anyone clearing it by hand. Seats' briefs will name
the copies folder. A week after the builds are live, a check reads each seat's hourly counts and reports any seat
that passed the budget without being told.
