# TD-2106: Decide what removes old session and build leftovers from temporary space

## What it does

Sessions and builds leave files in the machine's shared temporary space, and nothing clears them. The hourly disk
sweep gains a rule for two kinds. Build folders left by a killed install go after a quiet day. Claude Code's
temporary files go after three quiet days, the age you chose, unless something shows they may still matter. The
precheck's install also moves into its own temporary folder, so a killed run stops leaving build folders behind.

## The key choices, and why

- Removal is permanent, so every doubt keeps the file. An entry stays if a live session works in it, if it belongs
  to a live session's project, or if it holds git work that exists nowhere else.
- A file's age counts its last change of any kind, because a copied file can carry an old date and look abandoned.
- While a session outside ShiftLead is open, nothing written since it started is removed, since it may be that
  session's. The cost is that a session left open for weeks holds the sweep back until it closes.
- If the sessions cannot be read, or a linked container node is unreachable, nothing in Claude Code's folder goes
  that hour.
- The sweep refuses a temporary folder that is a link or belongs to another user, so it cannot be aimed elsewhere.
- Each pass spends at most about a minute here, so a large first clear-out is spread over several hours.

## What it rules out

- Removing anything from a scratch home's test runs, or following a link out of the temporary space.
- Seeing a session started under a settings folder no profile declares. Its files are protected by age alone.
- A resumed session keeping an old scratchpad that was removed. It makes a new one, as it does after a reboot.

## What you will see

Nothing new to press. The disk reading counts what the rule removed under scratch, and names up to twenty entries
a pass that only a safety test kept. Temporary space stops growing without limit, more slowly while a long-lived
outside session is open.
