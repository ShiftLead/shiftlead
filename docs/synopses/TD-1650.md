# TD-1650: The home notices a seat profile's tool upgraded since its last smoke and asks for the smoke, spending nothing

## What it does

When the tool a seat runs on (Claude Code, Gemini) is upgraded and no entry says so, as happened before TD-1576,
the home now notices and sends you a note asking you to run the seat smoke. It runs nothing itself and spends no
quota: noticing costs one version check of the tool's program each time a seat starts.

## The key choices, and why

- Each seat's start asks the tool for its version and writes it on the session's record. Only seats are read, so
  your own sessions never wait on it, and a slow or broken check gives up after ten seconds and starts anyway.
- The home keeps the last version it told you about, per tool, profile and machine, so two machines on different
  versions never flip back and forth, and two tools sharing the default profile never confuse each other.
- The first version it sees is only recorded: the seats you already declared stand on their own smokes.
- The note comes to you, not to a techlead. The smoke spends the profile's quota, which a techlead may not
  approve, so it could only pass the question up. The techlead agreed to this default.
- At most one note a day, listing every change since the last one: tools that update themselves often cost you
  one note, not one per update.
- Each line names the command to run the smoke, and where: on a node it says to run it on that machine.

## What it rules out

- The home never runs the smoke on its own; a scheduled smoke stays your choice, as a standing spend.
- A seat on the default profile can be smoked only if that profile has its own config directory set aside;
  the note says so, since the home cannot read which profile is the default.
- The home remembers the last version it told you about, not the last one smoked: the smoke's own line, quoted
  in a PR, stays the record that a smoke passed.
- Interactive and plain sessions are never read.

## What you will see

A note in your Inbox, such as: Gemini on profile gemini-reader moved from 0.65.0 to 0.66.0 on kmaster; its
seats there run on a tool version no seat smoke has passed on. Run it, with the command beside it. The seat
smoke's own last line also shows the tool's version, or says version unknown.
