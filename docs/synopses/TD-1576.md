# TD-1576: An unattended Gemini seat stops on every reply: its untrusted-flags guard prompts under yolo

## What it does

The Gemini fact-check seat stopped for you on every reply because Gemini CLI asks before running any command
that carries an option it has seen in earlier command output. Your unattended setting does not lift that check,
and no Gemini policy can. This repo's diffs and ao's own replies name every option, so the reply's option was
always "seen". The design gives the seat a road made only of plain words, so the check has nothing to stop on:

- a new reply command, ao reply, that takes the message id and the text with no option;
- the seat reads its inbox as plain text, which now says when an ask is a request to file an entry;
- every command in the fact-checker's brief carries no option and no path copied from output, and a test
  keeps it so.

## The key choices, and why

- A new command rather than a Gemini setting: the tool's code turns a policy's allow into a prompt (or a
  refusal when headless), so the setting route cannot work.
- A new command rather than a one-letter alias the tool happens to trust today: that list may change.
- The reply text is one single-quoted argument with no apostrophe in it, never a heredoc. The check splits
  a heredoc into words, which would expose an option quoted in a finding.
- The seat asks nobody a question. Asking takes an option, so what it cannot settle becomes a BLOCK finding.
- A request to read a PR as its reviewer is refused before it reaches the seat, whoever sends it. Its reply
  would need an option, and an unanswered one would keep restarting the seat. A team setup that names the
  fact-checker as a PR reader is marked as unable to follow.

## What it rules out

- Changing your Gemini settings, or anything in the Gemini adapter.
- Making other roles' briefs option-free: a Gemini lane member would still stop on the check.
- A fully automated live test: the build runs one live check by hand, and TD-1577's live smoke takes it over.

## What you will see

- The fact-check seat answers its asks without a prompt you have to allow.
- A slip, a command the model invents with an option, still shows as a prompt to answer in the terminal, but
  rarely rather than on every reply.
- Sending the fact-check seat a PR to review is refused, with a line naming the reader to ask instead.
