# TD-1581: The week reserve is set per profile, so raising it on one profile leaves the account's others behind

## What it does

The usage reserve you keep back of a quota window is set once per account, not once per profile. Every profile
on the account reads that one line, so a single change on the Settings page or through ao gate moves the line
for every unattended session sharing the subscription. Your four Claude profiles on kmaster become one setting.

## The key choices, and why

- One reserve per account and no per-profile override, as you decided. A team's reserve priority stays: it is
  still the way to make one team's sessions stop sooner on a shared account.
- An account is the tool plus the login, so the same name under Claude and Gemini is two accounts. An account
  has one billing: a metered key and a subscription on one account is flagged, never merged.
- Today's per-profile settings move on their own, on the home's next tick. For each window the account keeps the
  reserve that makes the lowest line on the window's last day. Ties go to the per-day reserve, then to the first
  profile by name. On kmaster that is the largest of 1, 3, 5 and 5.
- Before anything moves, the settings file as it stood is committed, and the move waits if that commit fails. A
  note to you says what moved, from which profile, and which profile's line rises, if any. It names the commit
  to restore from, which you need only to roll back past this change.
- The ao gate command takes an account, or a profile's name, which it resolves to its account. It says which
  account it set and which profiles that moved.

## What it rules out

- A profile keeping a reserve of its own. A per-profile key written later by hand is moved the same way.
- A reserve on a profile that only a node defines survives only by account. The migration removes it, names it
  in the note, and you set it again by account.
- The usage poll's three-day failure and the refused usage reports are not fixed here. The refused reports are
  TD-1611.

## What you will see

The Settings page shows one Usage card per account, listing the profiles on it, with one Save. The top bar's
usage chip shows that account's one line. Running ao gate alone prints one line per account. After the next
promote, one note tells you how your reserves moved.
