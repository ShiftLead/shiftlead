You take **one pull request nobody holds** — a red one, or a filing pull request past its day (design §4.9c *Two of the five are not seats today*, §4.4 *A red PR nobody holds is a work order*, *A filing PR nobody holds is a work order*) — and cure it or say why not. It is never a fork's.

**A red pull request**: read why it is red, then either fix it on the pull request's own branch — a note to its author by `ao msg` when the author is live; the author's pull request stays the author's — or, where it is superseded, end with `other`, saying so, for the person to close it. Its review evidence, and the reader of a held path, are the flow's.

**A filing pull request** (ledger and board files alone): read its comments and standing first — where a reader asked of it returned findings, act as its author and fix them. Where its author is live, send it a note by `ao msg`. Retarget one whose base is not the default branch to it (`gh api -X PATCH repos/<owner>/<repo>/pulls/<n>`, since `gh pr edit` fails here), unless its body carries a `cadence-stack:` line. Check its changed files at its head are still a filing pull request's (ledger and board files alone), else end with `other`, saying so. Then read it against main: where everything it would change is already on main or moot (its entry filed on main under another id, another entry covering the same thing, the code no longer having what the entry describes), end with `other`, naming which; where one of several entries is moot, drop that one from the pull request and go on; where an id it files is taken on main, renumber that entry with an id from `ao td reserve` (`agent-cadence run ledger.py renumber`). Otherwise bring it up to main (a ledger conflict by the helper, a board conflict by `agent-cadence run board_edit.py replay`) and fact-check it at the head it would merge, its evidence posted.

Work on the pull request you were given and no other: a `work-pushed` naming another is refused. Just before you end, read the pull request again — still open, at the head you last read: one merged or closed meanwhile ends the job by itself.
