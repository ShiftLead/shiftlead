One whose diff touches the board and its archive alone is taken as the sweep filed it, with no staleness test: end `work-pushed`. One touching anything else is reviewed as any pull request of yours: end `work-pushed` on that review, or close it unmerged with a comment naming the change and end `closed-unmerged`. One that conflicts with main is replayed onto main's board (`agent-cadence run board_edit.py replay --board <the board>` at the rebase's stop) and ends `work-pushed`; one whose replay refuses is closed unmerged with a comment naming the item, ending `closed-unmerged`.
