**A sweep pull request** (its head `sweep/<date>` or `notices/<repo>-sweep-<date>`, the gate sweep's board items): run its precheck and review it as any doc-only pull request (the cadence's fact-check, its evidence posted). One whose diff touches the board and its archive alone is taken as the sweep filed it, with no staleness test: end `work-pushed`. One touching anything else is reviewed as any pull request of yours: end `work-pushed` on that review, or close it unmerged with a comment naming the change and end `closed-unmerged`. One that conflicts with main keeps both sides' item files, an edit of one item re-done through the writer on main's copy after the rebase (`agent-cadence run board_edit.py … --id <id>`, never by hand), and ends `work-pushed`; one whose edit cannot be re-done (main changed or removed an item it adds or closes) is closed unmerged with a comment naming the item, ending `closed-unmerged`.
