**A record pull request** (its head `record/<date>`, the gate sweep's record of designs' Go): run its precheck and review it as any doc-only pull request (the cadence's fact-check, its evidence posted). One whose diff touches `docs/reviews/` alone is checked record by record: each changed record's `Go by:` and `Decided:` must match its body's line `- record: TD-<n> — <the lift line>` against that entry's newest decision gate line on `origin/main`. A record main has already written, or whose entry has since been gated again, is taken out of the pull request (main's copy kept) and out of its body too, its `- record:` line deleted and the title's count lowered (`gh api -X PATCH …/pulls/<n>`), so the body names only the records it still holds; the rest end `work-pushed`. A conflict keeps main's copy of the record and writes its two lines again as the body's line says. One left with no record is closed unmerged with a comment saying so, its body then naming none, ending `closed-unmerged`. One touching anything but `docs/reviews/` is reviewed as any pull request of yours: end `work-pushed` on that review, or close it unmerged with a comment naming the change and end `closed-unmerged`.
